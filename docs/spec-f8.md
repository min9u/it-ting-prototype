# F8 커뮤니티 명세 구현 (2026-11-16)

## 요청
Figma 02 "스켈레톤 기능 명세"의 F8 커뮤니티 요구사항을 빠짐없이 구현하고, 디자인은 03 Screens와 02 명세 화면의 그림을 참고해 맞춘다. 명세 문장과 03 디자인이 다르면 02 명세(기능)를 따른다.

- 기준 자료: `design/figma/spec/f8/F8-01.png` ~ `F8-12.png`, 공통 규칙 `design/figma/spec/f5/f0-common.png`
- 이전 검토 `docs/community-spec-review.md`는 11-12·11-13 기준이라 참고만 함. 그 뒤 명세에 저장한 글·내가 쓴 글·댓글 단 글·글 삭제·신고가 들어왔음

- `App.tsx`: import 한 줄, 라우트 3개 추가(`/board/mine`, `/board/commented`, `/board/:postId/edit`), `/board/saved`는 `BoardActivity kind="saved"`로

- `components/Feedback.module.css`: `.etc` 입력칸 스타일
- `screens/ScreenIndex.tsx`: 커뮤니티 목록을 새 화면으로 바꿈

### 00 공통에서 쓴 규칙
- 4 사용자 표시: 반 표기 없음, 소속은 캠퍼스·기수·층. 누르면 프로필 팝업. 탈퇴한 사용자는 기본 두더지 + "탈퇴한 사용자", 소속 없음, 눌리지 않음(p1 댓글에 예시)
- 5 관심사 태그: 커뮤니티 글은 대분류, 나와 겹치는 건 세부 관심사로 세고 ✓ 표시
- 6 팝업: ×·바깥·ESC로 닫힘 (공용 Modal)
- 7 빈 상태: 흙더미 두더지 + 문구 (공용 EmptyMole)
- 8 시간: 방금 · N시간 전 · 어제 · N일 전, 7일이 넘으면 날짜
- 16 완료 토스트, 17 삭제 확인, 18 저장 전 취소("아직 저장되지 않았습니다", 나가기 / 계속 수정), 21 대상 없음

## 판단한 것
- **시간 표기 "N분 전" 없음**: 공통 8이 "방금 · N시간 전 · 어제 · N일 전"이라 1시간 안은 모두 "방금". 03 디자인의 "12분 전"과 다름
- **7일 넘은 글은 날짜**: 공통 8 "그보다 오래되면 날짜"를 7일로 봄
- **이어 쓰기 확인 팝업은 만들지 않음**: 요청에는 있었지만 최신 명세(글쓰기 7)가 "임시 저장 없음"이라 기존 임시저장·임시저장한 글 패널도 뺌
- **글 상세 A안 삭제**: 확정 시안 B만 남김 (`?v=b` 주소도 없앰)
- **댓글 더 보기 문구**: 남은 게 10개보다 적으면 "댓글 4개 더 보기"처럼 남은 수를 씀
- **댓글 삭제 설명(답글 없을 때)**: 명세에 없어 "삭제한 댓글은 되돌릴 수 없어요."로 씀
- **토스트 문구**: 저장 "글을 저장했어요"(+저장한 글 바로가기), 저장 취소 "저장을 취소했어요", 글 삭제 "게시물을 삭제했어요"(명세 예시), 댓글 삭제 "댓글을 삭제했어요", 이미 신고 "이미 신고했어요", 등록 "게시글이 등록되었어요 / 커뮤니티에서 바로 확인할 수 있어요"(공용 TOAST.posted는 "게시판" 문구라 따로 둠), 수정·신고는 공용 TOAST(edited·reported)
- **공유**: 명세에 동작이 없어 주소 복사 + "링크를 복사했어요" 토스트
- **2·3번째 사진**: 대표 사진은 위에, 나머지는 본문 아래 작은 칸으로 보여 줌
- **좋아요·저장 수**: 목 데이터의 다른 사람 수 + 내 것. 인기 점수의 저장 수도 같음
- **"내 관심사만"의 내 관심사**: 온보딩·내 정보 수정에서 고른 값(`getMyInterests`), 없으면 목 데이터
- **"많이 이야기하는 관심사"**: 디자인 그림의 "관심사 별로 보기"(저장한 글 등 화면)도 같은 위젯으로 씀. 서브 화면에서 누르면 그 관심사로 거른 커뮤니티 목록으로 감
- **삭제된 글을 지운 뒤 상세 주소**: 공통 21 "삭제된 글이에요" 화면. 없는 글 id도 같은 화면
- **글 수정 화면을 남의 글·가려진 글로 열면**: 안내 화면("내가 쓴 글만 수정할 수 있어요" / "신고로 가려진 글은 수정할 수 없어요")
- **오른쪽 사이드는 따라오지 않음**: 위젯이 화면보다 길어 아래가 잘려서 일반 흐름으로 둠
- **상태는 새로고침하면 처음으로**: 아티팩트에서 sessionStorage가 막힐 수 있어 메모리에만 둠. 화면 사이 이동에서는 이어짐

## 확인한 것
- `npx tsc -b`, `npx vite build` 통과
- 헤드리스 크롬(1440×960)으로 스크린샷: 목록(1·2쪽, 빈 상태 + 필터 초기화, 내 관심사만 + 댓글순), 상세(대표 사진, 레일, 모임 카드, 태그, 댓글 10개 + 더 보기, 탈퇴한 사용자, 가려진 댓글, 다음 읽을 글), 신고 팝업(기타 입력칸), 신고 후 접힌 글 + 토스트, 내 글 → 수정 → 제목 바꾸고 취소 → 저장 전 취소 팝업 → 나가기, 내 글 삭제 → 목록 + 토스트, 글쓰기(모임 홍보 → 모임 필수, 태그 고르기) → 등록 → 상세 + 토스트, 댓글 등록, 내가 쓴 글(가려진 글 표시), 댓글 단 글(내 댓글 한 줄·외 N개) → 그 댓글로 스크롤·강조, 댓글 수정("수정됨"), 답글에 답글(@닉네임), 저장한 글(저장 날짜), 가려진 글 안내 화면

## 남은 것
- **비로그인으로 열 때(상세 16)**: 앱에 로그인 상태가 없어 로그인 화면으로 보내는 것과 로그인 뒤 돌아오기를 못 함. 인증 가드가 생기면 `/board/*`에 걸면 됨
- **알림(F9)·관리자 복구(F11)**: 가려짐·삭제된 글의 알림 줄, 작성자 알림, 관리자가 공개로 되돌리기는 각 영역에서
- **방명록·사용자 신고의 "이미 신고했어요"**: 공용 `ReportDialog`는 사유·기타 입력만 맞췄고, 중복 신고 막기는 부르는 쪽(땅굴·프로필 팝업)에서 해야 함
- **실제 사진 저장**: 올린 사진은 브라우저 object URL이라 새로고침하면 사라짐 (백엔드 필요)
- 모바일 폭(390px)은 레이아웃만 접어 두었고 스크린샷으로는 확인 안 함 (공통 20: 데스크톱 전용)
