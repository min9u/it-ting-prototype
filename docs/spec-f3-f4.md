## 판단한 것
- **가구 후보**: 데이터(interest_catalog)에는 세부 관심사마다 가구가 하나뿐이고 03 시안의 후보(피아노·스피커·피아노 의자)는 카테고리 가구라서, 후보 = 그 관심사의 기본 가구 + 같은 대분류에서 내가 고르지 않은 선반 소품 2개로 정함(자리가 선반이라 같은 자리에 들어가는 것만). 바닥·반려동물 자리 관심사(기타연주, 반려동물 5종)는 후보가 기본 하나. 카테고리 가구(피아노·오락기 등)는 고르는 대상이 아님.
- **"통하는 취향" 5명 이하**: 목 인원수가 전국 규모(수십~수천)라 그대로면 묶음이 비어서, 1/100 로 줄여 SSAFY 규모로 보고 5명 이하를 묶음(`isRare`). 화면엔 숫자를 안 보여줌.
- **땅굴 무드**: 명세대로 "가장 큰 취향(가중치)" 대신 대표 관심사(맨 앞)의 대분류. 3a 배지 문구도 "대표 관심사".
- **안내 말풍선**: 03 시안에는 × 가 있지만 명세(마우스를 올렸을 때만, 닫기 없음)를 따름. 키보드 초점에서도 뜸.
- **상태 배지**: 명세 이미지 판은 "단골 N명"만 있어서 방문자 배지·방문자 목록 모달을 뺌. 단골 수는 목 값 8.
- **내 정보 수정 "두더지 꾸미기" 버튼**: 예전 명세(메타데이터)에는 있었지만 지금 명세 이미지에는 없어 뺌(꾸미기 모드 두더지 탭에서 함).
- **관심사 재선택 후 흐름**: 4 → 2 → "다음"이면 3을 건너뛰고 3a(새로 만들기) → 4. 질문·답변은 그대로 유지.
- **닉네임 겹침**: 서버가 없어 목 사용자 닉네임 + 몇 개 예약어(도토리·보리·두더지·운영자 등)로 판정.
- **캠퍼스·층 이동**: 내 소속(`ME_HOME`)과 프로필에는 저장하고 토스트로 "입구가 옮겨졌어요"를 알리지만, 탐색 들판의 내 자리(`MY_FLOOR`, F5 영역)는 건드리지 않음. "새 학기 안내에서 '나중에 하기'를 누른 사람"의 상태도 F5 쪽이라 반영 못 함.
- **방명록 모달을 방문자 뷰도 씀**: 방문자(삭제 권한 없음)에게는 "신고"만 보이게 함 (예전엔 동작 없는 삭제|신고가 보였음).
- **질문 문장**: 02 에 질문 목록이 없어 Figma 예시 말투로 대분류마다 2개 + TMI 8개를 만듦(`data/questions.ts`).
- 꾸미기 저장·내 정보 저장 토스트는 공통 문구 `TOAST.edited`("수정이 완료되었어요").
