### D. 땅굴을 별도 스레드(Worker)에서 그리기 — 시험판
- `app/src/three/worker/`: 메인(`roomWorkerHost.ts`)이 캔버스를 `transferControlToOffscreen()`으로 Worker(`roomWorker.ts`)에 넘기고, Worker는 **원래 `roomScene.ts`를 그대로** 돌림. Worker에는 DOM이 없어서 `workerShim.ts`가 최소한만 흉내 냄 (window·document·ResizeObserver·Image, OffscreenCanvas에 style·getBoundingClientRect 등)
- 입력: 캔버스 누르기·끌기·휠과 키(WASD·방향키)를 메시지로 보내고, Worker에서 가짜 이벤트로 다시 쏨. 리액션·액세서리·패널 이동·가볍게 보기도 메시지
- Worker를 못 만들거나 시작하다 실패하면 원래대로 메인 스레드에서 그림
- 시험판 한계: **말풍선·가구 이름표가 안 보임**(DOM이라), 커서 모양 고정, 탭을 숨겨도 Worker는 그리기를 안 멈춤(쉬면 멈춤은 그대로 됨), Worker 쪽 코드가 따로 번들됨(공유 빌드 크기 증가)

### E. 2D 두더지 (탐색하기) — 시험판
- `app/src/three/moleSprites.ts`: 두더지를 불러온 뒤 한 번, 방향 4개(앞·오른쪽·뒤·왼쪽) × (쉬기 4장 + 걷기 6장) = 40장을 3D로 찍어 2D 아틀라스(224px 칸)에 모음. 렌더러가 alpha 없이 만들어져 있어서 검은 바탕·흰 바탕에 두 번 그려 차이로 투명도를 구함. 6장마다 한 프레임 쉬어서 긴 작업을 쪼갬. 착용한 액세서리도 같이 찍힘 (F를 켜면 빠짐)
