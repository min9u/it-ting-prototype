## 1. 게시글

### C 글쓰기
1. **카테고리 목록이 화면마다 다르다** (가장 먼저 정할 것)
   - 목록 화면 탭(디자인): 전체 / 모임 후기 / 자유
   - 목록 명세 표: 전체 / 질문 / 자유 / 모임 후기 / 정보
   - 글쓰기 명세: 자유 / 질문 / 후기 / 모임 홍보 (필수 1개)
   - 저장한 글 탭(03): 전체 / 자유 / 정보 / 질문 / 모임 후기
   - 글 상세 시안 B "다음 읽을 글" 라벨: 정보, 질문
   - → "후기"와 "모임 후기"가 같은지, "정보"는 글쓰기에서 못 고르는지, "모임 홍보"는 목록 탭에 없는데 어디서 보는지가 정해지지 않음
2. 관심사 태그: "선택. 관심사 목록에서 골라 붙인다"만 있음. **최대 개수**, 내가 등록한 관심사만인지 전체 65개인지 없음
3. 이미지: **최대 장수, 용량, 형식**, 순서 바꾸기·삭제 없음. 상세에서 여러 장일 때 어떻게 보여 주는지 없음(A는 "본문 가운데", B는 "첫 사진을 화면 폭 전체로")
4. 모임 연결: "내가 만들었거나 참여한 모임 중 하나". **취소·삭제된 모임**, 끝난 모임도 고를 수 있는지, 나중에 모임이 삭제되면 글의 모임 카드는 어떻게 되는지 없음. "모임 홍보" 카테고리일 때 모임 연결이 필수인지도 없음
5. 입력 검증: 제목 50자·본문 1000자·필수는 있음. **공백만 입력**, 글자 수 넘김 처리(입력 막기 vs 경고), 등록 버튼 연타(중복 등록) 방지, 등록 실패 시 처리 없음
6. "비로그인 시 로그인 유도": 앱은 로그인 뒤에만 커뮤니티에 들어오는 구조라, 비로그인으로 커뮤니티를 볼 수 있는지 자체가 정해져야 함 (공유 링크로 들어온 사람 포함, 아래 R-7)

### R 목록·상세
1. **정렬 옵션이 다름**: 주석 "최신순(기본)/인기순/게시순" vs 명세 표 "최신순(기본)/인기순/댓글순". "게시순"은 최신순과 같은 말이라 오타로 보임. **인기순의 계산식**이 없음
2. **이번 주 인기 글 TOP5 기준이 다름**: 주석 "최근 1일, 좋아요·댓글·북마크" vs 명세 표 "최근 7일, 좋아요·댓글". 제목이 "이번 주"인데 1일. 가중치, 동점, 5개가 안 될 때 처리 없음
3. **글 더 보기**: 주석 "더 없으면 버튼 비활성화" vs 명세 표 "버튼을 숨긴다". 한 번에 몇 개인지 없음
4. 검색: "제목·본문·닉네임, Enter로 실행". 검색창 안내 문구는 "선택된 카테고리 내 검색" → 카테고리 탭·내 관심사만·관심사 칩·정렬과 **어떻게 겹치는지**(AND인지, 검색하면 필터가 풀리는지), **결과 없음 화면**, 검색어 지우기 없음
5. 필터 조합: 카테고리 탭 + 내 관심사만 토글 + "많이 이야기하는 관심사" 칩이 동시에 걸릴 때 규칙 없음. 칩의 기간·개수 없음. 다른 글 상세에서 관심사 태그를 눌러 왔을 때 목록에 어떤 필터가 걸린 상태인지 없음
6. 목록 카드 항목: 주석에는 "북마크"가 있고 명세 표에는 없음. 카드에서 바로 저장할 수 있는지 정해야 함
7. 공유(링크 복사): 링크를 받은 사람이 **비로그인이면** 글을 볼 수 있는지 없음 (앱 전체 접근 정책과 연결)
8. 조회수: 같은 사람이 여러 번 볼 때, 작성자 본인이 볼 때 세는지 없음
9. **글 상세 시안 A와 B 중 무엇이 기준인지** 정해야 함. 03 디자인은 A 계열이지만 명세에 없는 것이 있음: "< 게시판 돌아가기", **이전 글 / 다음 글**(어떤 순서·필터 기준인지 없음). B에만 있는 것: 인용 블록(글쓰기에 입력 칸이 없음 → 누가 어떻게 정하는지 불명), 더보기의 "차단"(다른 곳에 차단 기능 명세 없음), 댓글 정렬
10. 이름: 명세는 "커뮤니티", 03 디자인 GNB·뒤로 가기는 "**게시판**". 안내 문구도 "디굴디굴 나누는 이야기"(주석·디자인) vs "**두런두런** 나누는 이야기"(명세 표)

### U 글 수정
1. 진입·채우기·완료 후 상세 이동은 명세 있음
2. **수정 중 나가기 확인 팝업**이 글쓰기에만 있고 수정에는 없음 (바꾼 내용이 있을 때 띄울지)
3. 수정한 글에 "수정됨" 표시, 수정 시각을 보여 줄지 없음
4. 카테고리를 바꿀 수 있는지(특히 댓글이 달린 뒤), 수정 가능 기간 제한이 있는지 없음
5. 수정 완료 토스트: 앱 Toast 6종에 "수정"이 있으나 명세에는 없음

### D 글 삭제 (명세 없음, 디자인만 있음)
- 03 팝업: "게시물을 삭제할까요? 게시물에 달린 댓글과 답글도 함께 사라지고 되돌릴 수 없어요. [취소] [삭제]"
- 정해야 할 것
  1. 진입: 글 상세 › 더보기 › "삭제" (명세 표 4번 "본인 글이면 수정·삭제"에만 한 줄)
  2. 삭제 뒤 어디로 가는지 (목록? 직전 화면?), 완료 토스트 문구
  3. 다른 사람이 **저장한 글**, 그 글에 대한 **알림**, 공유 링크로 들어왔을 때 → "삭제된 글이에요" 화면이 필요한지
  4. 댓글이 달린 글도 삭제 가능한지 (팝업 문구로는 가능)
  5. 관리자 삭제(신고 처리 결과)와 작성자 삭제의 표시 구분

## 2. 댓글·답글

- C: "빈 입력은 등록 불가"만 있음
  - **글자 수 제한** 없음
  - **답글 깊이**: 디자인상 답글에는 "답글 달기"가 없어 1단계로 보임 → 명세에 "답글은 한 단계" 명시 필요. 답글에서 누구에게 답하는지(@닉네임) 표시 여부
  - 03 2026-11-12 디자인은 "답글 달기 → 대상 댓글 아래 입력창(②안)"으로 정해짐 → 명세에 반영 필요
- R: "댓글 더 보기 + 남은 개수". 한 번에 몇 개, **댓글 수 21에 답글이 포함되는지**, 정렬(시안 B에만 "최신순" 드롭다운)
- **U 댓글 수정: 명세 없음** (본인 댓글 수정 가능? 어디서? "수정됨" 표시?)
- **D 댓글 삭제: 명세 없음**
  - 답글이 달린 댓글을 지우면 답글도 지우는지, "삭제된 댓글이에요" 자리만 남기는지
  - 글쓴이가 남의 댓글을 지울 수 있는지
- 댓글 신고: 없음 (글 신고만 디자인 있음)
- 댓글 좋아요: 목록에 수는 있으나 눌러서 토글하는지 명세 없음

## 3. 좋아요·저장·신고

- 좋아요: 내 글에 좋아요 가능 여부, 좋아요 누른 사람 목록을 볼 수 있는지
- 저장(북마크)
  - **저장한 글 화면(03)이 명세에 없음**: 저장한 날짜 표시, 탭(카테고리), 키워드 검색, 정렬 기준(저장 순?), 목록에서 저장 취소 방법
  - 저장한 글 화면 옆 "내 활동"에 "댓글 단 글", "저장한 글"이 있음 → **"내가 쓴 글"**은 없는지, "댓글 단 글" 화면 명세도 필요
- 신고 (03 팝업만)
  - 사유: 스팸·홍보 / 욕설·비하·괴롭힘 / 음란물 / 기타. "**기타**" 선택 시 직접 입력 칸이 있는지
  - 같은 글을 두 번 신고할 수 있는지, 내 글은 신고 메뉴가 안 보이는지
  - 신고 뒤 처리: 몇 건 이상이면 자동으로 숨기는지, 신고한 사람에게 결과를 알리는지 (관리자 F11 "신고 처리"와 연결)
  - 시안 B의 "차단"을 넣을지

## 5. 결정이 필요한 질문 (우선순위 순)
