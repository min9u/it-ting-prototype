## 2. CRUD별로 빠졌거나 애매한 것

### 게시글
- **C 글쓰기** (740:4054)
  1. 관심사 태그 "선택. 관심사 목록에서 골라 붙인다": **최대 개수**, 내 관심사만인지 전체 65개인지
  2. 이미지 "선택. 사진 추가로 올리고 썸네일": **최대 장수·용량·형식**, 순서·삭제. 상세는 A "본문 가운데", B "첫 사진을 화면 폭 전체로" → 여러 장일 때 보여 주는 방법
  3. 모임 연결 "내가 만들었거나 참여한 모임 중 하나": **취소·종료·삭제된 모임**도 고를 수 있는지, 연결한 모임이 나중에 삭제되면 글의 모임 카드(상세 13번)는 어떻게 되는지. "모임 홍보" 카테고리면 모임 연결 필수인지
  4. 검증: **공백만 입력**, 글자 수 초과 처리(입력 막기 / 경고), **등록 연타**(중복 등록) 방지, 등록 실패 시
  5. 글쓰기 버튼 "비로그인 시 로그인 유도": 커뮤니티를 비로그인으로 볼 수 있다는 뜻인데, 그 범위가 다른 곳에 없음 (아래 R-6)
- **R 목록·상세**
  1. 한 번에 불러오는 글 수 ("글 더 보기")
  2. 검색(9번) "제목·본문·닉네임, Enter": 카테고리 탭·내 관심사만·관심사 칩·정렬과 **같이 걸리는지**(AND인지, 검색하면 필터가 풀리는지), **결과 없음**(F0 빈 상태를 가리키면 됨), 검색어 지우기
  3. "많이 이야기하는 관심사" 칩(11번): 기간, 개수, 다른 필터와의 관계
  4. 상세의 관심사 태그(7번) "해당 관심사 글 목록으로 이동": 목록에 어떤 필터 상태로 도착하는지 (칩 필터와 같은 것인지)
  5. 조회수: 같은 사람 반복 조회, 작성자 본인 조회를 세는지
  6. 공유(8번) "링크 복사": 링크를 연 사람이 **비로그인**이면 글을 볼 수 있는지
  7. 관련 이야기 TOP3(14번) "같은 주제": 주제 = 관심사 태그인지 카테고리인지. 태그가 없는 글이면
- **U 글 수정** (740:4183)
  1. 진입·기존 내용 채우기·완료 후 상세 이동은 있음
  2. **수정 중 나가기 확인**: 글쓰기에만 있음. 수정에도 같은 규칙인지
  3. "수정됨" 표시·수정 시각 노출
  4. 댓글이 달린 뒤 카테고리·제목을 바꿀 수 있는지, 수정 기간 제한
  5. 완료 알림: F0 "저장, 삭제, 신고, 작성이 끝나면 짧은 문구" → **수정**도 토스트 대상인지 (F0 목록에 수정이 없음)
- **D 글 삭제** (명세 없음. 상세 4번 "본인 글이면 수정·삭제"뿐)
  1. 확인 팝업은 F0 "되돌릴 수 없는 삭제는 확인 팝업(취소 / 삭제)"를 가리키면 됨. 다만 **문구**(댓글·답글도 같이 사라지는지)는 F8에 적어야 함
  2. 삭제 뒤 이동할 화면, 완료 토스트 문구
  3. 다른 사람의 **저장 목록**, F9 **알림**(내 글에 댓글 등), 공유 링크로 지운 글에 들어왔을 때 → "삭제된 글" 처리
  4. 관리자 숨김(F11 "글·댓글 숨김")과 작성자 삭제가 사용자에게 어떻게 다르게 보이는지

## 4. 03 디자인에서 참고할 수 있는 것 (명세로 옮길 후보)
03에는 이미 그려진 답이 있어서, 위 빈칸을 채울 때 참고하면 된다. 명세와 다르다고 고칠 대상은 아니다.

| 02의 빈칸 | 03 참고 |
|---|---|
| 글 삭제 | 삭제 팝업: "게시물을 삭제할까요? 게시물에 달린 댓글과 답글도 함께 사라지고 되돌릴 수 없어요. [취소] [삭제]" → 글과 댓글을 함께 지우는 방식 |
| 글 신고 | 신고 팝업: "이 게시물을 신고할까요? 신고 사유를 골라 주세요. 신고한 사람은 상대에게 알려지지 않아요." 사유 4개(스팸·홍보 / 욕설·비하·괴롭힘 / 음란물 / 기타), [취소] [신고하기] |

| 답글 입력 위치 | 답글 달기 → 그 댓글 바로 아래 입력창 (2026-11-12) |
| 글 상세 | 03은 시안 A 계열 + "이전 글 / 다음 글" (02에는 없음. 넣을지 정하기) |
| 이름 | 03 GNB·뒤로 가기는 "게시판", 02(F0·F8)는 "커뮤니티" → 02 기준이면 03 쪽 문구를 바꿀 대상 |

## 5. 결정이 필요한 질문 (우선순위 순)
1. 카테고리 최종 목록 (목록 탭·글쓰기 공통)
2. 글 상세 시안 A / B 중 확정
3. 글 삭제, 댓글 수정·삭제 명세 추가 (특히 답글 달린 댓글 삭제)
4. 댓글·답글 좋아요, 댓글 신고 추가 여부 (F9·F11과 맞추기)
5. 인기 글 기준(1일 / 7일, 북마크 포함)과 정렬 옵션(댓글순 / 게시순), 더 보기(비활성 / 숨김)
6. 저장한 글을 어디서 보는지 (화면 추가 여부)
7. 차단한 사람의 글·댓글 노출
8. 글쓴이 카드 소속 표기(F0의 "반 안 보여 줌"), 작성 시간 형식(F0와 맞추기), 안내 문구(디굴디굴 / 두런두런)
9. 이미지·태그 개수, 댓글 글자 수 제한
10. 비로그인 접근 범위 (공유 링크)
