- Draco + WebP는 앱이 이미 해독기를 갖고 있어(`three/glb.ts`, 일반 빌드 wasm · 공유 빌드 JS 해독기) 코드 변경 없이 읽힘. 두더지 glb가 2개(0.67MB + 0.80MB)에서 1개(0.68MB)로 줄어 공유 빌드도 0.8MB쯤 가벼워짐.

## 높이 +0.03m
- glb `mole` 노드 translation y = +0.03. 앱 코드가 어느 쪽인지 확인한 결과:
  - **땅굴 방 · 탐색 · 방문자**(`moleActor.ts`): 두더지 그룹(actor) 위치에 sit point·바닥 높이를 놓고 glb 노드가 그 위에 얹힘 = v1_3(`mole.glb`)도 이미 같은 +0.03이었음 → **바뀐 것 없음**, 방석 높이도 그대로.
  - **채팅방**(`chatRoomScene.ts`): 옛 `mole_chat.glb`에는 노드 이동이 없어서 `root.position.y = SIT_Y(0.13)`을 "그대로" 썼음 → v1_4로 바꾸면 노드가 더해져 3cm 뜸. **그룹 높이를 `SIT_Y − MOLE_NODE_Y`(0.10)로** 맞춤(`ROOT_Y`, 퇴장 연출도 같은 기준). 몸 최저점 0.0118 + 0.13 = 0.0418 + 0.10 = 0.1418로 같음. 시험이 glb 노드 값과 `MOLE_NODE_Y`가 같은지 확인(글 파일이 바뀌면 시험이 알려 줌).
