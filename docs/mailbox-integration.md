## 판단한 것
- **블룸 대신 빛무리 스프라이트**: 땅굴 방은 조명을 구운 장면이라 후처리(EffectComposer)가 없음. 선택적 블룸을 하려면 composer + 블룸 패스 + 층 나누기가 필요해 매 프레임 비용이 커지고, 저사양(배경 한 번 A·선명한 방 S·부분 그리기)과도 맞지 않음. 그래서 우체통 앞에 가산 혼합 원형 스프라이트(#FFD27A)를 두고 투명도를 발광 세기에 맞춤(세기 × 0.38). 우체통 밖으로 번지는 느낌은 비슷하게 나고 비용은 거의 0
- **외곽선**: OutlinePass 대신 메시마다 법선 방향으로 1.2cm 부풀린 뒷면 단색 껍데기(#FFF4D2)를 자식으로 붙이고 호버 때만 보임. 깃발이 움직여도 같이 따라감
- **움직이는 층(layer 1)에 둠**: 깃발·편지·발광·외곽선이 바뀌는 물건이라 저사양 배경 그림(A)·선명한 방 그림(S, 탭 안 캐시)에는 넣지 않음 → 상태가 바뀌어도 방 그림을 다시 찍지 않고, 바뀐 프레임에만 우체통 둘레 사각형을 부분으로 다시 그림. 선명한 방 캐시 키에 우체통 상태를 넣을 필요도 없음
- **발광 반복(0.5↔1.5, 2.6초 주기)은 고사양만**: 저사양은 가만히 있으면 그리기를 멈추는 구조라 계속 반복하면 루프가 쉬지 못함 → 세기 1 고정. 모션 줄이기 설정이어도 고정
- **클릭 상자** 0.6 × 0.72 × 0.56m (모델 0.30 × 0.40 × 0.26m). 앞에 가구·집주인이 더 가까우면 그쪽이 먼저. 마우스를 올리면 외곽선 + "방명록 보기" 이름표. 캔버스 커서는 원래 손가락
- **남의 땅굴에서 깃발**: 집주인의 "읽지 않은 방명록" 상태를 방문자가 보는 건 이상해서, 방문자 화면에서는 내가 남겼을 때만 올라가게 함 (확인받을 것)

## 확인
- `npx tsc -b` 통과, `vite build` 통과
- 헤드리스 크롬(CDP)으로 확인: 고사양(`?gpu=gpu`)·저사양(가속 끔) 모두 침대 발치 오른쪽에 우체통, 새 방명록 있음이면 빛무리·편지가 보임. 저사양에서 마우스 올림 → 외곽선 + "방명록 보기", 클릭 → 방명록 전체보기 모달(두더지 그대로), 닫은 뒤 깃발 내림·편지 숨김·발광 꺼짐이 잔상 없이 다시 그려짐
- 처음 만든 코드에서 traverse 도중 외곽선 자식을 붙여 무한 재귀 → 메시를 먼저 모으도록 고침
