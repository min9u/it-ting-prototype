## 결론
탐색 화면을 **걸어 다니는 밭 → 구멍에서 구멍으로 뛰는 들판**으로 바꿨다. 예전 화면(← → 로 이웃 넘기기, 고정 안내판, 첫 진입 추천 모달)은 없앰.

| 명세 (02 F5 · 00 공통) | 구현 |
|---|---|
| 1 돌아다니기: 들판 = 한 학기의 캠퍼스-층, 입구는 땅굴을 만든 순서대로 자리에 놓이고 안 바뀜. 빈 들판이면 빈 상태 + "다른 캠퍼스-층 가보기" | 방향키(WASD도)·구멍 클릭으로 점프. 자리 번호 = 온보딩 완료 순서(목 데이터). 빈 들판(부울경-1층)에서 빈 상태 카드 |

|---|---|
| 들판 108×72m, 구역 36×36 6칸, 켜는 구역 수 = ceil(인원/25), 번호 순서 | 켤 구역만 만들어 붙임. 서울-2층 38자리 → 구역 2개, 서울-3층 61 → 3개 |

| 안 켠 구역은 잔디색 평면, 울타리는 켜진 구역 안의 것만 | 바깥 잔디(`outer_grass`) 재질을 복제해 구역 크기 평면으로 덮음(바깥 둥근 모서리까지 1.5m 더 크게). 울타리는 위치가 켜진 구역 안인 것만 |
| 구멍: hole_rim 만 인스턴스 색, 내 구멍은 분홍 #F2A3A1 + 후광, 배정 안 된 자리는 빈 자리 또는 없음 | 링 색은 `instanceColor`(rim 의 COLOR_0 가 흰색이라 그대로 곱해짐). 빈 자리는 `empty_pad` 로 보여 줌 (들판이 얼마나 찰지 보이게) |
| 두더지 앵커 = 구멍 중심, 높이 0.075, 회전 0, 카메라 정면 | `mole.glb` 를 v1_3(동작 25개, v1_2 의 상위 호환)으로 교체. 땅굴 방도 같은 파일 |
| 방향키: 화면 기준 ±45° 안 가장 가까운 구멍, 없으면 안 움직임. 클릭: 그 구멍으로 바로 | 같음. 거리가 비슷하면 더 곧은 방향(점수 = 거리 + (1−cos)×6) |
| hop_down 0.42 → 숨김 → 카메라 0.4 → 보임 + hop_up 0.5 → idle, 1배속, 이동 중 입력 잠금, depthTest 끄기·투명 금지 | `MoleActor.hop('down'|'up')` 추가. 카메라는 ease-in-out 0.4초. 이동 중 목표 구멍에 노란 링(깜빡임) |
| Enter: 서 있는 구멍의 땅굴, 화면 어두워짐 → 땅굴 | 0.45초 어두워진 뒤 이동. 들판에 나올 때(땅굴에서 나옴 포함)는 어두운 화면에서 장면 준비가 끝나면 밝아짐 |
| 카메라: FOV 32.3°, 45°, 12m 고정. 목표점은 켜진 구역 camRect 합집합 안 | 같음. 합집합은 "가장 가까운 사각형 안의 점"으로 제한 |
| 사다리: 서버(캠퍼스·층) 선택으로 | 사다리 둘레 1.5m 를 누르면 캠퍼스-층 고르기 |
| 작물은 설정값(theme.crop_glb·crop_nodes·grass_color) | 배치의 작물 항목은 노드 이름으로 들어 있고 glb 는 `theme.crop_glb` 로 고름. 새 작물 glb 가 오면 `GLB` 표에 한 줄 + 배치 JSON 다시 만들기 |
| 성능: 인스턴싱 + 켜진 구역·카메라 주변만 | 부품(노드) × **12m 칸**마다 InstancedMesh 하나 → 화면 밖 칸은 frustum culling 으로 안 그림. 그림자는 해 그림자 상자(30m)를 카메라를 따라 옮김. 저사양은 그림자 대신 두더지 발밑 판 |

배치 JSON(약 800KB)은 앱이 쓰는 값만 남겨 136KB(gzip 40KB)로 줄임: `node app/scripts/build-field-layout.mjs` → `app/src/data/fieldLayout150.json`. 탐색에 들어갈 때만 받음(별도 청크).

## 판단한 것 (확인받을 것)
1. **탈퇴로 빈 번호 (디자이너가 의견을 물음)**: 제안(가장 작은 빈 번호부터 재사용)에 동의. 다만 **30일 동안은 빈 자리로 두고** 그 뒤 재사용을 제안. 이웃들이 익숙한 자리에 바로 낯선 사람이 들어오면 헷갈리고, 단골은 사람 기준이라 영향이 없음. 구역 수는 "가장 큰 배정 번호" 기준으로 켜야 빈 번호가 있어도 구멍이 잘리지 않음 (목 데이터: 서울-2층 7·31번, 서울-3층 20번이 빈 자리)
2. **배정 안 된 자리 = 빈 자리(empty_pad)로 보여 줌** (구멍을 안 만드는 쪽도 허용됐음). 켜진 구역이 비어 보이지 않고 "아직 올 사람 자리"로 읽힘
3. **다른 들판에서 두더지 처음 위치**: 그 들판엔 내 구멍이 없으니 가장 작은 번호 구멍. 구멍이 하나도 없으면 사다리 옆 흙 위
4. **안내판 위치**: 03 디자인처럼 두더지 머리 왼쪽 위. 내 구멍에서는 "내 땅굴 · 서울-2층 · 13번 자리 / 내 땅굴 들어가기"
5. **추천 대상**: 이번 학기 모든 들판의 사람(지금 보는 들판과 관계없음, 명세 그대로). 같은 점수는 날짜 시드로 섞음
6. **오른쪽 카드에 "땅굴 들어가기" 버튼 없음**: 명세 화면에 없어서 뺌. 들어가기는 안내판·Enter
7. **선택 하이라이트**: 마우스를 올린 구멍 = 흰 링 + 이름표(접속 중이면 초록 점), 이동 목표 = 노란 링
8. **시작 화면 둘러보기(`LookAround`)와 랜딩은 예전 밭(`fieldScene.ts`)을 그대로 씀**. 이번엔 탐색 화면만 바꿈
   - 다른 컴퓨터에서 11-13에 하던 탐색 작업(걷기·줌·굴로 들어가 이웃 굴로 이동, `docs/field-move.md`, 커밋 0601249)과 합칠 때 **탐색 화면은 이번 구현으로** 둠. 디자이너 v3.8 이 "걷기 이동·표지판 충돌·줌아웃은 보류, 구멍 점프로 대체"라고 정했기 때문. 그 작업의 `fieldScene.ts` 변경은 시작 화면용으로 그대로 남아 있고, 방문자 뷰 말풍선(집주인 머리 위)·`RoomModeToggle onPick` 등은 함께 살림. 땅굴 위치 아이디어(`docs/burrow-location-design.md`)의 "층 = 밭" 방향은 v3.9 와 같고, 자리 배치는 v3.9 가 정한 "온보딩 완료 순서"를 따름(관심사 동네 안은 쓰지 않음)
9. **목 데이터**: 서버가 없어서 들판마다 사람·자리를 시드로 만듦(`app/src/data/field.ts`). 실명 목 사용자는 서울-2층 1·2·6·9·12·14번, 나는 13번(디자이너 예시와 같은 자리)

## 확인한 것
- `tsc -b`, `npm run build` 통과
- 헤드리스 크롬(1440×960) 스크린샷: 첫 화면(내 구멍 분홍 링·후광), 방향키 → 옆 구멍, 구멍 클릭 → 점프, Enter → 그 사람 땅굴, 안내판, 추천 설정 → 결과 → 카드 뒤집기, 캠퍼스-층 고르기 → 빈 들판, 단골 목록, 저사양(`?gpu=software`, 점프 중 약 58fps), 방문자 뷰 단골 추가
