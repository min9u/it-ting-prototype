# 시작 화면 로딩 정리 (2026-11-12)

## 요청
"사이트에 처음 들어가면 그림이 떴다가 사라지고, 다시 가구가 3D로 뜬다. 가구가 나오기 전에 가구 라벨이 먼저 나온다. 번잡하다.
'고른 관심사가 가구가 돼요…' 문장은 남기고, 화면 세팅이 다 끝나기 전까지는 로딩 애니메이션을 보여 달라."

## 원인
- `RoomView`가 3D 준비 전에 자리표시 그림(room-v2.webp)을 보여 주다가, 캔버스가 **만들어지자마자**(모델을 받기 전) 그림을 치움 → 빈 화면 → 모델이 뜸
- 그 뒤 천장 구멍·두더지 낙하·가구 낙하가 차례로 나옴
- 가구 이름표는 3D와 상관없이 0.3초부터 뜸

## 한 것
- `roomScene`: `SceneHandle.loaded` (모델을 다 받고 첫 그림을 그린 뒤 풀림, 실패해도 풀림), `still` 옵션 (천장 구멍·두더지·가구 낙하 없이 다 차려진 방)
- `RoomView`: `loader` 옵션. 다 차려질 때까지 자리표시 그림 대신 **흙더미에서 고개를 내민 두더지(벡터 SVG, 머리만 통통) + 흙 부스러기 애니메이션 + "땅굴 파는 중..."**, 다 되면 3D를 0.6초 페이드 인. 리액션 버튼도 그 뒤에. WebGL이 없어 3D를 못 만들면 8초 뒤 자리표시 그림
- `Landing`: `still loader`, 가구 이름표는 방이 뜬 뒤 0.08초 간격으로. 왼쪽 문장은 처음부터 그대로
- 모션 줄이기면 로딩 그림은 멈춰 있음
- ~~다른 화면은 그대로~~ → 같은 날 사용자 요청으로 **모든 땅굴 화면(내 땅굴·남의 땅굴·온보딩 미리보기·둘러보기)도 로딩 애니메이션이 기본** (`RoomView loader` 기본 true). 시작 화면만 still(연출 없음), 나머지는 3D가 뜬 뒤 천장 구멍·두더지 낙하 연출 그대로. version 26
