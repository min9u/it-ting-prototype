## 한 일
### 1. 두더지 기본 상태 (`three/moleActor.ts`, `three/roomScene.ts`)
- 내 땅굴: 천장에서 떨어져 → 한 번 두리번 → 1.4초 뒤 걸어가 **노랑 방석(`sit_point_cushion_02`)에 앉음**. 방석 앞 걸어오는 시작점(-0.68, 0.65)까지 가서 방석을 보고 → 앉기 동작에서 몸을 돌려 카메라를 봄. 앉은 상태는 `mole_sit_idle` 반복(기존 `SIT.cushion`)
- 낙하 연출이 없을 때(정지 그림·동작 줄이기)는 처음부터 앉은 자세 (`sitHomeNow`)
- 동작 버튼: 앉아 있으면 **일어나 → 방석 앞으로 → 카메라를 보고 동작(인사·두리번·헛발질) → 다시 앉기**. 커피는 기존 그대로 앉은 채 마심(`drinkStep` 의 앉은 자세)
- 걷다가 멈추면 5초 뒤 방석으로 돌아와 앉음 (클릭·방향키·가구 클릭 모두. 다른 가구에 앉아 있으면 그대로)
- 방문자 뷰: 집주인 = 노랑 방석(처음부터 앉음), 손님 = 하늘 방석(`sit_point_cushion_01`)에 앉음. 인사하면 둘 다 일어나 마주 보고 인사 → 5초 뒤 각자 방석으로. **VisitBurrow.tsx · RoomView.tsx 는 안 고침** (roomScene 안에서 끝남 → "#3 머지 후" 남는 것 없음)
- 새 API (`MoleActor`): `setHome(node)` · `sitHome()` · `sitHomeNow()` · `isSeated()`. 앉는 가구 노드 → 자리 계산을 `seatPlace`/`seatSteps` 한 곳으로 빼고 `interact`(방석 클릭)도 같이 씀

### 2. 길 찾기 · 발자리
- 원탁 발자리를 네모(±0.86)로 막으면 **방석 앞 걸어오는 시작점이 막힌 곳**이 되어 두더지가 못 들어가고 원탁 둘레를 한 바퀴 도는 버그가 있었음(반려동물 방에서 재현) → 원탁만 **십자 모양 네모 둘**(모서리를 잘라 둥근 몸 반지름 원에 가깝게)로. 침대·협탁 발자리는 카탈로그에서 이미 빠짐
- 걷기 시험 (`tools/room-path/walk-check-v38.mjs`, 개발 서버 기준, 가속 켬): 관심사 A·B·C 방에서 바닥 시험 점 10개(장애물 안 점은 건너뜀) 걷기
  | 방 | 시험 경로 | 도착 오차 8cm 안 | 가구·동물 네모 안으로 1cm 넘게 들어간 적 | 처음 앉음 | 걷고 난 뒤 방석 복귀 |
  |---|---|---|---|---|---|
  | A 작은 소품 위주 | 9 | 9 | 0 | O | O (7.6초) |
  | B 큰 모델 여러 개 | 7 | 7 | 0 | O | O (7.6초) |
  | C 반려동물 포함 | 7 | 7 | 0 | O | O (7.6초) |
  - 앉아 있다 일어나는 동안 방석 네모 안에서 시작하는 것은 시험에서 뺌(앉는 가구라서 당연)
  - 못 한 것: 동물 모델 몸과의 거리를 모델 단위로 잰 것은 아님(발자리 네모 + 몸 반지름 기준), 앉은 몸 ↔ 원탁 겹침은 눈으로만 봄(겹침 없음)

### 3. 카메라 구도 (`three/roomFrame.ts`, `three/stills.ts`)
- 문제: 앞쪽 바닥 반려동물 자리(pet_slot 01~05 · prop_slot 15~19)가 아래 버튼 줄(y ≥ 885) · 이펙트 버튼 · 오른쪽 정보 패널(x ≥ 1068)에 가림
- 슬롯 좌표를 같은 카메라로 투영해서 숫자를 정함: `ROOM_FRAME { h 1.0 → 0.89, top -0.06 → -0.053 }`. **돔 꼭대기 화면 위치는 그대로**, 가상 화면만 11% 줄여 바닥 앞쪽이 위로(맨 앞 자리 y 904 → 812), 양옆이 안으로(맨 오른쪽 소품 x 1122 → 1063) 들어옴. 카메라 위치·시선은 안 바꿈(스펙 카메라 그대로)
- 시험: `tests/room-frame.test.ts` (stills.ts 의 따로 적은 값과 같은지 + 반려동물 자리 10개가 버튼 줄·패널에 안 걸리는지)
- 알림: `ROOM_FRAME` 은 시작 화면(Landing `PIN_BOX`)·`RoomView` 자리표시 그림도 같이 씀 → 그쪽도 같은 비율로 줄어듦. 랜딩 방 구간은 이번에 눈으로 확인 못 함

### 4. roomStyle 침대·협탁 정리
- `three/roomStyle.ts`: `shapeBed` · `shapeNightstand` · `headShape` · `linkClone`(침대 베개용) 삭제, SHAPERS 에서 뺌
