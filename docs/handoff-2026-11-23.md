## 새 컴퓨터 설정
1. 저장소: `git clone https://github.com/min9u/it-ting-prototype.git` → Node 24.18 (`app/.nvmrc`, `frontend/.nvmrc`) → `cd app && npm ci`, `cd frontend && npm ci`
2. 확인: `frontend/`에서 `npm run dev`(http://localhost:3000, 실험실 켜짐) · `npm test` · `npm run build`. 자세한 것은 `frontend/README.md`
3. GitHub CLI: `brew install gh` → `gh auth login -h github.com -p https -w -s admin:ssh_signing_key` (Git 인증도 gh 로)
4. **커밋 서명** (팀 `dev` · `main`은 서명 커밋만 병합. 키는 컴퓨터마다 따로):
   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_signing -C "commit signing"   # 별도 터미널, 비밀번호 권장
   ssh-add --apple-use-keychain ~/.ssh/id_ed25519_signing                    # 맥: 키체인에 저장
   echo 'ssh-add --apple-load-keychain -q 2>/dev/null' >> ~/.zshrc           # 재부팅 뒤 자동으로
   git config --global gpg.format ssh
   git config --global user.signingkey ~/.ssh/id_ed25519_signing.pub
   git config --global commit.gpgsign true
   echo "<GitHub 인증 이메일> $(cat ~/.ssh/id_ed25519_signing.pub)" > ~/.ssh/allowed_signers
   git config --global gpg.ssh.allowedSignersFile ~/.ssh/allowed_signers
   gh ssh-key add ~/.ssh/id_ed25519_signing.pub --type signing --title "<컴퓨터 이름> commit signing"
   ```
   푸시한 커밋이 GitHub에서 Verified인지 확인 (`gh api repos/min9u/it-ting-prototype/commits/<sha> --jq .commit.verification`)
5. 맥이면 긴 작업 동안 덮개를 열고 전원 연결 (절전되면 작업이 끊김. 원래 컴퓨터에서 하루 세 번 끊겼음)
