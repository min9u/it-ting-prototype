# 모임 카테고리 6개 · 플랫폼 이름 삭제 (2026-11-22)

**요청**: "모임 분류를 관심사에서 명세 07의 모임 카테고리 6개로 바꿔 … 모임 만들기에서 플랫폼 이름 칸 삭제(명세 07, D4로 결정). M16 기록은 '명세로 뒤집힘'으로." 브랜치 `feat/meetup-category`.

## 결론
- **카테고리** (명세 07 리스트 3 · 만들기 4 · "카테고리"): 취미/문화 · 식사/카페 · 스터디/프로젝트 · 기타 · 게임 · 운동. 모임 전용 분류로 **관심사와 관계없음**, 모임 하나에 하나(필수). 카드 색·표지판·캘린더 라벨 색을 정함. 표는 `app/src/data/meetupCategory.ts` 한 곳(이름·색·서버 코드 제안).
- **플랫폼 이름 칸 삭제** (만들기 3): 온라인은 접속 링크(선택)만. 모임에 캠퍼스·플랫폼 이름을 두지 않음.
- M15(대표 관심사 1개 + 태그 3개) · M16(플랫폼 필수)은 [meetup-spec-review.md](meetup-spec-review.md)에서 "명세로 뒤집힘"으로 표시.

## 바뀐 곳
| 영역 | 내용 |

| 만들기 | "대표 관심사" 고르기 → 카테고리 6개 칩, 온라인 "플랫폼" 칸 삭제, 필수값 안내·미리보기 |

## 명세·Figma 차이 (명세를 따름)
- Figma 목록·만들기 시안은 스터디·프로젝트를 나눠 7칸이고 구분자가 "·"(취미 · 문화). 명세는 6개, "/" 표기 → 명세.
- Figma 만들기에 온라인 플랫폼 칩이 있음(옛 시안) → 명세대로 삭제.
- 카테고리별 색 값이 명세·Figma에 없음 → 기존 톤 토큰으로 지정(취미/문화 butter, 식사/카페 mint, 스터디/프로젝트 clay, 기타 sand, 게임 lilac, 운동 sage). **디자이너 확인 필요**.
