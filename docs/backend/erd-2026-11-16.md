# 디굴디굴 ERD (백엔드, 2026-11-16 기준)

- 출처: 백엔드 ERD 아티팩트 https://claude.ai/artifact/7FjN8K7G19QL2Z1z5txs2n (원본 표기 "docs/db 2026-11-16 기준", 테이블 38개)
- 페이지 스크립트의 데이터를 그대로 표로 옮김. 프론트 쪽 해석·질문은 [api-draft.md](api-draft.md), [erd-gaps.md](erd-gaps.md)에
- 표기: PK 기본 키 · UQ 유일 · ? 비어 있을 수 있음 · 1:1 = 대상 하나에 최대 한 줄 · (FK 아님) = 문서에 FK로 적지 않은 참조 · 타입 빈칸 = 아직 안 정함
- enum 값(role, status, type, category, mode, reason 등)은 ERD에 없음 → 정해지면 받아야 함
