## 공통 (여러 영역)

1. **관심사 · 대분류에 바뀌지 않는 `code` 칼럼**(예: `cafe_coffee`, `OUTDOOR`)을 `GET /interest-categories` · 관심사 태그 · 글의 `interestCategoryId` 쪽에 실어 줄 수 있는지. 지금은 이름으로 잇고 있어 이름을 다듬으면 가구 · 아이콘이 사라진다. 커뮤니티 글 목록 · 글쓰기의 대분류 숫자 id 도 `GET /interest-categories` 의 id 를 쓰는 게 맞는지 — [온보딩 · 내 땅굴 1](00-01-03-04-onboarding-burrow.md#백엔드--팀에-물을-것), [커뮤니티 1](08-community.md#5-백엔드--팀에-확인할-것), [interest-enum.md](../interest-enum.md)
2. **모임 카테고리의 순서**: 관심사 · 질문은 닫음(아래 "닫은 것"). 모임 카테고리 enum 을 주는 순서가 명세 표 순서인지 — [모임 7](07-meetup.md#5-백엔드--팀에-물어볼-것)
3. **SSE 연결과 세션 연장**: `GET /me/event-stream` 이 계속 열려 있는 동안에도 "쓸 때마다 14일 연장"이 되는지 — [공통 계층 5장](../api-v1-foundation.md#5-명세에서-애매하거나-확인할-것)
4. **SSE 다시 연결 때 놓친 소식**: `Last-Event-ID` 로 다시 줄 계획이 있는지 (없으면 지금처럼 다시 조회) — [채팅 7](06-chat.md#7-백엔드--팀에-물을-것)
5. **CORS · 쿠키**: 허용 출처 기본값 `http://localhost:3000`(Next.js 로 옮긴 뒤와 맞음), `Secure` 세션 쿠키를 개발에서는 `localhost` 로만 받는 것으로 둬도 되는지 — [공통 계층 5장](../api-v1-foundation.md#5-명세에서-애매하거나-확인할-것)
6. **사진 올리기(`POST /images`) 실패 모양**: 형식 · 크기 위반이 `400 INVALID_INPUT` + `fields[{field:'file'}]` 인지, 너무 큰 파일을 프록시가 `413` 으로 끊을 수 있는지. 프론트가 JPEG · PNG · WebP · 5MB 를 미리 막아도 되는지 (커뮤니티 글쓰기와 채팅 첨부가 같은 API) — [커뮤니티 2](08-community.md#5-백엔드--팀에-확인할-것), [채팅 5](06-chat.md#7-백엔드--팀에-물을-것)

## 02 인증 · 10 설정

1. **Google 콜백 뒤 프론트 주소**: 로그인됨 `/auth/google`, 처음 쓰는 계정 `/signup/ssafy?via=google`, 로그인 못 함 `/login?error=<code>`, 연동 확인 `/settings/google?verified=true`, 탈퇴 인증 `/settings/leave`, 실패 `<시작 화면>?error=<code>` 로 맞춰 줄지 — [인증 · 설정 4장 1](02-10-auth-settings.md#4-애매해서-정한-것)
2. **Google 로그인 취소의 code 이름** (목은 `GOOGLE_LOGIN_CANCELED`) — [4장 2](02-10-auth-settings.md#4-애매해서-정한-것)
3. **정지 계정의 Google 로그인**: 사유 · 기간을 `/login?error=ACCOUNT_SUSPENDED&reason=…&endsAt=…` 쿼리로 주는지 — [4장 3](02-10-auth-settings.md#4-애매해서-정한-것)
4. **재설정 메일 속 링크** 주소를 `/password-reset/new?token=<token>` 으로 만들어 주는지 — [4장 4](02-10-auth-settings.md#4-애매해서-정한-것)
5. **웹 푸시 내용 모양**: 서비스 워커는 `{ title, body, url }` JSON 으로 가정 — [4장 8](02-10-auth-settings.md#4-애매해서-정한-것)
6. `GET /oauth/google/verify` 를 세션 없이 열면 `/login` 으로 보낼 텐데, 로그인 뒤 설정으로 돌려보낼지 — [5장](02-10-auth-settings.md#5-백엔드--팀에-물을-것)
7. 서비스 워커 `/push-sw.js` 를 배포 경로 맨 위에 둬도 되는지 (Nginx, 범위 `/`) — [5장](02-10-auth-settings.md#5-백엔드--팀에-물을-것)
8. 회원가입 3 을 Google 가입으로 열었는데 가입 진행 기록이 없으면(`SIGNUP_EXPIRED`) 로그인 화면으로 보내는 게 맞는지 — [5장](02-10-auth-settings.md#5-백엔드--팀에-물을-것)

## 06 채팅

1. **메시지 멱등 키**: "다시 보내기"로 두 번 저장될 수 있다. 요청에 `clientMessageId` 를 받아 같은 값이면 한 번만 저장하고 응답 · 소식에 돌려줄 수 있는지 — [채팅 7장 1](06-chat.md#7-백엔드--팀에-물을-것)
2. **모임 링크 모양**: 서버가 본문에서 알아보는 링크가 `https://<도메인>/meetups/{id}` 뿐인지, 해시 라우팅 `/#/meetups/{id}` 도인지 — [7장 2](06-chat.md#7-백엔드--팀에-물을-것)

## 07 모임

1. 리스트 카드에 `isLiked` 가 없어 카드의 하트를 뺐다. 리스트에서 찜하려면 필요 — [모임 5장 1](07-meetup.md#5-백엔드--팀에-물어볼-것)
2. 상세에 내 신청 메시지가 없다 (신청 대기 카드의 "주최자에게 남긴 말"). 필요하면 `myApplication.message` — [5장 2](07-meetup.md#5-백엔드--팀에-물어볼-것)

4. 신청 관리 팝업을 알림(F9 "모임 참여 요청")에서도 여는지. 알림 팝업 API 가 신청이 온 모임 id 를 주지 않아 지금은 늘 내 모임 › 내가 연 모임 탭으로 — [5장 4](07-meetup.md#5-백엔드--팀에-물어볼-것), [알림 1](09-notification.md#백엔드--팀에-물을-것)
