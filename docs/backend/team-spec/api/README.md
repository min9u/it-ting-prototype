## 문서를 쓰는 법

[템플릿](_template.md)을 복사해 `docs/api/<번호>-<영역>.md`로 저장한다. API마다 아래 절을 이 순서로 쓴다. 이 문서만 읽고 프론트엔드와 백엔드가 같은 것을 만들 수 있을 만큼 적는다.

| 절 | 적는 것 | 쓰는 API |
|---|---|---|
| 첫 문단 | 하는 일, 어느 화면이 언제 부르는지, 로그인이 필요한지, 명세의 어느 화면 · 항목을 처리하는지 | 모두 |
| 요청 | 받는 값의 위치 · 이름 · 타입 · 필수 여부 · 길이와 범위, 실제 값으로 채운 요청 예시 | 모두 |
| 서버가 하는 일 | 검사하는 순서와 그때의 에러, 저장하는 테이블과 칼럼, 함께 일어나는 일(메일 보내기, 세션 만들기) | 데이터를 바꾸는 API |
| 응답 `data` | 주는 값의 이름 · 타입 · 설명 · 값이 오는 곳 | 모두 |
| 주는 방식 | 어떤 줄을 주고 빼는지, 순서, 한 번에 주는 개수 | 조회하는 API |
| 응답 예시 | 응답 틀까지 넣은 실제 JSON | 모두 |
| 에러 | 공통 에러 코드가 아닌 것의 상태 코드, `code`, 때 | 모두 |

- 명세에 없는 것을 정했으면 문서 끝의 "명세에 없어 이 문서에서 정한 것"에 적는다.
- 영역 전체에 걸친 약속(예: 가입 단계, 저장하는 때)은 "영역 규칙"에 한 번만 적는다.

### 값이 오는 곳

응답의 값마다 어디서 오는지를 적는다. API가 주는 값이 모두 DB 칼럼은 아니다([DB 설계 원칙](../db/README.md)).

| 적는 법 | 뜻 | 예 |
|---|---|---|
| `테이블.칼럼` | DB에 저장된 값을 그대로 준다 | `user_profile.nickname` |
| 계산: … | 저장하지 않는다. 서버가 응답을 만들 때 저장된 값에서 계산한다 | `isShared`, `isCurrent`, `nextStep` |
| 서버 설정 | DB가 아니라 서버의 설정에 있는 값이다 | 기수 목록 |
| 임시 저장소 | Redis에 잠깐 두는 값에서 온다 | 인증 코드의 만료 시각 |

그림, 안내 문구, "3분 전" 같은 화면 표현은 API가 주지 않는다. 프론트엔드가 갖는다.
