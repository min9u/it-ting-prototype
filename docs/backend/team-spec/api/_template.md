## <메서드> <주소>

<이 API가 하는 일과, 어느 화면이 언제 부르는지를 한두 문장으로 쓴다.>

- 로그인: 필요 / 불필요
- 명세: <화면 이름> <항목 번호>

### 요청

타입은 숫자, 문자열, enum, 참/거짓, 시각, 날짜, 객체, 목록 가운데 하나를 쓴다. 파일을 올리는 API만 위치에 폼, 타입에 파일을 쓴다. enum은 설명에 가능한 값을 모두 적는다. 객체나 목록 안의 값은 `mole.head`, `answers[].answer`처럼 경로로 적는다. 받는 값이 없으면 "없다."라고 쓴다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|---|
| 경로 | `<이름>` | 숫자 | ✓ | <설명> |
| 쿼리 | `<이름>` | enum | | `<값 1>`, `<값 2>` 가운데 하나. 보내지 않으면 <기본 동작> |
| 본문 | `<이름>` | 문자열 | ✓ | <설명과 길이 · 범위> |

```text
<메서드> <쿼리까지 넣은 실제 주소>
```

```json
{ "<이름>": "<본문이 있으면 실제 값으로 채운 예>" }
```

<데이터를 바꾸는 API에만 쓴다. 검사하는 순서, 저장하는 테이블과 칼럼, 함께 일어나는 일을 번호로 적는다. 앞 번호에서 걸리면 뒤 번호는 하지 않는다.>

1. <검사와 그때 답하는 에러 코드>
2. <저장하는 테이블과 칼럼>

### 응답 `data`

<성공했을 때의 상태 코드가 `200`이 아니면 먼저 쓴다. 돌려줄 값이 없으면 "`null`이다."라고 쓴다.>

| 이름 | 타입 | 설명 | 값이 오는 곳 |
|---|---|---|---|
| `<이름>` | 숫자 | <설명. 값이 없을 수 있으면 언제 `null`인지> | `<테이블>.<칼럼>` |
| `<이름>` | 참/거짓 | <설명> | 계산: <무엇에서 어떻게 계산하는지> |
