## 모임 – 리스트

- 들어오는 곳: GNB “모임”
- 나가는 곳: 카드 → [모임 상세](#모임--상세) / 모임 만들기 → [모임 만들기](#모임--만들기) / 전체 보기 → [내 모임](#모임--내-모임) / 캘린더로 보기 → [캘린더 팝업](#모임--캘린더-팝업) / 날짜 › 직접 설정 → [날짜 필터](#모임--리스트--날짜-필터)
- 공통: [00 공통](00-common.md) 1 GNB, 3 푸터, 7 빈 상태

1. **모임 만들기**: 모임 만들기 화면으로 이동한다.
2. **검색**: 모임 이름과 소개 글에서만 찾는다. 카테고리는 검색하지 않고 카테고리 필터로 고른다. 입력하면 목록이 바로 바뀐다.
3. **카테고리 필터**: 카테고리는 모임 전용 분류이고 관심사와 관계없다. 모임 하나는 카테고리 하나를 가진다. 목록: 취미/문화, 식사/카페, 스터디/프로젝트, 기타, 게임, 운동. “전체”를 고르거나 카테고리를 여러 개 골라 목록을 좁힌다.
4. **날짜 · 방식 · 정렬**:
   - 날짜: 전체(기본) / 오늘 / 이번 주 / 이번 주말 / 직접 설정.
   - 방식: 전체(기본) / 오프라인 / 온라인.
   - 정렬: 가까운 날짜순(기본) / 최신등록순 / 인기순(찜이 많은 순) / 인원순(참여 확정 인원이 많은 순).
   - 검색, 카테고리, 날짜, 방식은 함께 적용된다. 캠퍼스로는 거르지 않는다.
5. **모임 카드 목록**: 3열 카드. 상태 배지, 표지판, 카테고리, 제목, 일시, 장소(방식), 인원을 보여준다. 카드 색과 표지판은 카테고리 색을 따른다. 인원은 주최자를 포함한 확정 인원 / 정원(예: 4 / 6명). 상태 배지는 모집 중 / 모집 완료 두 가지다. 모집 완료는 흐리게 하고 맨 뒤에 둔다. 지난 모임과 취소된 모임은 보이지 않는다(내 모임에서만 본다). 카드를 누르면 모임 상세로 이동한다.
6. **페이지 이동**: “N개씩 보기”로 6 / 12 / 24개 중 고른다(기본 6개). 이전 · 다음과 페이지 번호로 이동한다.
7. **내 모임 위젯**: 내가 참여 · 신청 · 주최한 모임 요약. 상태 배지는 참여 확정 / 신청 대기 / 내가 주최. “전체 보기”는 내 모임으로 이동한다.
8. **다가오는 일정**: 내 모임 중 가까운 일정(날짜, 제목, 시간 · 장소, D-day). 누르면 모임 상세로 이동한다. “캘린더로 보기”는 캘린더 팝업을 연다(기본 보기: 내 모임).

## 모임 – 리스트 · 정렬 열림

- 들어오는 곳: 모임 리스트의 “정렬”
- 나가는 곳: 값을 고르면 닫히고 목록 순서가 바뀐다
- 공통: 화면의 나머지는 [“모임 – 리스트”](#모임--리스트)와 같다

1. **정렬 드롭다운**: 누르면 목록이 열리고, 바깥을 누르면 닫힌다. 지금 적용된 값을 보여준다. 방식 드롭다운(전체 / 오프라인 / 온라인)도 같은 방식으로 열린다.
2. **정렬 값**: 가까운 날짜순(기본) / 최신등록순 / 인기순 / 인원순. 값의 뜻은 [“모임 – 리스트”](#모임--리스트)의 “날짜 · 방식 · 정렬”과 같다. 고르면 바로 적용된다. 어떤 정렬이든 모집 완료는 맨 뒤에 둔다.

## 모임 – 리스트 · 개수 보기 열림

- 들어오는 곳: 모임 리스트 아래의 “N개씩 보기”
- 나가는 곳: 값을 고르면 닫히고 목록이 바뀐다
- 공통: 화면의 나머지는 [“모임 – 리스트”](#모임--리스트)와 같다

1. **N개씩 보기**: 한 페이지에 보여줄 모임 수를 고른다. 지금 값을 버튼에 보여준다.
2. **개수 값**: 6개(기본) / 12개 / 24개. 고르면 바로 적용되고 1페이지로 돌아간다.

## 모임 – 리스트 · 날짜 필터

- 들어오는 곳: 모임 리스트의 “날짜”
- 나가는 곳: 값을 고르면 닫히고 목록이 바뀐다 / 직접 설정 → [날짜 직접 설정](#모임--리스트--날짜-직접-설정)
- 공통: 화면의 나머지는 [“모임 – 리스트”](#모임--리스트)와 같다

1. **날짜 드롭다운**: 누르면 목록이 열리고, 바깥을 누르면 닫힌다. 지금 적용된 값을 드롭다운에 보여준다.
2. **빠른 선택**: 전체(기본) / 오늘 / 이번 주 / 이번 주말. 고르면 바로 적용된다. 이번 주는 오늘부터 이번 주 일요일까지, 이번 주말은 이번 주 토요일과 일요일이다.
3. **직접 설정**: 달력을 열어 기간을 고른다(날짜 직접 설정).

## 모임 – 리스트 · 날짜 직접 설정

- 들어오는 곳: 날짜 필터의 “직접 설정”
- 나가는 곳: 적용 → 달력이 닫히고 목록이 바뀐다 / 바깥을 누르면 적용하지 않고 닫힌다
- 공통: 화면의 나머지는 [“모임 – 리스트”](#모임--리스트)와 같다

1. **달 이동**: 이전 달과 다음 달로 넘긴다. 처음 열면 이번 달을 보여준다.
2. **기간 고르기**: 처음 누른 날이 시작일, 다음에 누른 날이 끝나는 날이 된다. 하루만 보려면 같은 날을 두 번 누른다. 오늘보다 앞선 날은 고를 수 없다(지난 모임은 리스트에 나오지 않는다). 고른 기간을 달력 아래에 글로 보여준다.
3. **초기화 / 적용**: 적용을 누르면 모임 날짜가 고른 기간 안에 있는 모임만 보여주고, 드롭다운에 기간(예: 11.14 ~ 11.20)을 표시한다. 기간을 고르기 전에는 적용이 꺼져 있다. 초기화는 고른 기간을 지우고 “전체”로 돌아간다.

## 모임 – 상세

- 들어오는 곳: 모임 리스트 · 내 모임 · 캘린더 팝업의 모임 / [모임 알림](09-notification.md) / 공유 링크 / [채팅](06-chat.md)의 모임 카드 · 모임 정보 팝업 / [커뮤니티](08-community.md) 글의 모임 카드 / 모임 생성 완료 팝업의 “모임 보러 가기”
- 나가는 곳: 참여 신청하기 → [신청 대기](#모임-상세--상태-신청-대기) / 모임 대화 미리보기(확정자 · 주최자) → [모임 대화(F6)](06-chat.md) / 브레드크럼 → [모임 리스트](#모임--리스트)
- 공통: [00 공통](00-common.md) 1 GNB, 3 푸터, 4 사용자 표시, 5 관심사 태그, 15 프로필 팝업, 16 완료 토스트

1. **브레드크럼 · 카테고리 · 모집 상태**: 브레드크럼(모임 / 카테고리)과 카테고리 칩, 모집 상태 배지를 보여준다. 모집 상태는 모집 중(남은 자리 표시) / 모집 완료 / 지난 모임 / 취소됨. 정원이 차거나 모집 마감 시각이 지나면 모집 완료, 모집 마감 전에 자리가 나면 다시 모집 중, 시작 시각이 지나면 바로 지난 모임으로 바뀐다. 오른쪽 행동 카드는 내 상태(미신청 / 신청 대기 / 미승인 / 참여 확정 / 주최자)에 따라 바뀌고, 달라지는 내용은 [“모임 상세 – 상태” 화면들](#모임-상세--상태-표)에 적는다. 이 화면은 미신청 상태다.
2. **공유 · 찜**: 공유는 모임 링크를 복사한다. 로그인하지 않은 사람이 링크를 열면 [로그인 화면](02-auth.md)으로 보내고, 로그인하면 이 모임 상세로 온다. 하트는 찜을 켜고 끈다(내 모임 › 찜한 모임). 찜한 모임은 빈자리 알림을 받을 수 있다(내 모임 › 찜한 모임).
3. **대표 이미지**: 모임 이름, 일시, 장소가 적힌 표지판 그림.
4. **모집 현황**: 참여가 확정된 두더지와 빈자리를 좌석으로 보여준다. 정원에는 주최자가 포함되어 주최자가 첫 자리를 차지한다(정원 6명 = 주최자 1명 + 참여자 5명). 나와 관심사가 겹치는 두더지 수를 함께 보여준다.
5. **주최자에게 남길 말**: 선택 입력. 신청할 때 함께 전달한다. 주최자가 메시지를 받지 않기로 했으면 숨긴다.
6. **참여 신청하기**: 누르면 신청이 접수되고 신청 대기 상태로 바뀐다. 모집 마감 일시를 정한 모임만 마감 안내를 보여준다. 정원이 찼거나 마감됐으면 끈다. 모집 마감 시각까지 주최자가 처리하지 않은 신청은 자동으로 미승인된다(마감 일시가 없으면 모임이 시작될 때). 정원이 차도 기다리던 신청은 그대로 남고, 자리가 나면 주최자가 수락할 수 있다. 스스로 신청을 취소한 경우에만 다시 신청할 수 있다. 확정 후 참여를 취소했거나 내보내진 사람에게는 버튼 자리에 “이 모임에는 다시 신청할 수 없어요”를 보여주고, 거절되거나 자동으로 미승인된 사람에게는 미승인 카드(“참여가 어려워요”)를 보여준다. 신청 기록의 상태는 신청 대기 / 신청 취소 / 미승인 / 참여 확정 / 참여 취소 / 내보내짐 / 모임 취소로 마감 일곱 가지다([상태 표](#모임-상세--상태-표)).
7. **모임 소개**: 주최자가 적은 소개 글.
8. **모임 정보**: 언제 / 어디서(오프라인은 장소) / 어떻게(오프라인 · 온라인) / 정원(확정 인원 / 정원, 주최자 포함) / 준비물. 온라인 모임의 접속 링크는 참여 확정자에게만 보인다.
9. **모임 대화 미리보기**: 참여 확정자와 주최자에게는 모임 대화의 최근 메시지 3개를 보여주고, 누르면 [모임 대화(F6)](06-chat.md)로 이동한다. 상세에서는 읽기만 하고 입력은 모임 대화에서 한다. 그 밖의 사람(미신청 · 신청 대기 · 미승인)에게는 같은 자리를 흐리게 가리고 “참여가 확정되면 모임 대화를 볼 수 있어요”를 보여준다. 가려진 상태에서는 실제 메시지 내용을 내려보내지 않는다. 이 화면은 가려진 상태다.

표 아래에 적힌 글:

- 위 표는 보는 사람의 상태, 아래 표는 모임의 모집 상태다(Figma에서는 한 표의 위 다섯 줄과 아래 세 줄이다).
- 모집 상태가 모집 완료 · 지난 모임 · 취소된 모임이면 미신청인 사람에게 아래 표의 카드를 보여준다.
- 모임 대화 미리보기는 참여 확정자와 주최자에게만 보이고 그 밖에는 가려진다(“모임 – 상세” 10).
- 화면마다 달라지는 내용은 각 상태 프레임에 있다.
- 신청 기록의 상태는 일곱 가지다: 신청 대기 / 신청 취소(다시 신청 가능) / 미승인(거절 · 자동, 미승인 카드, 다시 신청 불가) / 참여 확정 / 참여 취소(다시 신청 불가) / 내보내짐(다시 신청 불가) / 모임 취소로 마감(신청 대기 중 모임이 취소됨, 다시 신청 불가).

### 상태 화면에 공통인 것

아래 “모임 상세 – 상태: …” 화면 9개에는 다음 내용이 똑같이 적혀 있다. 여기에 한 번만 적고, 각 화면에는 [“모임 – 상세”](#모임--상세)와 달라지는 것만 적는다.

- 들어오는 곳: 모임 상세를 열었을 때 내 상태나 모집 상태가 이 경우일 때
- 공통: 화면의 나머지는 [“모임 – 상세”](#모임--상세)와 같다 / 상태별 차이는 [“모임 상세 – 상태 표”](#모임-상세--상태-표)
- 1번 항목 **상태 표시**: “모임 – 상세” 1과 같다.

## 모임 상세 – 상태: 미신청

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)
- [“모임 – 상세”](#모임--상세)가 이 상태를 그린 화면이다. 아래 항목은 “모임 – 상세” 4 ~ 6에 적힌 내용의 일부이고, 새로 더해지는 내용은 없다.

2. **행동 카드**: 남은 자리, 참여 두더지, 나와 겹치는 관심사를 보여준다. 정원에는 주최자가 포함된다(“모임 – 상세” 4).
3. **주최자에게 남길 말**: 선택 입력(“모임 – 상세” 5).
4. **참여 신청하기**: 누르면 신청이 접수되고 “신청 대기” 상태로 바뀐다. 다시 신청할 수 있는 경우와 없는 경우, 그때 보여주는 것은 “모임 – 상세” 6과 같다.

## 모임 상세 – 참여 신청 완료 토스트

- 들어오는 곳: 모임 상세(미신청)의 “참여 신청하기”
- 나가는 곳: 신청 내역 보기 → [내 모임](#모임--내-모임)(신청 대기 탭) / 토스트가 사라지면 신청 대기 상태 화면
- 공통: [00 공통](00-common.md) 16 완료 토스트 / 화면의 나머지는 [“모임 상세 – 상태: 신청 대기”](#모임-상세--상태-신청-대기)와 같다

1. **완료 토스트**: 참여 신청하기를 누르면 화면이 신청 대기 상태로 바뀌고 “참여 신청이 완료되었습니다” 토스트가 뜬다. 뜨고 사라지는 방식은 [00 공통](00-common.md) 16을 따른다.
2. **신청 내역 보기**: 내 모임의 “신청 대기” 탭으로 이동한다.

## 모임 상세 – 상태: 신청 대기

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)

2. **행동 카드**: 주최자 확인을 기다리는 상태. 결과는 알림으로 알려 준다. 주최자가 모집 마감 시각까지 처리하지 않으면 자동으로 미승인되고 미승인 알림이 간다(마감 일시가 없으면 모임이 시작될 때). 정원이 차도 기다리던 신청은 그대로 남고, 자리가 나면 주최자가 수락할 수 있다. 승인되지 않으면 이 카드에 "아쉽게도 모임 참여가 승인되지 않았어요. 다른 모임을 둘러보세요."를 보여주고, 신청 취소 버튼은 없앤다(다른 버튼은 두지 않는다).
3. **신청 취소**: 누르면 확인 후 신청을 취소하고 “미신청”으로 돌아간다. 스스로 취소한 신청은 같은 모임에 다시 신청할 수 있다.

## 모임 상세 – 상태: 신청 대기 · 미승인

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)

2. **행동 카드 (미승인)**: 주최자가 신청을 거절했거나, 모집 마감 시각까지 처리되지 않아 자동으로 미승인된 상태. 신청자에게 미승인 알림이 가고, 카드 제목은 "참여가 어려워요", 안내는 "아쉽게도 모임 참여가 승인되지 않았어요. 다른 모임을 둘러보세요." 신청 취소 버튼과 마감 안내는 없애고 다른 버튼은 두지 않는다. 같은 모임에는 다시 신청할 수 없다.

## 모임 상세 – 상태: 참여 확정

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)

2. **행동 카드**: 참여가 확정된 상태.
3. **모임 대화 열기 / 참여 취소**: 모임 대화방으로 이동한다. 참여 취소는 확인을 거치고 주최자에게 알린다. [채팅](06-chat.md) 모임 정보 팝업의 “모임 나가기”와 같은 동작이라, 어느 쪽에서 하든 참여가 취소되고 모임 대화방에서도 빠진다. 시작 24시간 전까지만 할 수 있고, 그 뒤에는 버튼이 꺼지고 “주최자에게 모임 대화로 알려주세요”라고 안내한다. 확정 후 참여를 취소하면 같은 모임에 다시 신청할 수 없다.
4. **모임 대화 미리보기**: “모임 – 상세” 10과 같다. 참여 확정 상태라 최근 메시지 3개가 그대로 보이고, 누르면 [모임 대화(F6)](06-chat.md)로 이동한다.

## 모임 상세 – 상태: 주최자

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)

2. **행동 카드**: 주최자에게는 모임 대화 열기와 모임 수정 · 취소를 보여주고, 그 밖의 화면은 참여 확정 상태와 같다. 확정 인원(주최자 포함)을 함께 표시한다. 신청 관리는 상세에 두지 않고 내 모임 › 내가 연 모임에서만 한다.

4. **모임 대화 미리보기**: “모임 – 상세” 10과 같다. 주최자에게도 최근 메시지 3개가 그대로 보인다.

- 들어오는 곳 · 공통 · 1번 항목: [상태 화면에 공통인 것](#상태-화면에-공통인-것)

3. **모임 대화 열기 / 모임 수정 · 삭제**: 참여 확정자(주최자 제외)가 0명이면 '모임 수정 · 취소' 대신 '모임 수정 · 삭제'가 보인다. 누르면 [모임 수정](#모임-수정--취소) 화면으로 이동하고, 삭제는 [확인 팝업](#모임-수정--삭제-확인-팝업)을 거친다. 신청 대기자가 있어도 확정자가 0명이면 삭제할 수 있다.

2. **행동 카드**: 정원(주최자 포함)이 다 찬 상태. 신청할 수 없다. 자리가 나면 다시 모집 중이 된다.

3. **비활성 버튼**: 누를 수 없다.

## 모임 – 만들기

- 들어오는 곳: 모임 리스트 · 내 모임의 “모임 만들기”
- 나가는 곳: 모임 만들기 → [모임 생성 완료 팝업](#모임--모임-생성-완료-팝업) / 그만두기 → 이전 화면
- 공통: [00 공통](00-common.md) 1 GNB, 3 푸터, 18 저장 전 취소

1. **몇 명과 함께할까요**: 정원(− / +로 조정, 2~50명, 기본 6명, 주최자 포함: 정원 6명 = 주최자 1명 + 참여자 5명, 만들자마자 1명 확정), 준비물(선택), 신청할 때 메시지 받기(받을게요 / 안 받을게요). 안 받을게요를 고르면 모임 상세의 “주최자에게 남길 말”을 숨긴다.
2. **언제 만나요**: 달력에서 날짜를 고르고 시작 시간과 끝나는 시간(선택)을 정한다. 오늘 이후만 고를 수 있고, 끝나는 시간은 시작 시간보다 뒤여야 한다. 모집 마감 일시는 선택이고, 비우면 모임이 시작될 때까지 신청을 받는다. 정원이 차 있는 동안에는 새 신청을 받지 않는다.
3. **어디서 만나요**: 만나는 방식은 오프라인 / 온라인. 오프라인은 장소(주소 찾기 또는 직접 입력)와 상세 주소(선택)를 받는다. 온라인은 접속 링크(선택)를 받는다. 모임에는 캠퍼스와 플랫폼 이름을 두지 않는다. 링크는 참여 확정자에게만 보이고 모임 대화방에도 안내한다.
4. **무엇을 함께할까요**: 모임 이름(필수), 소개(선택), 카테고리(필수, 하나). 카테고리 목록은 [“모임 – 리스트”](#모임--리스트) 3과 같다. 내 관심사와 관계없이 고른다. 카테고리가 모임 카드 색, 표지판, 캘린더 라벨 색을 정한다.
5. **미리보기 카드**: 입력한 이름, 카테고리, 일시, 장소, 정원이 모임 카드에 어떻게 보이는지 바로 보여준다.
6. **그만두기 / 모임 만들기**: 필수값(모임 이름, 카테고리, 날짜, 시작 시간, 오프라인이면 장소)을 채워야 “모임 만들기”가 켜진다. 누르면 모임을 등록하고 모임 생성 완료 팝업을 띄운다. 모임 대화방은 이때 함께 만들어지고, 참여가 확정된 사람부터 들어온다. “그만두기”는 입력한 내용이 있으면 [00 공통](00-common.md) 18의 확인을 거치고, 내용은 저장하지 않는다.

## 모임 – 모임 생성 완료 팝업

- 들어오는 곳: 모임 만들기의 “모임 만들기”
- 나가는 곳: 모임 보러 가기 → [모임 상세](#모임--상세)(주최자)
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **완료 그림 · 안내**: 만든 모임 이름이 적힌 표지판 그림과 함께, 모임 탐색(모임 리스트)에 표지판이 올라갔다고 알려준다. [탐색 들판](05-explore-visit.md)에는 모임 표지판을 세우지 않는다.
2. **모임 요약**: 일시, 장소 · 방식, 정원(나를 포함).
3. **채팅방 안내**: 모임 대화방이 자동으로 만들어진다고 알려준다. 참여가 확정된 사람부터 들어온다.
4. **공유하기 / 모임 보러 가기**: 공유하기는 모임 링크를 복사한다([“모임 – 상세”](#모임--상세) 2와 같다). 모임 보러 가기는 만든 모임의 상세로 이동한다.

## 모임 – 내 모임

- 들어오는 곳: 모임 리스트 내 모임 위젯의 “전체 보기”
- 나가는 곳: 모임 → [모임 상세](#모임--상세) / 신청 관리 → [신청 관리](#모임--신청-관리) / 모임 수정 → [모임 수정](#모임-수정--취소) / 모임 채팅 → [모임 대화(F6)](06-chat.md) / 캘린더로 보기 → [캘린더 팝업](#모임--내-모임--캘린더-팝업) / 모임 만들기 → [모임 만들기](#모임--만들기)
- 공통: [00 공통](00-common.md) 1 GNB, 3 푸터, 7 빈 상태

1. **모임으로 돌아가기**: 모임 리스트로 돌아간다.
2. **상태 탭**: 다가오는 모임 / 신청 대기 / 내가 연 모임 / 찜한 모임 / 지난 모임. 다가오는 모임에는 참여가 확정된 모임과 내가 연 예정 모임이 들어간다. 신청 대기 중인 모임은 신청 대기 탭에만 있다가 주최자가 수락하면 다가오는 모임으로 옮겨진다. 내가 연 모임과 찜한 모임에는 시작하지 않은 모임만 들어간다. 내가 열었거나 참여가 확정됐던 모임은 시작하면 지난 모임으로 옮겨진다. 그런 모임이 취소되면 시작 전이라도 바로 지난 모임에 “취소됨”으로 남는다. 신청 대기 중에 취소된 모임은 내 모임에 나오지 않는다. 탭 옆 숫자는 개수. 지난 모임은 기록으로만 보고 지울 수 없다. 후기는 이번 범위에 없다.
3. **내 모임 목록**: 가까운 날짜순. 표지판, 상태, D-day, 카테고리, 일시, 장소(방식), 인원을 보여준다. 승인되지 않은 신청(거절·자동 미승인)은 신청 대기 탭에 “승인되지 않음”으로 남고, 모임이 시작되면 목록에서 빠진다.
4. **상태별 버튼**: 신청 대기: 신청 취소 / 참여 확정: 모임 채팅 / 내가 연 모임: 신청 관리(신청 수 표시), 모임 수정.
5. **확인 필요 알림**: 새 메시지, 새 참여 신청, 주최자 확인 대기처럼 확인할 내용을 한 줄로 보여준다.
6. **다음 모임 카드**: 다가오는 모임 중 가장 가까운 모임까지 남은 날짜와 일시 · 장소.
7. **미니 캘린더 · 캘린더로 보기**: 모임이 있는 날을 카테고리 색으로 표시한다. 오늘은 진한 원. “캘린더로 보기”는 캘린더 팝업을 연다(기본 보기: 내 모임).
8. **모임 만들기**: 모임 만들기 화면으로 이동한다.

## 모임 – 내 모임 · 찜한 모임

- 들어오는 곳: 내 모임의 “찜한 모임” 탭
- 나가는 곳: 참여 신청 → [모임 상세](#모임--상세)
- 공통: [00 공통](00-common.md) 16 완료 토스트 / 화면의 나머지는 [“모임 – 내 모임”](#모임--내-모임)과 같다

1. **찜한 모임 탭**: 모임 상세에서 찜한 모임을 모아 본다. 숫자는 찜한 모임 개수.
2. **찜한 모임 목록**: 가까운 날짜순. 모집 상태, D-day, 카테고리, 일시, 장소(방식), 인원을 보여준다. 지난 모임과 취소된 모임은 찜했더라도 목록에서 빠진다. 모집 완료는 흐리게 하고 맨 뒤에 둔다. 남은 자리가 1~2자리면 “N자리 남았어요”로 강조한다.
3. **찜 해제**: 하트를 누르면 찜이 풀리고 목록에서 빠진다. 토스트의 “되돌리기”로 되살릴 수 있다.
4. **참여 신청**: 모임 상세로 이동한다.
5. **빈자리 알림 받기**: 모집 완료된 모임에만 보인다. 켜 두면 자리가 났을 때 알림을 보낸다. 참여 확정자가 참여를 취소하거나 내보내졌을 때, 주최자가 정원을 늘렸을 때 자리가 난다. 알림 종류는 [F9](09-notification.md) “빈자리 생김”.

## 모임 – 캘린더 팝업

- 들어오는 곳: 모임 리스트의 “캘린더로 보기”
- 나가는 곳: [모임 상세](#모임--상세) / 모임 채팅 → [모임 대화(F6)](06-chat.md) / 닫기 → 원래 화면

1. **월 이동**: 이전 달과 다음 달로 넘긴다.
2. **보기 전환**: 내 모임 / 전체 모임. 기본은 내 모임이다. 내 모임은 내가 열었거나, 참여가 확정됐거나, 신청해 기다리는 모임이다.
3. **월간 달력**: 모임이 있는 날에 모임 이름을 카테고리 색 라벨로 보여준다. 오늘은 진한 원, 고른 날은 테두리. 지난 모임도 그날 칸에 보여주고, 취소된 모임은 보여주지 않는다.
4. **고른 날의 모임**: 고른 날짜의 모임 목록. 상태, 시간, 장소(방식), 인원. 바로가기는 모임 상세와 모임 채팅(참여 확정일 때만).
5. **이번 달 요약**: 참여 확정 · 신청 대기 · 내가 연 모임 개수. 보기 전환과 상관없이 내 모임을 센다.

- 나가는 곳: 닫으면 내 모임 화면이 그대로 있다
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **캘린더 팝업**: 구성과 동작은 [“모임 – 캘린더 팝업”](#모임--캘린더-팝업)과 같다. 기본 보기는 내 모임이고 전체 모임으로 바꿀 수 있다.

## 모임 – 신청 관리

- 들어오는 곳: 내 모임 › 내가 연 모임 카드의 “신청 관리” / 알림 팝업의 “모임 참여 요청”([F9](09-notification.md))
- 나가는 곳: 거절 → [거절 확인 팝업](#모임--신청-관리--거절-확인-팝업) / 내보내기 → [내보내기 확인 팝업](#모임--신청-관리--내보내기-확인-팝업) / 닫기 → [내 모임](#모임--내-모임)
- 공통: [00 공통](00-common.md) 4 사용자 표시, 6 팝업 · 모달, 15 프로필 팝업

1. **신청 관리**: 내 모임 › 내가 연 모임 카드의 “신청 관리”로만 연다(모임 상세에는 두지 않는다). 모임 이름, 확정 인원, 대기 인원을 표시한다.
2. **신청자**: 프로필(두더지), 닉네임, 겹치는 관심사 수, 신청자가 남긴 말.
3. **거절 / 수락**: 수락하면 참여 확정되고 상대에게 알림. 거절은 확인 팝업("거절하시겠습니까? 거절하시면 신청자에게 미승인 알림이 갑니다.")을 거치고, 거절하면 상대에게 "참여가 승인되지 않았어요" 알림이 간다. 정원(주최자 포함)이 차면 수락 비활성. 모집 마감 시각까지 처리하지 않은 신청은 자동으로 미승인되고 신청자에게 미승인 알림이 간다(마감 일시가 없으면 모임이 시작될 때). 정원이 차도 기다리던 신청은 그대로 남고, 자리가 나면 주최자가 수락할 수 있다. 거절된 사람은 같은 모임에 다시 신청할 수 없다.
4. **참여 확정자 / 내보내기**: 참여 확정자 목록. '내보내기'를 누르면 확인 팝업을 거치고, 내보내면 상대에게 알림이 가고 자리가 다시 열려 모임은 다시 모집 중이 된다. 내보낸 사람은 같은 모임에 다시 신청할 수 없다. 내보낸 사람은 모임 대화방에서도 자동으로 나간다.

## 모임 – 신청 관리 · 거절 확인 팝업

- 들어오는 곳: 신청 관리의 “거절”
- 나가는 곳: 취소 · 거절 → [신청 관리](#모임--신청-관리)
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **거절 확인 팝업**: 제목 "거절하시겠습니까?", 설명 "거절하시면 신청자에게 미승인 알림이 갑니다."
2. **취소 / 거절**: '취소'는 팝업만 닫는다. '거절'을 누르면 신청이 거절되고 신청자에게 "참여가 승인되지 않았어요" 알림이 간다. 거절한 신청은 신청 대기 목록에서 빠지고, 그 사람은 같은 모임에 다시 신청할 수 없다.

## 모임 – 신청 관리 · 내보내기 확인 팝업

- 들어오는 곳: 신청 관리 참여 확정자 줄의 “내보내기”
- 나가는 곳: 취소 · 내보내기 → [신청 관리](#모임--신청-관리)
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **내보내기 확인 팝업**: 제목 "[닉네임]님을 내보낼까요?", 설명 "내보내면 되돌릴 수 없고 상대에게 알림이 가요."
2. **취소 / 내보내기**: '취소'는 팝업만 닫는다. '내보내기'를 누르면 참여가 취소되고 상대에게 알림이 간다. 자리가 다시 열려 모임은 다시 모집 중이 된다. 내보낸 사람은 같은 모임에 다시 신청할 수 없다. 내보낸 사람은 모임 대화방에서도 자동으로 나간다.

## 모임 수정 · 취소

- 들어오는 곳: 내 모임의 “모임 수정” / 모임 상세(주최자)의 “모임 수정 · 취소”
- 나가는 곳: 수정 완료 → [모임 상세](#모임--상세) / 모임 취소하기 → 확인 뒤 [내 모임](#모임--내-모임) / 모임 삭제하기(참여 확정자 0명) → [삭제 확인 팝업](#모임-수정--삭제-확인-팝업)
- 공통: [00 공통](00-common.md) 1 GNB, 3 푸터, 16 완료 토스트, 18 저장 전 취소 / 입력 칸은 [“모임 – 만들기”](#모임--만들기)와 같다

1. **모임 수정**: 기존 모임 정보를 채운 상태로 연다. 시작 12시간 전까지 수정할 수 있고(참여자가 바뀐 내용을 확인할 시간을 두기 위해), 수정하면 신청자와 참여자 모두에게 알림이 간다. 12시간 전이 지나면 입력 칸은 잠기고 모임 취소만 할 수 있다. 모집 마감 일시는 만들 때만 정하고, 수정 화면에서는 바꿀 수 없다.
2. **정원**: 이미 확정된 인원(주최자 포함)보다 적게 줄일 수 없다. 줄이려 하면 빨간 안내. 정원이 차 있던 모임의 정원을 늘려 자리가 나면 다시 모집 중이 되고, 빈자리 알림을 켠 사람에게 알림이 간다.
3. **모임 취소하기 / 수정 완료**: 수정 완료나 모임 취소 시 신청자와 참여자 모두에게 알림이 간다. 모임 취소는 시작 전까지 언제든 할 수 있고, 확인 팝업 후 진행. 참여 확정자(주최자 제외)가 0명이면 기록 없이 삭제하고, 1명 이상이면 취소(기록 남음)한다. 모임을 취소하거나 모임이 끝나도 모임 대화방은 계속 남고, 참여자는 각자 나갈 수 있다.

## 모임 수정 · 삭제 확인 팝업

- 들어오는 곳: 모임 수정의 “모임 삭제하기”(참여 확정자 0명)
- 나가는 곳: 삭제 → [내 모임](#모임--내-모임) / 취소 → [모임 수정](#모임-수정--취소)
- 공통: [00 공통](00-common.md) 6 팝업 · 모달, 17 삭제 확인

1. **삭제 확인 팝업**: 제목 "모임을 삭제할까요?", 설명 "삭제하면 모임과 신청 내역이 사라지고 되돌릴 수 없어요."
2. **취소 / 삭제**: '취소'는 팝업만 닫는다. '삭제'를 누르면 모임이 삭제되고 목록·내 모임에서 사라진다. 신청 대기자에게는 모임이 삭제됐다는 알림이 간다.
3. **모임 삭제하기**: 참여 확정자(주최자 제외)가 0명일 때 '모임 취소하기' 자리에 '모임 삭제하기'가 보인다. 누르면 삭제 확인 팝업이 뜬다.

## 영역 규칙

여러 화면에 흩어져 적힌 규칙을 모았다. 괄호 안은 그 내용이 적힌 화면과 항목 번호다.

### 모집 상태

모임의 모집 상태는 모집 중 / 모집 완료 / 지난 모임 / 취소됨 네 가지다(모임 – 상세 1). 상태 표와 상태 화면에서는 취소됨을 “취소된 모임”이라고 쓴다.

| 모집 상태 | 이 상태가 되는 때 | 이 상태일 때 |
|---|---|---|
| 모집 중 | 모집 완료였다가 모집 마감 전에 자리가 나면 다시 모집 중이 된다(모임 – 상세 1). 주최자가 참여 확정자를 내보내면 자리가 다시 열려 다시 모집 중이 된다(신청 관리 4). | 배지에 남은 자리를 표시한다(모임 – 상세 1). |
| 모집 완료 | 정원이 차거나 모집 마감 시각이 지나면(모임 – 상세 1). | 참여 신청하기를 끈다(모임 – 상세 6). 정원이 차 있는 동안에는 새 신청을 받지 않는다(만들기 2). 기다리던 신청은 그대로 남고, 자리가 나면 주최자가 수락할 수 있다(모임 – 상세 6). 리스트와 찜한 모임 목록에서 흐리게 하고 맨 뒤에 둔다(리스트 5, 정렬 열림 2, 찜한 모임 2). 찜한 모임에서 빈자리 알림을 켤 수 있다(찜한 모임 5). |
| 지난 모임 | 시작 시각이 지나면 바로(모임 – 상세 1). | 신청할 수 없다(상태: 지난 모임 2). 리스트에 보이지 않고 내 모임에서만 본다(리스트 5). 내 모임의 “지난 모임” 탭에 기록으로 남고 지울 수 없다(내 모임 2). 후기는 이번 범위에 없다. 모임 대화방은 계속 남고, 참여자는 각자 나갈 수 있다(상태: 지난 모임 2). |
| 취소됨 | 참여 확정자(주최자 제외)가 1명 이상인 모임을 주최자가 취소하면. 취소는 시작 전까지 언제든 할 수 있다(모임 수정 · 취소 3). | 신청자와 참여자 모두에게 알림이 간다. 기록이 남는다(모임 수정 · 취소 3). 리스트에 보이지 않고 내 모임에서만 본다(리스트 5). 주최자와 참여 확정자의 내 모임 › 지난 모임에 “취소됨”으로 남는다(내 모임 2). 모임 대화방은 계속 남고, 참여자는 각자 나갈 수 있다(상태: 취소된 모임 2). |

### 신청 기록 상태

신청 기록의 상태는 신청 대기 / 신청 취소 / 미승인 / 참여 확정 / 참여 취소 / 내보내짐 / 모임 취소로 마감 일곱 가지다(모임 – 상세 6, 상태 표).

| 신청 기록 상태 | 이 상태가 되는 때 | 다시 신청 | 이 상태일 때 |
|---|---|---|---|
| 신청 대기 | 참여 신청하기를 누르면(모임 – 상세 6). | – | 주최자 확인을 기다린다. 결과는 알림으로 온다(상태: 신청 대기 2). 정원이 차도 그대로 남고, 자리가 나면 주최자가 수락할 수 있다. 내 모임에서는 신청 대기 탭에만 있다(내 모임 2). |
| 신청 취소 | 신청 대기 중에 스스로 신청을 취소하면(상태: 신청 대기 3). | 가능 | 미신청으로 돌아간다. |
| 미승인 | 주최자가 거절하면(신청 관리 3). 또는 모집 마감 시각까지 주최자가 처리하지 않으면 자동으로. 마감 일시가 없으면 모임이 시작될 때(모임 – 상세 6). | 불가 | 신청자에게 미승인 알림이 간다. 모임 상세에 미승인 카드(“참여가 어려워요”)를 보여준다(상태: 신청 대기 · 미승인 2). 내 모임의 신청 대기 탭에 “승인되지 않음”으로 남고, 모임이 시작되면 목록에서 빠진다(내 모임 3). |
| 참여 확정 | 주최자가 수락하면(신청 관리 3). | – | 상대에게 알림이 간다. 내 모임의 다가오는 모임으로 옮겨진다(내 모임 2). 모임 대화방에 들어온다(만들기 6). 모임 대화 미리보기와 온라인 접속 링크가 보인다(모임 – 상세 8, 9). |
| 참여 취소 | 참여 확정 뒤 스스로 참여를 취소하면. 시작 24시간 전까지만 할 수 있다. 채팅 모임 정보 팝업의 “모임 나가기”와 같은 동작이다(상태: 참여 확정 3). | 불가 | 주최자에게 알린다. 모임 대화방에서도 빠진다. 버튼 자리에 “이 모임에는 다시 신청할 수 없어요”를 보여준다(모임 – 상세 6). |
| 내보내짐 | 주최자가 신청 관리에서 참여 확정자를 내보내면(신청 관리 4). | 불가 | 상대에게 알림이 간다. 자리가 다시 열려 모임은 다시 모집 중이 된다. 모임 대화방에서도 자동으로 나간다. 버튼 자리에 “이 모임에는 다시 신청할 수 없어요”를 보여준다(모임 – 상세 6). |
| 모임 취소로 마감 | 신청 대기 중에 주최자가 모임을 취소하면(모임 수정 · 취소 3). | 불가 | 신청자에게 모임 취소 알림이 간다. 미승인 알림은 가지 않는다. 주최자가 처리할 신청 수에서 빠진다. 모임 상세에는 취소된 모임 카드를 보여준다(상태: 취소된 모임 2). |

### 정원

- 정원에는 주최자가 포함된다(정원 6명 = 주최자 1명 + 참여자 5명). 모임을 만들자마자 1명 확정이다(만들기 1).
- 정원은 2~50명이고 기본 6명이다(만들기 1).
- 인원은 주최자를 포함한 확정 인원 / 정원으로 보여준다(예: 4 / 6명)(리스트 5).
- 정원(주최자 포함)이 차면 신청 관리의 수락이 비활성이 된다(신청 관리 3).
- 수정할 때 이미 확정된 인원(주최자 포함)보다 적게 줄일 수 없다(모임 수정 · 취소 2).

### 모임이 만들어지고 없어지는 때

- 만들기: “모임 만들기”를 누르면 모임을 등록한다. 모임 대화방은 이때 함께 만들어진다(만들기 6).
- 수정: 시작 12시간 전까지 할 수 있다. 12시간 전이 지나면 입력 칸은 잠기고 모임 취소만 할 수 있다. 모집 마감 일시는 만들 때만 정하고 수정 화면에서는 바꿀 수 없다(모임 수정 · 취소 1).
- 취소: 시작 전까지 언제든 할 수 있다. 참여 확정자(주최자 제외)가 1명 이상이면 취소하고 기록이 남는다(모임 수정 · 취소 3).
- 삭제: 참여 확정자(주최자 제외)가 0명이면 취소 대신 기록 없이 삭제한다(모임 수정 · 취소 3). 신청 대기자가 있어도 삭제할 수 있다(상태: 주최자 · 참여 확정 0명 3). 삭제하면 모임과 신청 내역이 사라지고, 신청 대기자에게는 모임이 삭제됐다는 알림이 간다(삭제 확인 팝업 1, 2).
- 지난 모임은 삭제할 수 없고 내 모임 › 지난 모임에 기록으로 남는다(상태: 주최자 3).
- 수정 완료나 모임 취소 시 신청자와 참여자 모두에게 알림이 간다(모임 수정 · 취소 3).

### 모임 대화방

- 모임을 등록할 때 함께 만들어지고, 참여가 확정된 사람부터 들어온다(만들기 6).
- 참여를 취소하거나 내보내지면 모임 대화방에서도 빠진다(상태: 참여 확정 3, 신청 관리 4).
- 모임을 취소하거나 모임이 끝나도 계속 남고, 참여자는 각자 나갈 수 있다(모임 수정 · 취소 3).
- 모임 상세의 모임 대화 미리보기는 참여 확정자와 주최자에게만 보인다. 가려진 상태에서는 실제 메시지 내용을 내려보내지 않는다(모임 – 상세 9).
- 온라인 모임의 접속 링크는 참여 확정자에게만 보이고 모임 대화방에도 안내한다(만들기 3).

### 카테고리

- 카테고리는 모임 전용 분류이고 관심사와 관계없다. 모임 하나는 카테고리 하나를 가진다(리스트 3).
- 카테고리는 여섯 가지다: 취미/문화, 식사/카페, 스터디/프로젝트, 기타, 게임, 운동(리스트 3).
- 카테고리가 모임 카드 색, 표지판, 캘린더 라벨 색을 정한다(만들기 4).

- **모임 대화 미리보기의 항목 번호**: “모임 상세 – 상태 표” 아래의 글, “상태: 참여 확정” 4, “상태: 주최자” 4는 모임 대화 미리보기를 “모임 – 상세” 10이라고 가리킨다. “모임 – 상세”에서 모임 대화 미리보기는 9번이고 10번은 없다.
- **모집 완료의 조건과 안내**: “모임 – 상세” 1과 상태 표의 덧붙임은 정원이 차거나 모집 마감 시각이 지나면 모집 완료이고, 모집 마감 전에 자리가 나야 다시 모집 중이라고 적는다. “상태: 모집 완료” 2와 상태 표의 “행동 카드에 보이는 것”은 정원이 다 찬 경우만 적고 있어, 모집 마감 시각이 지나 모집 완료가 된 모임에 보여줄 안내가 없다. “상태: 모집 완료” 2의 “자리가 나면 다시 모집 중이 된다”에도 “모집 마감 전”이라는 조건이 없다.
- **신청 관리를 여는 곳**: “모임 – 신청 관리” 1은 내 모임 › 내가 연 모임 카드의 “신청 관리”로만 연다고 적는다. 같은 화면의 들어오는 곳에는 알림 팝업의 “모임 참여 요청”(F9)도 있다.
- **직접 설정이 여는 화면의 이름**: “모임 – 리스트”의 나가는 곳은 “날짜 › 직접 설정 → 날짜 필터”라고 적고, “모임 – 리스트 · 날짜 필터”의 나가는 곳은 “직접 설정 → 날짜 직접 설정”이라고 적는다.
