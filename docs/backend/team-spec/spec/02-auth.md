# 02. 로그인 · 회원가입 · 비밀번호 찾기

이메일이나 Google 계정으로 로그인하거나 가입한다. 가입할 때 SSAFY 인증을 하고, 비밀번호를 잊으면 재설정 메일로 새 비밀번호를 정한다.

- 공통 규칙: [00 공통](00-common.md)

## 로그인

- 들어오는 곳: [랜딩](01-landing.md#랜딩-03--방) · [둘러보기(땅 · 견본 방)](01-landing.md#둘러보기--땅) · [로그인 필요](01-landing.md#로그인-필요--4번째-방)의 “로그인”, [견본 방](01-landing.md#둘러보기--견본-방)의 잠긴 기능, [새 비밀번호 설정](#비밀번호-찾기--새-비밀번호-설정) 완료
- 나가는 곳: 로그인 성공 → [내 땅굴](04-my-burrow.md)(둘러보기의 방은 견본이라 돌아가지 않는다. 온보딩을 마치지 않았으면 [온보딩 1](03-onboarding.md#온보딩-1--나를-부르는-이름)) / Google로 계속하기 → 같은 규칙, 처음 쓰는 Google 계정은 [회원가입 3](#회원가입-3--ssafy-인증) / 비밀번호 찾기 → [재설정 메일 요청](#비밀번호-찾기--재설정-메일-요청) / 회원가입 → [회원가입 1](#회원가입-1--이메일)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고 · 흐린 배경 · 두더지)

1. **제목**: “다시 오셨군요!” 한 줄만 노출한다.
2. **이메일 입력**: 이메일 형식을 검사한다. 칸을 벗어날 때 형식이 틀리면 “이메일 형식을 확인해 주세요”를 표시한다. 브라우저 자동완성을 허용한다.
3. **비밀번호 입력**: 입력값은 가려서 표시한다. Enter 키로 로그인을 제출한다.
4. **로그인 버튼**: 두 칸이 모두 채워지면 활성화한다. 요청 중에는 로딩을 표시한다. 실패하면 “이메일 또는 비밀번호가 맞지 않아요”를 보여준다(어느 쪽이 틀렸는지는 알리지 않는다). 정지된 계정이면 로그인되지 않고, 정지 사유와 기간을 알리는 팝업을 띄운다(예: “신고로 인해 7일 동안 로그인할 수 없어요”). Google 로그인도 같다.
5. **Google로 계속하기**: Google 계정으로 로그인하거나 가입한다. 처음 쓰는 Google 계정이면 회원가입 3 · SSAFY 인증으로 간다.
6. **비밀번호 찾기**: 재설정 메일 요청 화면으로 이동한다. 이메일로 가입한 계정만 해당한다.
7. **회원가입**: 회원가입 1단계(이메일)로 이동한다. 입력한 이메일이 있으면 그대로 넘겨준다.

## 회원가입 1 · 이메일

- 들어오는 곳: [랜딩](01-landing.md) “시작하기” · “내 땅굴 만들기”, [로그인 필요](01-landing.md#로그인-필요--4번째-방) · [로그인](#로그인)의 “회원가입”
- 나가는 곳: 다음 → [회원가입 2](#회원가입-2--비밀번호)
- Google로 가입하면 회원가입 1 · 2를 건너뛰고 [회원가입 3](#회원가입-3--ssafy-인증)으로 간다.
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고 · 흐린 배경 · 두더지)

1. **진행 표시**: 막대와 “1/3”로 이메일 가입 3단계 중 현재 단계를 보여준다.
2. **제목·안내**: 제목 “땅굴 주소를 만들어요”와 안내 “가입할 이메일을 인증해요.”를 보여준다.
3. **이메일 입력**: 로그인에 쓸 이메일을 입력한다. 본인 이메일인지 확인하려고 이 주소로 인증 코드를 보낸다. 형식에 맞지 않는 문자(공백, 허용되지 않는 특수문자 등)를 입력하면 바로 입력란 아래에 “이메일 형식을 확인해 주세요”를 띄운다.
4. **재전송 버튼**: 이메일 입력란 오른쪽 칩이다. 누르면 인증 코드를 다시 보낸다. 재전송 간격 제한이 필요하다. (제안)
5. **인증 코드 입력**: 6자리 숫자를 입력한다. 오른쪽에 남은 시간(예: 4:52)을 표시한다. 숫자가 아닌 문자를 입력하면 바로 “숫자 6자리를 입력해 주세요”를 띄운다.
6. **스팸함 안내**: “메일함에 코드가 없으면 스팸함도 확인해 주세요.” 문구를 입력란 아래에 표시한다.
7. **다음 버튼**: 코드를 입력하기 전에는 흐린 비활성 상태다. 입력이 끝나면 활성화되어 2단계로 이동한다. (제안)

## 회원가입 2 · 비밀번호

- 들어오는 곳: [회원가입 1](#회원가입-1--이메일)의 “다음”
- 나가는 곳: 다음 → [회원가입 3 · SSAFY 인증](#회원가입-3--ssafy-인증)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고 · 흐린 배경 · 두더지), 9 비밀번호 규칙

1. **진행 표시**: 막대와 “2/3”로 이메일 가입 3단계 중 현재 단계를 보여준다.
2. **제목·안내**: 제목 “비밀번호를 정해요”를 보여준다.
3. **비밀번호 입력**: 비밀번호를 입력한다. 입력값은 점으로 가린다. 규칙과 충족 여부 표시는 [00 공통](00-common.md) 9를 따른다. 규칙에 어긋나는 문자(공백 등)를 입력하면 바로 입력란 아래에 오류 문구를 띄운다.
4. **비밀번호 확인**: 같은 비밀번호를 한 번 더 입력한다. 입력하는 동안 두 값이 다르면 바로 “비밀번호가 일치하지 않아요”를 띄운다.
5. **다음 버튼**: 비밀번호 조건을 모두 채우면 활성화되어 회원가입 3 · SSAFY 인증으로 이동한다. 그 전에는 비활성 상태이다. (제안)

## 회원가입 3 · SSAFY 인증

- 들어오는 곳: [회원가입 2](#회원가입-2--비밀번호)의 “다음”(이메일 가입), Google 계정 선택(Google 가입)
- 나가는 곳: 땅굴 파기 → [온보딩 1](03-onboarding.md#온보딩-1--나를-부르는-이름)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고 · 흐린 배경 · 두더지)

1. **진행 표시**: 막대와 “3/3”로 이메일 가입 3단계 중 현재 단계를 보여준다. Google로 가입하면 이 화면 하나뿐이라 진행 표시를 숨긴다.
2. **제목·안내**: 제목 “SSAFY 인증을 해요”와 안내 “Mattermost로 인증 코드를 보내요.”를 보여준다.
3. **기수 · 캠퍼스 · 층**: 기수와 캠퍼스 · 층을 목록에서 고른다(캠퍼스를 고르면 그 캠퍼스의 층이 나온다, [00 공통](00-common.md) 19). 모두 필수이고 프로필에 항상 공개된다. 반은 받지 않는다. 여기서 고른 캠퍼스-층의 이번 학기 들판에 내 땅굴이 놓인다. 캠퍼스와 층은 [내 정보 수정](04-my-burrow.md)에서 바꿀 수 있다.
4. **Mattermost ID · 코드 받기**: SSAFY Mattermost ID를 입력하고 “코드 받기”를 누르면 Mattermost 메시지로 인증 코드가 온다. 코드는 3에서 고른 기수의 Mattermost로 보내므로, 받은 코드를 입력하면 그 기수의 교육생임이 함께 확인된다. 다시 누르면 재전송한다. 재전송 간격 제한이 필요하다. (제안)
5. **인증 코드 입력**: [회원가입 1](#회원가입-1--이메일)의 5와 같다(6자리 숫자, 남은 시간 표시, 숫자가 아니면 바로 오류).
6. **안내 문구**: “Mattermost 메시지가 오지 않으면 ID를 다시 확인해 주세요.” 문구를 입력란 아래에 표시한다.
7. **약관 동의**: “이용약관 동의”와 “개인정보 수집·이용 동의” 체크박스가 있다. 둘 다 필수이다. Google 가입자도 이 화면에서 동의한다.
8. **땅굴 파기 버튼**: 인증 코드 확인과 필수 약관 동의를 모두 마치면 활성화되어 가입을 마치고 온보딩 1로 이동한다. 그 전에는 비활성 상태이다. (제안)

## 비밀번호 찾기 · 재설정 메일 요청

- 들어오는 곳: [로그인](#로그인) “비밀번호 찾기”(이메일로 가입한 계정만), [링크 만료](#비밀번호-찾기--링크-만료) “다시 받기”
- 나가는 곳: 링크 보내기 → [메일 보냄](#비밀번호-찾기--메일-보냄) / 로그인으로 돌아가기 → [로그인](#로그인)

1. **이메일**: 가입한 이메일을 입력한다. 형식이 틀리면 바로 안내한다.
2. **링크 보내기**: 가입하지 않은 이메일이어도 “메일을 보냈어요” 화면으로 똑같이 이동한다(가입 여부 노출 방지).
3. **로그인으로 돌아가기**: 로그인 화면으로 이동한다.

## 비밀번호 찾기 · 메일 보냄

- 들어오는 곳: [재설정 메일 요청](#비밀번호-찾기--재설정-메일-요청)의 “링크 보내기”
- 나가는 곳: 메일의 링크 → [새 비밀번호 설정](#비밀번호-찾기--새-비밀번호-설정)(유효한 링크) 또는 [링크 만료](#비밀번호-찾기--링크-만료) / 다시 보내기 → 이 화면

1. **메일 보냄**: 입력한 이메일과 관계없이 같은 문구를 보여준다.
2. **다시 보내기**: 다시 보내면 이전 링크는 무효가 된다. (제안)
3. **유효 시간**: 링크는 30분 동안, 한 번만 쓸 수 있다.

## 비밀번호 찾기 · 새 비밀번호 설정

- 들어오는 곳: 재설정 메일의 링크(유효할 때)
- 나가는 곳: 비밀번호 바꾸기 → [로그인](#로그인)
- 공통: [00 공통](00-common.md) 9 비밀번호 규칙

1. **새 비밀번호**: [회원가입 2](#회원가입-2--비밀번호)의 3과 같다(규칙과 충족 여부 표시는 [00 공통](00-common.md) 9).
2. **새 비밀번호 확인**: [회원가입 2](#회원가입-2--비밀번호)의 4와 같다. 두 값이 다르면 바로 “비밀번호가 일치하지 않아요”를 띄운다.
3. **비밀번호 바꾸기**: 성공하면 링크를 만료시키고 로그인 화면으로 이동한다.

## 비밀번호 찾기 · 링크 만료

- 들어오는 곳: 30분이 지났거나 이미 쓴 재설정 링크
- 나가는 곳: 다시 받기 → [재설정 메일 요청](#비밀번호-찾기--재설정-메일-요청)

1. **링크 만료**: 30분이 지났거나 이미 쓴 링크로 들어오면 보여준다.
2. **다시 받기**: 재설정 메일 요청 화면으로 이동한다.

## 영역 규칙

### 가입 경로

- 이메일 가입은 3단계다: 회원가입 1 · 이메일 → 회원가입 2 · 비밀번호 → 회원가입 3 · SSAFY 인증.
- Google로 가입하면 회원가입 1 · 2를 건너뛰고 회원가입 3으로 간다. 이때 회원가입 3의 진행 표시는 숨긴다.
- 약관 동의는 이메일 가입자와 Google 가입자 모두 회원가입 3에서 한다.
- 회원가입 3의 “땅굴 파기”로 가입을 마치면 온보딩 1로 간다. 계정은 이때 만들어진다.
- 가입 도중에 나가면 그때까지 입력한 내용은 저장되지 않는다. 다시 가입하려면 처음부터 다시 한다(이메일 가입은 회원가입 1부터, Google 가입은 “Google로 계속하기”부터). 가입을 마치지 않은 사람은 로그인할 수 없다.

### 로그인한 뒤 가는 곳

이메일 로그인과 Google로 계속하기에 같은 규칙을 쓴다.

| 계정 상태 | 가는 곳 |
|---|---|
| 처음 쓰는 Google 계정 | 회원가입 3 · SSAFY 인증 |
| 온보딩을 마치지 않은 계정 | 온보딩 1 |
| 새 학기가 열렸는데 이번 학기의 캠퍼스 · 층을 고르지 않은 계정 | 내 땅굴. 그 위에 새 학기 안내가 뜨고, 고르기 전에는 닫을 수 없다([05 탐색 · 방문](05-explore-visit.md#땅굴-메인--새-학기-안내)) |
| 그 밖 | 내 땅굴 |
| 정지된 계정 | 로그인되지 않는다. 정지 사유와 기간을 알리는 팝업을 띄운다 |

### 비밀번호 재설정 링크

- 링크는 30분 동안, 한 번만 쓸 수 있다.
- 다시 보내면 이전 링크는 무효가 된다. (제안)
- 비밀번호를 바꾸는 데 성공하면 링크를 만료시킨다.
- 30분이 지났거나 이미 쓴 링크로 들어오면 링크 만료 화면을 보여준다.
- 가입하지 않은 이메일을 넣어도 같은 화면으로 이동하고 같은 문구를 보여준다(가입 여부 노출 방지).
- 비밀번호 찾기는 이메일로 가입한 계정만 해당한다.

## 아직 정하지 않은 것

**(제안)으로 남은 것**

- 회원가입 1 · 이메일: 4 재전송 버튼(재전송 간격 제한이 필요하다), 7 다음 버튼
- 회원가입 2 · 비밀번호: 5 다음 버튼
- 회원가입 3 · SSAFY 인증: 4 Mattermost ID · 코드 받기(재전송 간격 제한이 필요하다), 8 땅굴 파기 버튼
- 비밀번호 찾기 · 메일 보냄: 2 다시 보내기(이전 링크 무효)

**서로 맞지 않아 보이는 곳**

- 이메일 인증 코드를 처음 보내는 동작: 회원가입 1 · 이메일의 3은 입력한 주소로 인증 코드를 보낸다고 하는데, 처음 보내는 버튼이나 때가 적혀 있지 않다. 4는 “재전송 버튼”뿐이다. 회원가입 3의 4는 “코드 받기”로 처음 받고 다시 누르면 재전송한다.
- 로그인의 들어오는 곳: 재설정 메일 요청의 3 “로그인으로 돌아가기”가 로그인의 들어오는 곳에 없다.
- 로그인 화면으로 보내진 뒤: [00 공통](00-common.md) 11은 비로그인이 그 밖의 화면이나 공유 링크를 열면 로그인 화면으로 보낸다고 한다. 로그인의 들어오는 곳에는 이 경우가 없다. 나가는 곳은 내 땅굴뿐이라, 로그인한 뒤 열려던 화면으로 가는지 적혀 있지 않다.
- 회원가입 2 · 비밀번호의 5: 다음 버튼은 “비밀번호 조건을 모두 채우면” 활성화된다고 적는다. 4 비밀번호 확인의 두 값이 같아야 하는지는 적혀 있지 않다.
- 비밀번호 찾기 화면 4개의 공통: 로그인 · 회원가입 화면은 [00 공통](00-common.md) 11(로고 · 흐린 배경 · 두더지)을 가리키는데, 비밀번호 찾기 화면 4개의 흐름에는 이 줄이 없다.
