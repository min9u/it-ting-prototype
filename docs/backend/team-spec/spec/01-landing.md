## 랜딩 03 · 방

- 들어오는 곳: 첫 방문. 랜딩은 한 페이지를 스크롤하며 방(이 화면) → 이웃 두 구간으로 바뀐다([스크롤 모션 타임라인](#스크롤-모션-타임라인)).
- 나가는 곳: 스크롤 → [랜딩 04 · 이웃](#랜딩-04--이웃) / 로그인 → [로그인](02-auth.md#로그인) / 시작하기 → [회원가입 1](02-auth.md#회원가입-1--이메일)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고)

1. **상단 메뉴**: “로그인” 링크와 “시작하기” 버튼이 있다. 로그인 화면, 회원가입 1단계로 각각 이동한다. 랜딩 전체에서 같은 자리에 둔다. (제안)
2. **배경**: 텐트 모양 방 안쪽 3D 일러스트다. 가구가 놓인 아늑한 방을 보여 준다.
3. **두더지**: 방 한가운데 서 있는 두더지다. 이 방의 주인공이다. (제안)
4. **가구 라벨**: 게임기·소설책·물감 상자·카세트 워크맨·필름 카메라·캠핑 의자 라벨 6개다. 가구 위에 분류 이름(게임·독서·그림·음악·사진·캠핑)과 가구 이름을 함께 달고 점선으로 가구와 잇는다. 고른 관심사가 가구가 된다는 걸 보여 준다.
5. **제목·부제**: 제목은 “나의 관심사가 내 땅굴의 가구가 돼요”, 부제는 “책을 좋아하면 소설책이, 음악을 좋아하면 카세트 워크맨이 놓여요”다.

## 랜딩 04 · 이웃

- 들어오는 곳: [랜딩 03 · 방](#랜딩-03--방)에서 스크롤
- 나가는 곳: 내 땅굴 만들기 → [회원가입 1](02-auth.md#회원가입-1--이메일) / 먼저 둘러보기 → [둘러보기 · 땅](#둘러보기--땅) / 로그인 → [로그인](02-auth.md#로그인)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고), 10 모션 줄이기

1. **상단 메뉴**: [랜딩 03 · 방](#랜딩-03--방)의 1과 같다.
2. **배경**: 방에서 땅 위로 올라온 장면이다. 방 입구(구멍)와 팻말이 보인다.
3. **두더지**: 구멍에서 올라온 두더지가 정면을 본다. 눈 깜빡임 루프가 있다. (제안)
4. **팻말 태그**: 팻말 위에 이웃 땅굴 태그 3개(독서·게임, 캠핑·사진, 그림)와 한 줄 문구를 띄운다.
5. **제목·부제**: “같은 걸 좋아하는 이웃이 생각보다 가까이 살아요” 제목과 “땅 위를 걸으며 땅굴을 구경하고, 마음이 맞으면 같이 모여요.” 부제를 보여준다.
6. **내 땅굴 만들기**: 누르면 회원가입 화면으로 이동한다. (제안)
7. **먼저 둘러보기**: 누르면 로그인 없이 둘러보기(땅) 화면으로 이동한다.

## 스크롤 모션 타임라인

랜딩(랜딩 03 · 04)의 스크롤 모션을 설명하는 보조 프레임이다. 화면 이동은 없다. 랜딩은 방과 이웃 두 구간이고, 땅 위에서 구멍 속으로 들어가는 장면은 없다.

- 공통: [00 공통](00-common.md) 10 모션 줄이기

1. **제목·안내**: “스크롤 모션 타임라인” 제목과 안내 문구가 있다. 3D 씬은 고정되고 텍스트만 바뀐다고 알린다.
2. **장면 썸네일**: 스크롤 진행도 0–50% 방 · 50–100% 이웃, 두 장면을 보여준다.
3. **진행 축**: 스크롤 진행도를 나타내는 가로 눈금이다. 구간 막대가 이 축 위에 놓인다. (제안)
4. **방 등장**: 방이 다 차려질 때까지 로딩 애니메이션(“땅굴 파는 중...”)을 보여주고, 다 차려지면 가구가 놓인 방이 한 번에 페이드 인 한다. 가구가 하나씩 떨어지는 연출은 없다.
5. **라벨**: 방이 나타난 뒤 가구마다 라벨이 0.08초 간격으로 순서대로 나타난다.
6. **폴아웃**: 방에서 다시 땅 위로 올라와 이웃 땅굴이 보인다.
7. **카피**: 각 구간에 진입할 때 문구가 아래에서 위로 16px 올라오며 페이드 인 한다.
8. **하단 설정**: 대기 루프(두더지 숨쉬기 · 깜빡임 3초 루프) 설정을 안내한다. 모바일 설정은 이번 범위에 없다([00 공통](00-common.md) 20 지원 기기).

## 둘러보기 · 땅

- 들어오는 곳: [랜딩 04](#랜딩-04--이웃) “먼저 둘러보기”, [견본 방](#둘러보기--견본-방) · [로그인 필요](#로그인-필요--4번째-방) 화면의 “땅 위로 돌아가기”
- 나가는 곳: 들어가기 → [둘러보기 · 견본 방](#둘러보기--견본-방) / 4번째 방 들어가기 → [로그인 필요 · 4번째 방](#로그인-필요--4번째-방) / 로그인 → [로그인](02-auth.md#로그인)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고)

1. **배경**: 밝은 땅 위 장면에 방 입구(구멍)와 팻말을 보여준다. 비로그인은 캠퍼스-층을 고르지 않고, 견본 방으로 채운 들판 하나만 본다. 실제 사용자의 땅굴은 보여주지 않는다.
2. **구경한 방 표시**: 오른쪽 위에 구경한 방 수를 점 3개로 보여준다. 구경할 때마다 점이 채워진다. (제안)
3. **로그인 링크**: 누르면 로그인 화면으로 이동한다.
4. **방 입구**: 땅 위의 구멍과 방 이름 팻말이다. 누르면 방 카드가 나타난다. (제안)
5. **방 카드**: 견본 방의 이름과 관심사(예: 내굴, 독서·게임·캠핑)를 보여주는 카드다.
6. **들어가기 버튼**: 누르면 그 방으로 들어간다. 비로그인은 방 3개까지만 구경할 수 있다. (제안)
7. **하단 안내**: “땅굴을 눌러 들어가 보세요 · 로그인 없이 방 3개까지” 문구를 화면 아래에 보여준다.

## 둘러보기 · 견본 방

- 들어오는 곳: [둘러보기 · 땅](#둘러보기--땅)의 방 카드 “들어가기”(1 ~ 3번째 방)
- 나가는 곳: 땅 위로 돌아가기 → [둘러보기 · 땅](#둘러보기--땅) / 자물쇠가 붙은 기능 → [로그인](02-auth.md#로그인) / 로그인 → [로그인](02-auth.md#로그인)
- 공통: [00 공통](00-common.md) 5 관심사 태그, 10 모션 줄이기, 11 시작 화면 공통(로고), 13 땅굴 화면 공통 가운데 시점 조작

1. **견본 방**: 팀이 만들어 둔 예시 방이다. 실제 사용자의 땅굴이 아니다. 방과 가구, 견본 주인 두더지를 보여주고, 가구를 누르면 관심사 이름 말풍선이 뜬다([내 땅굴](04-my-burrow.md)과 같다). 비로그인은 내 관심사가 없으므로 겹치는 관심사 표시는 없다.
2. **상단**: 로고, 구경한 방 표시, 로그인 링크가 있다. [둘러보기 · 땅](#둘러보기--땅)의 2 · 3과 같다. 이 방에 들어오면 점이 하나 채워진다. GNB는 없다.
3. **방노트**: 견본 주인의 방 이름, 자기소개, 관심사, 질문 3개와 답변을 읽는다. 구성은 [방문자 뷰 · 방노트(F5)](05-explore-visit.md)와 같고, 소속(캠퍼스 · 기수 · 층), 신고 아이콘, “나와 같은 관심사”는 없다. 처음부터 펼쳐져 있고 접을 수 있다.
4. **잠긴 기능**: 대화 요청하기, 단골 추가, 우체통(방명록)은 자물쇠를 붙여 보여준다. 누르면 로그인 화면으로 간다. 자물쇠 말고 안내 문구는 따로 두지 않는다.
5. **땅 위로 돌아가기**: 누르면 둘러보기 · 땅으로 돌아간다. 구경한 방 수는 그대로 남는다.

## 로그인 필요 · 4번째 방

- 들어오는 곳: [둘러보기 · 땅](#둘러보기--땅)에서 4번째 방의 “들어가기”
- 나가는 곳: 로그인 → [로그인](02-auth.md#로그인) / 회원가입 → [회원가입 1](02-auth.md#회원가입-1--이메일) / 돌아가기 → [둘러보기 · 땅](#둘러보기--땅)
- 공통: [00 공통](00-common.md) 11 시작 화면 공통(로고 · 흐린 배경 · 두더지)

1. **구경한 방 표시**: [둘러보기 · 땅](#둘러보기--땅)의 2와 같다. 점 3개가 모두 채워져 있다.
2. **제목**: 제목 “방 3개를 다 구경했어요”를 보여준다.
3. **안내 문구**: 로그인하면 계속 둘러보고 방명록도 남길 수 있다고 알린다.
4. **로그인 버튼**: 누르면 로그인 화면으로 이동한다.
5. **회원가입 버튼**: 누르면 회원가입 1단계(이메일)로 이동한다.
6. **돌아가기 링크**: 누르면 방이 있는 땅 위로 돌아간다. (제안)

## 영역 규칙

- **랜딩 장면 순서**: 랜딩은 한 페이지를 스크롤하며 방 → 이웃 두 구간으로 바뀐다. 두 구간의 모션은 [스크롤 모션 타임라인](#스크롤-모션-타임라인)으로 정의한다.
- **둘러보기에서 보는 것**: 비로그인은 캠퍼스-층을 고르지 않고, 견본 방으로 채운 들판 하나만 본다. 견본 방은 팀이 만들어 둔 예시 방이고, 실제 사용자의 땅굴은 보여주지 않는다.
- **구경한 방 수**: 견본 방에 들어오면 점이 하나 채워진다. 땅 위로 돌아가도 구경한 방 수는 그대로 남는다. 비로그인은 방 3개까지만 구경할 수 있다. (제안) 4번째 방의 “들어가기”를 누르면 [로그인 필요 · 4번째 방](#로그인-필요--4번째-방)으로 간다.
- **로그인해야 쓰는 기능**: 견본 방의 대화 요청하기, 단골 추가, 우체통(방명록)은 자물쇠를 붙여 보여주고, 누르면 로그인 화면으로 간다.

## 아직 정하지 않은 것

**(제안)으로 남은 것**

- 랜딩 03 · 방: 1 상단 메뉴, 3 두더지
- 랜딩 04 · 이웃: 3 두더지(눈 깜빡임 루프), 6 내 땅굴 만들기
- 스크롤 모션 타임라인: 3 진행 축
- 둘러보기 · 땅: 2 구경한 방 표시, 4 방 입구, 6 들어가기 버튼(방 3개까지만 구경)
- 로그인 필요 · 4번째 방: 6 돌아가기 링크

**서로 맞지 않아 보이는 곳**

- 방 3개 제한: 둘러보기 · 땅의 6은 “방 3개까지만 구경할 수 있다”를 (제안)으로 둔다. 같은 화면의 7(하단 안내 “로그인 없이 방 3개까지”)과 로그인 필요 · 4번째 방(2의 제목 “방 3개를 다 구경했어요”)은 3개 제한을 확정된 것처럼 적는다.
- 돌아가기 문구: 둘러보기 · 땅의 들어오는 곳은 로그인 필요 화면의 “땅 위로 돌아가기”라고 적는다. 로그인 필요 · 4번째 방의 6과 나가는 곳은 “돌아가기”라고 적는다.
