# 04. 내 땅굴

내 땅굴과 내 정보를 보고, 두더지를 꾸미고, 내 정보를 바꾼다. 방문자가 남긴 방명록을 읽고 지운다.

## 땅굴 메인 – 내 땅굴

- 들어오는 곳: [로그인](02-auth.md), [온보딩](03-onboarding.md) 4의 관심사 확정, GNB 땅굴, 모드 전환의 “내 땅굴”
- 나가는 곳: 땅굴 꾸미기 → [꾸미기 모드](#땅굴--꾸미기-모드--두더지-탭) / 연필 버튼 · 자기소개 쓰기 → [내 정보 수정](#땅굴--내-정보-수정) / 접기 → [카드 접기](#땅굴-메인--내-땅굴--꾸미기-안내-말풍선--카드-접기) / 우체통 → [방명록 전체 보기](#땅굴-메인--내-땅굴--방명록-전체-보기) / 탐색 → 내 캠퍼스-층 들판([05 탐색 · 방문](05-explore-visit.md#땅굴-메인--탐색))
- 공통: [00 공통](00-common.md) 1 GNB, 13 땅굴 화면 공통(모드 전환)

1. **땅굴 꾸미기**: “땅굴 꾸미기”를 누르면 꾸미기 모드로 들어가 두더지를 꾸민다. 가구는 세부 관심사마다 하나로 정해져 있어 고르지 않는다([영역 규칙](#가구와-땅굴-무드)).
2. **상태 배지**: 단골 N명. 숫자만 보여주고 누구인지는 보여주지 않는다.
3. **땅굴 · 가구**: 내 땅굴을 화면 전체에 보여준다. 고른 세부 관심사마다 가구가 하나씩 놓여 있다. 가구를 누르면 그 가구의 관심사 이름을 말풍선으로 보여준다.
4. **내 정보 카드**: 닉네임과 캠퍼스 · 기수 · 층, 자기소개, 관심사 태그를 보여준다.
5. **내 정보 수정 (연필 버튼)**: 닉네임 옆 연필 버튼을 누르면 내 정보 수정이 열린다(오른쪽 카드가 수정 화면으로 바뀐다). 닉네임, 캠퍼스 · 층, 두더지, 관심사, 질문 · 답변, 자기소개를 바꿀 수 있다 → [땅굴 – 내 정보 수정](#땅굴--내-정보-수정).
6. **자기소개 빈 상태**: 자기소개가 없으면 안내 문구와 “자기소개 쓰기”를 보여준다. 누르면 내 정보 수정이 열린다.
7. **Q&A**: 관심사 아래에 질문 3개와 답변을 펼친 채로 보여준다.
8. **우체통 (방명록)**: 방 안의 3D 우체통으로 방명록이 있는지 보여준다. 글이 하나라도 있으면 깃발이 올라가고 편지와 은은한 빛이 보이며, 없으면 꺼진다. 누르면 방명록 전체 보기가 열린다. 내 땅굴에서는 글을 쓸 수 없다. 새 글이 달리면 알림(땅굴 종류)이 온다 → [09 알림](09-notification.md).
9. **접기**: “접기 >”를 누르면 내 정보 카드가 접혀 땅굴이 넓게 보인다. 접힌 상태와 다시 펼치는 방법은 [꾸미기 안내 말풍선 · 카드 접기](#땅굴-메인--내-땅굴--꾸미기-안내-말풍선--카드-접기) 2번을 따른다.

## 땅굴 메인 – 내 땅굴 · 꾸미기 안내 말풍선 · 카드 접기

- 들어오는 곳: [내 땅굴](#땅굴-메인--내-땅굴)에서 “땅굴 꾸미기” 버튼에 마우스를 올렸을 때(말풍선)
- 나가는 곳: 땅굴 꾸미기 → [꾸미기 모드](#땅굴--꾸미기-모드--두더지-탭)
- 공통: [00 공통](00-common.md) 1 GNB, 13 땅굴 화면 공통

1. **꾸미기 안내 말풍선**: “땅굴 꾸미기” 버튼에 마우스를 올렸을 때만 보이고, 벗어나면 사라진다. 닫기(X) 버튼은 없다.
2. **카드 접기 · 펼치기**: “접기”를 누르면 내 정보 카드가 접혀 땅굴이 넓게 보인다. 접힌 동안에는 “방노트” 버튼이 생기고, 누르면 다시 펼쳐진다.

## 땅굴 메인 – 내 땅굴 · 방명록 전체 보기

- 들어오는 곳: [내 땅굴](#땅굴-메인--내-땅굴) 방 안의 우체통
- 나가는 곳: 닫기 → [내 땅굴](#땅굴-메인--내-땅굴) / 삭제 → [방명록 삭제 확인](#땅굴-메인--내-땅굴--방명록-삭제-확인) / 신고 → 신고 팝업([08 커뮤니티](08-community.md)) / 작성자 → 프로필 팝업
- 공통: [00 공통](00-common.md) 4 사용자 표시, 6 팝업 · 모달, 7 빈 상태, 8 시간 표기

1. **제목 · 글 수**: “방명록” 제목과 글 수. 글이 달리거나 지워지면 바뀐다.
2. **방명록 글**: 방문자가 남긴 글을 작성자, 쓴 시각, 본문으로 보여준다. 최신순이고 정렬은 바꿀 수 없다. 글은 시간이 지나도 지워지지 않는다. 신고로 가려진 글은 목록과 글 수에서 빠진다 → [영역 규칙](#방명록-글이-만들어지고-없어지는-때). 주인은 글을 쓰거나 고칠 수 없다. 글이 없으면 “아직 아무도 방명록을 남기지 않았어요”.
3. **삭제 · 신고**: 글마다 있다. “삭제”는 방명록 삭제 확인을 열고, “신고”는 신고 팝업([08 커뮤니티](08-community.md))을 연다.
4. **페이지**: 한 페이지에 5개씩 보여준다. 글이 6개 이상이면 페이지 번호로 넘긴다.

## 땅굴 메인 – 내 땅굴 · 방명록 삭제 확인

- 들어오는 곳: [방명록 전체 보기](#땅굴-메인--내-땅굴--방명록-전체-보기)의 “삭제”
- 나가는 곳: 취소 → 방명록 전체 보기 / 삭제 → 방명록 전체 보기(그 글이 빠진 상태)
- 공통: [00 공통](00-common.md) 6 팝업 · 모달, 16 완료 토스트, 17 삭제 확인

1. **확인 문구**: “{작성자 닉네임}님의 방명록을 삭제할까요?” 지우면 내 땅굴에서 사라져 되돌릴 수 없고, 작성자에게는 알림이 가지 않는다고 안내한다.
2. **취소 / 삭제**: “삭제”를 누르면 그 글을 지우고 방명록 글 수를 줄인다.

## 땅굴 – 꾸미기 모드 · 두더지 탭

- 들어오는 곳: [내 땅굴](#땅굴-메인--내-땅굴)의 “땅굴 꾸미기”
- 나가는 곳: 저장하기 · 취소 · 닫기 → [내 땅굴](#땅굴-메인--내-땅굴)
- 공통: [00 공통](00-common.md) 1 GNB, 6 팝업 · 모달, 16 완료 토스트, 18 저장 전 취소

꾸미기 모드에는 두더지 탭만 있다. 고른 내용은 저장하기 전에도 땅굴 안 두더지에 바로 보인다.

1. **지금 착용 중**: 두더지가 지금 걸친 아이템을 보여준다.
2. **부위 탭**: 머리, 얼굴, 목, 손 가운데 꾸밀 부위를 고른다.
3. **아이템 고르기**: 부위마다 하나를 고르므로 최대 4개를 걸친다. “없음”을 고르면 그 부위의 아이템을 벗는다. 고르면 땅굴 안 두더지에 바로 보인다. 관심사 전용 아이템은 없고, 모든 아이템을 처음부터 고를 수 있다. 아이템 종류는 [온보딩](03-onboarding.md) 1의 두더지 꾸미기와 같다.
4. **취소 / 저장하기**: 저장하면 내 땅굴과, 다른 땅굴에 놀러 갔을 때의 내 두더지 모습에 반영된다.

## 땅굴 – 내 정보 수정

- 들어오는 곳: [내 땅굴](#땅굴-메인--내-땅굴) 내 정보 카드의 연필 버튼, “자기소개 쓰기”
- 나가는 곳: 저장하기 · 취소 · 뒤로(←) → 내 정보 카드로 돌아감 / 관심사 고르기 → [내 정보 수정 · 관심사 고르기](#땅굴--내-정보-수정--관심사-고르기)(고르기 완료 · 취소하면 내 정보 수정으로 돌아옴) / 질문 옆 ↻ 아이콘 → [온보딩](03-onboarding.md) 3과 같은 질문 목록(고르면 내 정보 수정으로 돌아옴)
- 공통: [00 공통](00-common.md) 16 완료 토스트, 18 저장 전 취소

1. **닉네임**: 규칙은 [온보딩](03-onboarding.md) 1의 닉네임 입력과 같다. 다른 사람과 겹치면 오류 문구를 보여주고 저장할 수 없다.
2. **기수 · 캠퍼스 · 층**: 캠퍼스와 층은 목록에서 골라 바꾼다([00 공통](00-common.md) 19). 캠퍼스를 바꾸면 층을 다시 고른다. 저장하면 내 땅굴이 새 캠퍼스-층의 들판으로 옮겨지고 있던 자리는 빈다. 단골 · 방명록 · 대화는 그대로다. 기수는 SSAFY 인증([회원가입](02-auth.md) 3)에 쓴 값이라 보여주기만 한다. 반은 받지 않는다.
3. **관심사**: “관심사 고르기”를 누르면 관심사 고르기 화면이 열려 전체 분야에서 다시 고른다. 칩의 ✕로 바로 뺄 수도 있다. 관심사를 바꾸면 땅굴 가구도 바뀐다 → [영역 규칙](#가구와-땅굴-무드). 고르기를 마치면 내 정보 수정으로 돌아와 칩에 반영되고, “저장”을 눌러야 저장된다.
4. **질문 · 답변**: 질문 말풍선 옆 ↻ 아이콘을 누르면 그 질문만 다시 고른다. 질문 목록에서 새 질문을 고르면 내 정보 수정으로 돌아와 그 자리의 질문이 바뀌고 답변 칸이 비워진다. 답을 쓰고 “저장”을 눌러야 반영된다(화면 구성은 디자인에서 바뀔 수 있다). 횟수 제한은 없다. 답변 규칙은 [온보딩](03-onboarding.md) 3과 같다. 글자 수는 입력 중인 답변에만 보여준다.
5. **자기소개**: 최대 150자, 선택 입력. 비우고 저장하면 내 정보 카드가 “아직 작성한 자기소개가 없어요.” 상태로 돌아간다.
6. **취소 / 저장하기**: 저장하면 오른쪽 패널이 내 정보 카드로 돌아가고 바로 반영한다. 필수 조건을 못 채우면 저장할 수 없다.
7. **패널 · 스크롤**: 연필 버튼을 누르면 오른쪽 내 정보 카드가 수정 패널로 바뀐다(팝업 아님). 항목이 패널 높이를 넘으면 가운데만 스크롤되고, 제목줄과 취소 / 저장하기는 고정한다. Figma 화면 옆의 긴 패널은 전체 길이를 펼친 참고용이다.

## 땅굴 – 내 정보 수정 · 관심사 고르기

- 들어오는 곳: [내 정보 수정](#땅굴--내-정보-수정)의 “관심사 고르기”
- 나가는 곳: 고르기 완료 → 내 정보 수정(고른 관심사가 칩에 반영, 저장은 내 정보 수정에서) / 취소 · “내 정보 수정으로” → 내 정보 수정(바꾼 관심사는 버림)
- 공통: [00 공통](00-common.md) 1 GNB, 18 저장 전 취소. 선택 개수, 10개 초과 안내는 [온보딩](03-onboarding.md) 2와 같다

1. **전체 분야에서 다시 고르기**: 왼쪽 분야 목록에서 분야를 고르면 오른쪽에 그 분야의 관심사 태그가 나온다. 태그를 눌러 더 고르거나 뺀다. 3개 이상, 최대 10개.
2. **지금 고른 관심사**: 내 정보에 저장된 관심사가 선택된 채로 열린다. 고른 관심사가 아래 “선택한 관심사”에 모이고, ×를 누르면 바로 뺀다.
3. **취소 / 고르기 완료**: “고르기 완료”는 3개 이상 골랐을 때 누를 수 있고, 누르면 내 정보 수정으로 돌아가 관심사 칩에 바로 반영한다. 실제 저장은 내 정보 수정의 “저장하기”를 눌렀을 때 되고, 그때 새 관심사의 가구가 방에 놓인다. “취소”는 바꾼 관심사를 버리고 내 정보 수정으로 돌아간다. 바꾼 내용이 있으면 [00 공통](00-common.md) 18 저장 전 취소를 먼저 띄운다.
4. **내 정보 수정으로 (뒤로가기)**: 화면 왼쪽 위의 “‹ 내 정보 수정으로”를 누르면 “취소”와 같이 바꾼 관심사를 버리고 내 정보 수정으로 돌아간다. 고른 관심사를 바꾼 상태라면 [00 공통](00-common.md) 18 저장 전 취소 확인을 먼저 띄운다.

## 영역 규칙

### 가구와 땅굴 무드

- 땅굴에는 세부 관심사마다 정해진 가구가 하나씩 놓인다(큰 것은 바닥·벽, 작은 것은 선반). 사용자는 가구를 고르지 않는다([00 공통](00-common.md) 5). 대분류마다 따로 놓이는 가구는 없다. 가구가 놓이는 자리는 정해져 있어 옮기거나 뺄 수 없다.
- 내 정보 수정에서 관심사를 바꾸면, 뺀 관심사의 가구는 사라지고 새 관심사의 가구가 놓인다.
- 땅굴 무드(벽 · 바닥)는 대표 관심사(내 관심사 목록의 맨 앞 것)가 속한 대분류로 정해지고, 대표 관심사가 달라질 때만 바뀐다.

### 방명록 글이 만들어지고 없어지는 때

방명록은 이 문서(주인 쪽)와 [05 탐색 · 방문](05-explore-visit.md#땅굴--방문자-뷰--방명록)(방문자 쪽)에 나뉘어 있다. 아래는 두 문서의 항목을 한데 모은 것이고, 규칙의 기준은 “적힌 곳”의 항목이다.

| 때 | 일어나는 일 | 적힌 곳 |
|---|---|---|
| 방문자가 “남기기”를 누른다 | 글이 목록 맨 위에 올라간다. 주인에게 알림(땅굴 종류)이 간다 | 05 방문자 뷰 · 방명록 1, 내 땅굴 8 |
| 서로 다른 3명이 신고한다 | 글이 가려져 목록과 글 수에서 빠진다. 주인, 방문자, 쓴 사람 모두에게 보이지 않는다. 관리자가 복구하면 다시 보인다 | 방명록 전체 보기 2, 05 방문자 뷰 · 방명록 2, [08 커뮤니티](08-community.md#커뮤니티--신고-팝업) 신고 팝업 4 |
| 주인이 “삭제”를 누른다 | 확인을 거쳐 글을 지운다. 작성자에게는 알림이 가지 않는다 | 방명록 전체 보기 3, 방명록 삭제 확인 1 · 2 |
| 쓴 사람이 자기 글의 “삭제”를 누른다 | 방명록 삭제 확인을 연다 | 05 방문자 뷰 · 방명록 3 |

- 주인은 자기 땅굴의 방명록에 글을 쓸 수 없다(내 땅굴 8, 방명록 전체 보기 2).
- 쓴 글은 주인도 쓴 사람도 고칠 수 없다(방명록 전체 보기 2, 05 방문자 뷰 · 방명록 1).
- 글은 시간이 지나도 자동으로 지워지지 않는다. 주인이나 쓴 사람이 지울 때, 주인이 탈퇴할 때, 관리자가 지울 때만 없어진다(방명록 전체 보기 2).
- 가려진 글은 보이지 않으므로 주인도 쓴 사람도 지울 수 없다. 관리자가 복구하거나 지울 때까지 가려진 채로 남는다.

## 아직 정하지 않은 것

- 내 정보 수정 4: 질문을 다시 고르는 흐름의 화면 구성은 디자인에서 바뀔 수 있다고 적혀 있다.

서로 맞지 않아 보인 곳:

- 내 땅굴 5는 내 정보 수정에서 “두더지”도 바꿀 수 있다고 적는다. 내 정보 수정 화면에는 두더지 항목이 없고, 두더지는 꾸미기 모드 · 두더지 탭에서 바꾼다.
- 내 정보 수정 3 · 4는 버튼을 “저장”으로, 내 정보 수정 6과 관심사 고르기 3은 “저장하기”로 적는다.
- 내 땅굴 9는 “접기 >”, 카드 접기 2는 “접기”로 적는다.
- 방명록 삭제 확인은 들어오는 곳이 내 땅굴의 방명록 전체 보기뿐이고, 확인 문구(“{작성자 닉네임}님의 방명록을 삭제할까요?”, 내 땅굴에서 사라진다, 작성자에게 알림이 가지 않는다)도 주인 기준이다. 그런데 [05 방문자 뷰 · 방명록](05-explore-visit.md#땅굴--방문자-뷰--방명록) 3은 방문자가 자기 글을 지울 때도 방명록 삭제 확인을 연다고 적는다. 방문자가 자기 글을 지울 때의 확인 문구가 없다.
- 꾸미기 안내 말풍선 · 카드 접기 화면의 들어오는 곳 · 나가는 곳에는 말풍선만 적혀 있고, 카드 접기(“접기” → “방노트”로 다시 펼침)는 빠져 있다.
- 방명록 전체 보기는 나가는 곳에 “작성자 → 프로필 팝업”이 있지만 공통 목록에 15 프로필 팝업이 없다. 같은 구성인 05 방문자 뷰 · 방명록의 공통 목록에는 있다.
