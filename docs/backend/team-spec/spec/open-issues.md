# 아직 정하지 않은 것

명세 본문에 반영하지 못한 것을 모은다. 정해지면 여기서 지우고 해당 문서에 쓴다. 영역 문서 끝의 "아직 정하지 않은 것"은 그 영역 안의 세부이고, 이 문서는 여러 영역에 걸친 것과 남은 검토 항목을 다룬다.

## 보류한 결정

- **관리자 화면의 세부**: 누가 관리자이고 어떤 일을 화면으로 하는지는 [11 관리자](11-admin.md)에 있다. 화면 구성과 신고 처리 흐름은 추후 정한다.
- **계정 정지의 나머지 규칙**: 정지된 계정이 로그인할 때 사유와 기간을 팝업으로 알리는 것까지 정했다. 정지 중 그 사람의 땅굴 · 글 · 연 모임이 다른 사람에게 어떻게 보이는지, 기간이 끝나면 자동으로 풀리는지는 관리자 화면과 함께 정한다.
- **새 학기 들판을 여는 방법**: 팀이 직접 여는지, 정해진 날짜에 자동으로 열리는지는 관리자 화면과 함께 정한다.
- **프로필 사진**: 선택 사항으로 받기로 했다. 어디서 올리고 어느 화면에 보여주는지는 정하지 않았다.
- **추천을 받을 때의 선택**: 캠퍼스 · 층이나 기수를 고르지 않고 전체에서 받을 수 있는지는 정하지 않았다.

## 임시 값

- 캠퍼스와 층 목록(화면 예시: 서울 · 대전 · 부울경 · 구미 · 광주, 1 ~ 20층)

## Figma 화면 그림이 명세와 다른 곳

글은 맞췄지만 그림을 아직 고치지 못한 곳이다.

- 정지 안내 팝업 화면이 없다
- 설정 – 알림 설정 화면에 "브라우저 알림 받기" 스위치가 없다
- 온보딩 3a 화면의 무드 근거가 "가장 큰 취향 · 태그 3개"로 그려져 있다(명세는 대표 관심사)
- 회원가입 3 화면의 기수 칸이 입력 칸으로 그려져 있다(명세는 목록에서 고르기)
- 커뮤니티 글 상세의 항목 번호가 11 다음 13이다(12번은 차단 기능을 없애며 지움)
- 모임 상세 명세에 주최자 카드(주최자 표시, 주최자 땅굴 놀러 가기)를 설명하는 항목이 없다
- 견본 방 화면은 방문자 뷰를 복제한 것이라 두더지가 둘 그려져 있다
- 꾸미기 모드 · 가구 탭 화면이 남아 있다(가구는 관심사마다 하나로 정해져 있어 고르지 않는다)
- 추천 친구 설정 화면에 관심사 · 질문 조건이 남아 있고, 질문 고르기 화면이 남아 있다(명세는 캠퍼스 · 층과 기수만 고른다)
- 모임 만들기 화면에 캠퍼스 칸과 플랫폼 이름 칸이 남아 있다(명세는 둘 다 없다)
- 온보딩 1의 안내가 실명과 사진을 받지 않는다고 적혀 있다(명세는 프로필 사진이 선택이다)
- 온보딩 4 화면의 땅굴 정보 카드에 캠퍼스 · 기수 · 층이 없다(명세는 보여준다)

## 디자인 시안(Figma 03 Screens)이 명세와 다른 곳

디자인 쪽에 알려 맞춰야 하는 차이다. 기능이 다른 것만 적었고, 생김새의 차이는 문제 삼지 않는다.

- 소속 표기가 "기수 · 지역 · 반"이다(명세는 캠퍼스 · 기수 · 층, 반 없음)
- 내 정보 카드와 내 정보 수정에 질문 · 답변이 없고, 캠퍼스 · 층을 고치는 칸이 없다
- 내 땅굴에 제목 · 안내 문구, 관심사 가구 수, 단골 수가 없다
- 꾸미기 안내 말풍선에 X 버튼이 있다(명세는 마우스를 올렸을 때만 보이고 X 없음)
- 온보딩 1 헤더에 "건너뛰기"가 있고, 3a에 "적어 주신 문장"이 남아 있다
- 추천 시안에 자동 모달, "오늘 하루 보지 않기", "다른 이웃 보기"가 남아 있다. 이름이 "오늘의 이웃"이다(명세는 "오늘의 추천 친구")
- 학기 선택, 탐색의 캠퍼스-층 버튼과 "캠퍼스-층 고르기" 화면이 없다
- 새 학기 안내(`1465:15925`, 탐색 버튼 알림 `1466:16137`)가 내 땅굴에서 탐색을 누를 때 뜨고 "나중에 하기"와 닫기로 미룰 수 있다. 탐색 버튼에 빨간 알림 점과 말풍선이 붙는다(명세는 접속하면 뜨고, 고르기 전에는 닫을 수 없다. 알림 점과 말풍선은 없다)
- 차단 아이콘 · 메뉴 · 차단한 사용자 댓글 · 차단 관리 화면이 남아 있으면 빼야 한다(차단 기능 없음)
- 탐색 · 방문: 단골 추가 버튼, 단골 땅굴 버튼과 목록, 방노트의 신고 아이콘, 방노트의 질문 3개와 답변, 추천 카드의 접힌 모서리가 없다. 추천 카드에 "겹치는 관심사 N개" 문구가 남아 있다
- 채팅: 가운데 찻방 그림이 없다. 오른쪽 상대 정보 패널과 모임 정보 패널, "접속 중" 배지, 채팅방 모양의 "요청 대기 중" 화면과 목록의 "대기 중" 대화, 요청 탭의 대화 / 모임 구분과 모임 신청 화면이 남아 있다. 필터 숫자가 받은 요청 + 보낸 요청이다(명세는 받은 요청만). 1:1 "대화 나가기" 버튼이 없다
- 모임: 분류가 관심사 칩이고 "내 관심사" 필터가 있다(명세는 카테고리). 날짜 · 방식 필터가 없다. 정렬 값이 "최신등록순 / 게시순 / 마감임박순 / 인원순"이다(명세는 가까운 날짜순 / 최신등록순 / 인기순 / 인원순). 검색 안내가 "모임, 관심사 검색"이다(명세는 모임 이름, 소개). "땅굴 지도에 표지판" 문구가 남아 있다
- 설정: 메뉴에 로그아웃이 없고 "앱 설정 · 언어 설정"과 버전 정보 화면이 있다. 알림 설정이 6종 + 방해 금지 시간 + 저장하기다(명세는 5종, 즉시 저장). 비밀번호 규칙 문구에 쓸 수 있는 특수기호(`!@#$%`)가 없다. 회원 탈퇴에 Google 계정용 인증이 없다. 공지사항 상세, 탈퇴 확인, 로그아웃 확인 화면이 없다

## 명세에 글이 없는 곳

화면이나 규칙이 필요해 보이지만 어디에도 적혀 있지 않은 것이다. 영역 안의 세부는 각 영역 문서의 끝에 있다.

- 모임: 지난 모임이나 취소된 모임을 참여 확정자, 주최자, 신청 대기자가 열었을 때의 행동 카드(상태 표는 미신청인 사람만 다룬다)
- 모임: 신청 취소, 참여 취소, 모임 취소의 확인 팝업 문구와 화면(거절, 내보내기, 삭제만 팝업이 있다)
- 모임: 참여 확정자가 없는 모임을 삭제할 때 모임 대화방이 어떻게 되는지
- 채팅: 1:1 "대화 나가기"의 확인 팝업 화면과 문구
- 로그인: 로그인 화면으로 보내진 사람이 로그인한 뒤 열려던 화면으로 가는지(모임 상세와 글 상세만 "로그인하면 이 화면으로 온다"고 적혀 있다)
