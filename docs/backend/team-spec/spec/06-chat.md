## 채팅 – 대화 선택 전

- 들어오는 곳: GNB “채팅”
- 나가는 곳: 대화 고르기 → [1:1 대화](#채팅--11-대화) · [모임 대화](#채팅--모임-대화) / 필터 “요청” → [받은 요청](#채팅--요청--받은-요청) / “땅굴 둘러보기” → 탐색([05 탐색 · 방문](05-explore-visit.md#땅굴-메인--탐색)) / “받은 요청 보기” → [받은 요청](#채팅--요청--받은-요청)
- 공통: [00 공통](00-common.md) 1 GNB, 14 채팅 공통

1. **찻방 (대화 선택 전)**: 채팅은 왼쪽 목록, 가운데 찻방, 오른쪽 대화 창의 세 칸이다. 찻방은 모든 대화가 같이 쓰는 채팅 전용 방이다. 고른 대화가 없으면 내 두더지 혼자 찻상 앞에 앉아 있고 맞은편 자리는 비어 있다.
2. **빈 상태 안내**: 대화 창 자리에 “아직 고른 대화가 없어요”와 안내 문구를 보여준다.
3. **안내 버튼**: “땅굴 둘러보기”는 내 캠퍼스-층 들판(탐색, [05 탐색 · 방문](05-explore-visit.md#땅굴-메인--탐색))으로 간다. “받은 요청 보기”는 요청 탭의 받은 요청으로 가고, 내가 받은 대화 요청 수를 함께 보여준다.

## 채팅 – 1:1 대화

- 들어오는 곳: 대화 목록 / [받은 요청](#채팅--요청--받은-요청)의 “수락하고 대화하기” / [방문자 뷰](05-explore-visit.md#땅굴--방문자-뷰)의 “대화하기” / [대화 요청 팝업](05-explore-visit.md#땅굴--방문자-뷰--대화-요청-팝업)의 “요청 보내기”(내가 거절한 요청이 남아 있는 사람에게 보냈을 때)
- 나가는 곳: 사용자 표시 · 상대 두더지 → 프로필 팝업 / “대화 나가기” → [대화 선택 전](#채팅--대화-선택-전) / 모임 카드의 “모임 보기” → 모임 상세([07 모임](07-meetup.md))
- 공통: [00 공통](00-common.md) 1 GNB, 4 사용자 표시, 8 시간 표기, 14 채팅 공통, 15 프로필 팝업

1. **찻방**: 나와 상대의 두더지가 찻상에 마주 앉아 차를 마신다. 두더지는 각자 꾸민 모습이고 아래에 닉네임을 보여준다. 상대 두더지를 누르면 프로필 팝업이 열린다.
2. **대화 창 헤더**: 상대의 사용자 표시와 겹치는 관심사 수. 사용자 표시를 누르면 프로필 팝업이 열리고, 신고는 그 팝업의 아이콘으로 한다. “접속 중” 표시는 없다.
3. **대화 나가기**: 누르면 확인을 거쳐 이 대화가 내 목록에서 사라진다. 상대의 목록에는 남되 읽기 전용이 된다: 대화 창 맨 끝에 “상대방이 대화방을 나갔습니다”가 표시되고 메시지를 보낼 수 없다. 그 뒤로는 두 사람 모두 상대 땅굴에서 “대화 요청하기”가 보이고, 다시 이야기하려면 대화 요청부터 한다. 다시 요청해 수락되면 빈 대화방이 새로 생기고, 남아 있던 사람의 예전 대화는 읽기 전용으로 따로 남는다. 상대가 탈퇴한 대화방도 같은 방식이다: 내 목록에 남고 읽기 전용이 되며 맨 끝에 “상대방이 탈퇴했습니다”가 표시된다.
4. **대화 시작 안내**: “{닉네임}님이 대화 요청을 수락했어요”와 두 사람의 겹치는 관심사 태그.
5. **메시지**: 내 메시지는 오른쪽, 상대 메시지는 왼쪽에 보낸 시각과 함께 보여준다. 새 메시지가 오면 맨 아래로 내려간다. 메시지 지우기와 읽음 표시는 없다.
6. **모임 카드**: 모임 상세에서 복사한 모임 링크를 메시지로 보내면 모임 카드로 바뀌어 보인다(모임 대화에서도 같다). 모임 이름, 일시, 인원과 “모임 보기”를 보여주고, 누르면 모임 상세([07 모임](07-meetup.md))로 간다.
7. **메시지 입력창**: 사진 첨부, 입력, 이모지, 보내기. 사진은 메시지 하나에 3장까지 붙인다. 글 없이 사진만 보낼 수 있고, 글도 사진도 없는 메시지는 보낼 수 없다.

## 채팅 – 모임 대화

- 들어오는 곳: 대화 목록의 모임 대화 / 모임 상세의 채팅([07 모임](07-meetup.md))
- 나가는 곳: “모임 정보” → [모임 정보 팝업](#채팅--모임-대화--모임-정보-팝업) / 참여자의 사용자 표시 · 두더지 → 프로필 팝업
- 공통: [00 공통](00-common.md) 1 GNB, 4 사용자 표시, 8 시간 표기, 14 채팅 공통, 15 프로필 팝업

1. **찻방 (모임)**: 참여자들의 두더지가 찻상에 둘러앉는다. 몇 마리까지 그릴지는 구현 단계에서 정한다. 두더지를 누르면 프로필 팝업이 열린다.
2. **대화 창 헤더 · 모임 정보**: 모임 이름, 참여 인원, 일시와 장소. “모임 정보”를 누르면 모임 정보 팝업이 열린다.
3. **공지**: 주최자가 올린 공지를 대화 맨 위에 고정한다. 공지는 하나만 둔다. 주최자에게만 공지 줄에 쓰기 · 고치기 · 지우기가 보인다. 공지가 없으면 참여자에게는 공지 줄이 보이지 않는다.
4. **참여 알림**: “{닉네임}님이 모임에 참여했어요” 같은 안내를 가운데에 보여준다.
5. **메시지**: 보낸 사람의 사용자 표시와 “주최” 표시를 함께 보여준다. 나머지는 [1:1 대화](#채팅--11-대화)와 같다. 모임 링크를 보내면 모임 카드로 보이는 것은 1:1 대화의 모임 카드와 같다.
6. **메시지 입력창**: [1:1 대화](#채팅--11-대화)와 같다.

## 채팅 – 모임 대화 · 모임 정보 팝업

- 들어오는 곳: [모임 대화](#채팅--모임-대화) 헤더의 “모임 정보”
- 나가는 곳: “모임 상세 보기” → 모임 상세([07 모임](07-meetup.md)) / “모임 나가기” → [모임 나가기 확인 팝업](#채팅--모임-대화--모임-나가기-확인-팝업) → \[예\] [대화 선택 전](#채팅--대화-선택-전) / 닫기 → 모임 대화
- 공통: [00 공통](00-common.md) 4 사용자 표시, 6 팝업 · 모달, 15 프로필 팝업

1. **모임 정보**: 카테고리, 일시, 장소, 확정 인원.
2. **참여자**: 참여자 수와 사용자 표시. 주최자는 “주최”, 나는 “나”로 표시한다. 사용자 표시를 누르면 프로필 팝업이 열린다.
3. **모임 상세 보기**: 모임 상세([07 모임](07-meetup.md))로 간다.
4. **모임 나가기**: 모임 상세([07 모임](07-meetup.md))의 “참여 취소”와 같은 동작이다. 확인을 거쳐 참여가 취소되고 이 대화가 내 목록에서 사라진다. 시작 24시간 전까지만 할 수 있다. 그 뒤부터 모임이 끝나기 전까지는 버튼이 꺼지고 나갈 수 없다(모임 상세의 “참여 취소”가 꺼지는 것과 같다). 주최자에게는 모임이 끝나거나 취소되기 전까지 이 버튼을 보여주지 않는다. 모임이 끝났거나 취소된 뒤에는 참여 취소 없이 대화방에서만 나간다(주최자 포함 누구나). 이때 참여 기록은 그대로 남는다. 끝난 모임과 취소된 모임의 대화방도 계속 남는다. 참여 취소 · 내보내기된 사람은 자동으로 대화방에서 나간다. 누르면 “정말 나가시겠습니까?” 확인 팝업이 뜬다. \[예\]를 누르면 모임에서 나가고 토스트 “모임을 나갔어요”가 뜬다.

## 채팅 – 요청 · 받은 요청

- 들어오는 곳: 필터 “요청 N” / [대화 선택 전](#채팅--대화-선택-전)의 “받은 요청 보기” / 대화 요청 알림([09 알림](09-notification.md)) / 알림 팝업의 “채팅 요청”([09 알림](09-notification.md))
- 나가는 곳: “거절” → [거절 확인 팝업](#채팅--요청--받은-요청--거절-확인-팝업) / “수락하고 대화하기” → [1:1 대화](#채팅--11-대화) / “보낸 요청” → [보낸 요청](#채팅--요청--보낸-요청) / “땅굴 놀러 가기” → [방문자 뷰](05-explore-visit.md#땅굴--방문자-뷰) / 사용자 표시 → 프로필 팝업
- 공통: [00 공통](00-common.md) 1 GNB, 4 사용자 표시, 5 관심사 태그, 14 채팅 공통, 15 프로필 팝업

1. **필터 “요청 N”**: N은 내가 받은 대화 요청 수만 센다. 내가 보낸 요청은 세지 않는다.
2. **요청 화면**: 요청 탭에서는 찻방과 대화 창 대신 가운데에 요청 목록, 오른쪽에 고른 요청의 사람 정보를 보여준다. 채팅에서는 대화 요청만 다룬다. 모임 참여 신청과 승인은 모임([07 모임](07-meetup.md))에서 처리한다.
3. **받은 요청 / 보낸 요청**: 두 목록을 바꿔 본다. 이름 옆에 각각의 건수를 보여준다.
4. **받은 요청 카드**: 요청한 사람의 사용자 표시, 요청 시각, 겹치는 관심사 태그, 첫 메시지를 최신순으로 보여준다. 카드를 누르면 오른쪽에 요청 보낸 사람 정보가 뜬다.
5. **거절 / 수락하고 대화하기**: 거절하면 내 목록에서 요청이 없어지고 상대에게 알리지 않는다. 보낸 사람 쪽에는 그대로 “답변 기다리는 중”과 “요청 보냄”으로 보인다. 거절한 뒤 그 요청이 만료되기 전에 내가 그 사람에게 대화 요청을 보내면, 거절했던 요청을 수락한 것으로 처리해 바로 1:1 대화방이 열린다([05 탐색 · 방문](05-explore-visit.md#땅굴--방문자-뷰--대화-요청-팝업) 대화 요청 팝업 3). 요청은 보낸 지 5일이 지나면 만료되어 양쪽에서 사라진다. 수락하면 그때 1:1 대화방이 만들어져 열리고 찻방에 두 두더지가 마주 앉는다. 수락 전에는 대화방이 없다. 상대에게 수락 알림이 간다([09 알림](09-notification.md)). 거절을 누르면 “요청을 거절하시겠습니까?” 확인 팝업이 뜬다. \[예\]를 누르면 목록에서 빠지고 토스트 “요청을 거절했어요”가 뜬다.
6. **요청 보낸 사람 프로필**: 고른 요청을 보낸 사람의 프로필을 모두 보여준다: 두더지, 닉네임, 캠퍼스 · 기수 · 층, 자기소개, 관심사(겹치는 관심사는 체크로 표시), 질문 3개와 답변. [방문자 뷰 방노트](05-explore-visit.md#땅굴--방문자-뷰--방노트)의 주인 정보와 같은 내용이다. “땅굴 놀러 가기”를 누르면 그 사람의 땅굴(방문자 뷰)로 간다.

## 채팅 – 요청 · 보낸 요청

- 들어오는 곳: 요청 탭의 “보낸 요청” / [대화 요청 완료 토스트](05-explore-visit.md#땅굴--방문자-뷰--대화-요청-완료-토스트)의 “채팅 보기”
- 나가는 곳: “요청 취소” → 카드가 사라짐 / 상대가 수락 → 1:1 대화방이 생김 / “받은 요청” → [받은 요청](#채팅--요청--받은-요청) / “땅굴 놀러 가기” → [방문자 뷰](05-explore-visit.md#땅굴--방문자-뷰)
- 공통: [00 공통](00-common.md) 1 GNB, 4 사용자 표시, 5 관심사 태그, 14 채팅 공통, 15 프로필 팝업

1. **보낸 요청 카드**: 내가 보낸 대화 요청은 여기서만 본다. 받은 요청과 같은 모양의 카드에 받는 사람의 사용자 표시, 보낸 시각, 겹치는 관심사 태그, 내가 쓴 메시지, “답변 기다리는 중” 상태를 보여준다. 수락되기 전에는 대화방이 만들어지지 않고 대화 목록에도 나오지 않는다. 카드를 누르면 오른쪽에 요청 받은 사람 정보가 뜬다. 보낸 지 5일이 지나면 요청이 만료되어 카드가 사라지고, 방문자 뷰의 버튼은 다시 “대화 요청하기”가 된다. 상대가 거절한 요청도 그때까지는 그대로 보인다.
2. **요청 취소**: 요청이 만료되기 전에는 언제든 취소할 수 있다. 상대가 이미 거절한 요청도 똑같이 취소된다(거절된 것이 드러나지 않게 한다). 취소하면 카드가 사라지고 상대의 받은 요청에서도 사라진다. 상대에게 알리지 않고, 방문자 뷰의 버튼은 다시 “대화 요청하기”가 된다.
3. **요청 받은 사람 프로필**: [받은 요청](#채팅--요청--받은-요청) 화면의 “요청 보낸 사람 프로필”과 같다. 요청을 받은 사람의 자기소개, 관심사, 질문 3개와 답변까지 모두 보여준다.

## 채팅 – 모임 대화 · 모임 나가기 확인 팝업

- 들어오는 곳: [모임 정보 팝업](#채팅--모임-대화--모임-정보-팝업)의 “모임 나가기”
- 나가는 곳: \[예\] → [대화 선택 전](#채팅--대화-선택-전)([모임 나감 토스트](#채팅--모임-나감-토스트)) / \[아니오\] → 모임 정보 팝업
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **확인 팝업**: 모임 정보 팝업 위에 “정말 나가시겠습니까?”를 띄운다.
2. **아니오**: 팝업을 닫고 모임 정보 팝업으로 돌아간다.
3. **예**: 모임에서 나간다. 모임 상세([07 모임](07-meetup.md))의 “참여 취소”와 같은 동작이다. 모임이 끝났거나 취소된 뒤에는 참여 취소 없이 대화방에서만 나간다([모임 정보 팝업](#채팅--모임-대화--모임-정보-팝업) 4). 어느 경우든 이 대화가 목록에서 빠지고 대화 선택 전으로 가며, 토스트 “모임을 나갔어요”가 뜬다.

## 채팅 – 모임 나감 토스트

- 들어오는 곳: [모임 나가기 확인 팝업](#채팅--모임-대화--모임-나가기-확인-팝업)의 \[예\]
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **토스트**: “모임을 나갔어요”가 화면 아래 가운데에 잠깐 떴다가 사라진다.
2. **대화 목록**: 나간 모임의 대화가 목록에서 빠진 상태로 대화 선택 전 화면을 보여준다.

## 채팅 – 요청 · 받은 요청 · 거절 확인 팝업

- 들어오는 곳: [받은 요청](#채팅--요청--받은-요청) 카드의 “거절”
- 나가는 곳: \[예\] → 받은 요청([거절 완료 토스트](#채팅--요청--받은-요청--거절-완료-토스트)) / \[아니오\] → 받은 요청
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **확인 팝업**: “요청을 거절하시겠습니까?”를 띄운다.
2. **아니오**: 팝업을 닫고 받은 요청으로 돌아간다. 요청은 그대로 남는다.
3. **예**: 요청이 없어지고 상대에게 알리지 않는다. 토스트 “요청을 거절했어요”가 뜬다.

## 채팅 – 요청 · 받은 요청 · 거절 완료 토스트

- 들어오는 곳: [거절 확인 팝업](#채팅--요청--받은-요청--거절-확인-팝업)의 \[예\]
- 공통: [00 공통](00-common.md) 6 팝업 · 모달

1. **토스트**: “요청을 거절했어요”가 화면 아래 가운데에 잠깐 떴다가 사라진다.
2. **받은 요청 목록**: 거절한 요청이 목록에서 빠지고 받은 요청 수와 필터 “요청 N”이 1 줄어든다. 다음 요청이 자동으로 선택된다. 남은 요청이 없으면 빈 상태를 보여준다(제안).
3. **요청 보낸 사람 프로필**: 새로 선택된 요청을 보낸 사람의 프로필로 바뀐다.

## 영역 규칙

아래는 여러 화면의 항목을 한데 모은 것이고, 규칙의 기준은 “적힌 곳”의 항목이다. 대화 요청을 보내는 화면은 [05 탐색 · 방문](05-explore-visit.md#땅굴--방문자-뷰)에 있다.

### 대화 요청의 상태

| 일어난 일 | 받은 사람 쪽 | 보낸 사람 쪽 | 적힌 곳 |
|---|---|---|---|
| 요청을 보낸다 | 받은 요청에 카드가 보이고 알림이 간다 | 보낸 요청에 “답변 기다리는 중” 카드가 보인다. 방문자 뷰의 버튼이 “요청 보냄”으로 바뀌고 다시 보낼 수 없다. 대화방은 아직 없다 | 05 대화 요청 팝업 3, 05 방문자 뷰 4, 받은 요청 4, 보낸 요청 1 |
| 받은 사람이 수락한다 | 그때 1:1 대화방이 만들어져 열린다 | 수락 알림이 간다. 1:1 대화방이 생긴다 | 받은 요청 5, 보낸 요청의 나가는 곳 |
| 받은 사람이 거절한다 | 내 목록에서 요청이 없어진다 | 알리지 않는다. 만료될 때까지 그대로 “답변 기다리는 중”과 “요청 보냄”으로 보이고, 그동안 취소할 수 있다 | 받은 요청 5, 보낸 요청 1 · 2 |
| 거절한 사람이 만료 전에 그 사람에게 대화 요청을 보낸다 | 새 요청을 만들지 않는다. 거절했던 요청을 수락한 것으로 처리해 1:1 대화방이 열린다 | 수락 알림이 간다. 1:1 대화방이 생긴다. 거절됐던 것은 드러나지 않는다 | 받은 요청 5, 05 방문자 뷰 4, 05 대화 요청 팝업 3 |
| 보낸 사람이 취소한다 | 받은 요청에서 사라진다. 알리지 않는다 | 카드가 사라진다. 방문자 뷰의 버튼이 다시 “대화 요청하기”가 된다 | 보낸 요청 2 |
| 보낸 지 5일이 지난다(만료) | 요청이 사라진다 | 카드가 사라진다. 방문자 뷰의 버튼이 다시 “대화 요청하기”가 된다 | 받은 요청 5, 보낸 요청 1, 05 방문자 뷰 4 |

- 상대가 먼저 나에게 보낸 요청에 내가 아직 답하지 않았으면 새 요청을 만들지 않고 토스트로 알린다(05 방문자 뷰 4).

### 대화방이 만들어지고 없어지는 때

| 때 | 일어나는 일 | 적힌 곳 |
|---|---|---|
| 대화 요청을 수락한다 | 1:1 대화방이 만들어진다. 수락 전에는 대화방이 없고 대화 목록에도 나오지 않는다 | 받은 요청 5, 보낸 요청 1 |
| 거절했던 사람에게 만료 전에 대화 요청을 보낸다 | 거절했던 요청을 수락한 것으로 처리해 1:1 대화방이 만들어진다 | 받은 요청 5, 05 대화 요청 팝업 3 |
| 1:1 대화에서 한 사람이 나간다 | 나간 사람의 목록에서 사라진다. 상대의 목록에는 남되 읽기 전용이 된다. 그 뒤로는 두 사람 모두 상대 땅굴에서 “대화 요청하기”가 보인다. 다시 요청해 수락되면 새 대화방이 생긴다 | 1:1 대화 3, 05 방문자 뷰 4 |
| 1:1 대화의 상대가 탈퇴한다 | 내 목록에 남고 읽기 전용이 된다 | 1:1 대화 3 |
| 모임에서 참여 취소 · 내보내기된다 | 그 사람은 자동으로 모임 대화방에서 나간다 | 모임 정보 팝업 4 |
| 모임이 끝나거나 취소된다 | 대화방은 계속 남는다. 그 뒤의 모임 나가기는 참여 취소 없이 대화방에서만 나간다(주최자 포함 누구나) | 모임 정보 팝업 4 |

## 아직 정하지 않은 것

- 모임 대화 1: 찻방에 두더지를 몇 마리까지 그릴지는 구현 단계에서 정한다.
- 거절 완료 토스트 2: 남은 요청이 없을 때 빈 상태를 보여주는 것은 `(제안)`이다.
- 대화 선택 전 1, 1:1 대화 1: 찻방 그림은 디자인이 없어 Figma에 밑그림으로 들어 있다.

서로 맞지 않아 보인 곳:

- 1:1 대화 3은 대화 나가기가 “확인을 거쳐” 된다고 적는다. 모임 나가기와 요청 거절에는 확인 팝업 화면이 있지만, 대화 나가기의 확인 팝업 화면과 문구는 없다.
- 모임 나감 토스트와 거절 완료 토스트는 공통 목록이 6 팝업 · 모달뿐이고 16 완료 토스트가 없다. [05 탐색 · 방문](05-explore-visit.md#땅굴--방문자-뷰--대화-요청-완료-토스트)의 대화 요청 완료 토스트는 16 완료 토스트를 가리킨다. 두 화면은 나가는 곳도 적혀 있지 않다.
