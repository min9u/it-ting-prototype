### 서버 연결 때 할 일 (지금은 목이라 안 함)
- **Google 분기** (명세 로그인 5 · 로그인한 뒤 가는 곳): 처음 쓰는 Google 계정 → 회원가입 3(진행 표시 숨김), 이미 가입한 계정 → 이메일 로그인과 같은 규칙(온보딩 전 → 온보딩 1, 그 밖 → 내 땅굴). 지금 `googleLogin()` 은 `LOGIN_FREE` 면 무조건 내 땅굴, 아니면 무조건 회원가입 3. 서버는 `GET /oauth/google` → 콜백이 로그인시키거나 가입 진행 기록(가입 쿠키)을 만들고 프론트로 보냄. Google 가입은 회원가입 3 에서도 약관 동의를 함
- **Google 로그인의 정지 팝업**: 명세 로그인 4 "Google 로그인도 같다". `googleLogin()` 결과에 `suspended` 가 없음
- **가입 도중 나가기 · 새로고침**: 입력한 내용은 저장하지 않고 처음부터 다시(이메일 가입은 회원가입 1, Google 은 "Google로 계속하기"). 지금은 `/signup/password` · `/signup/ssafy` 를 주소로 바로 열 수 있고, 모듈 변수 `signupDraft` 가 같은 탭에서 남아 이메일이 미리 채워짐 → 화면 상태로 들고 있다가 가입 1이 아닌 단계에 바로 들어오면 `/signup` 으로 보내기
- **가입 진행 만료 `409 SIGNUP_EXPIRED`**: `POST /ssafy-verifications` · `POST /users` 가 이 에러를 주면 "가입 시간이 지났습니다. 처음부터 다시 진행해 주세요."를 안내하고 가입을 처음부터 다시. 지금은 인증 코드 만료만 있음
- **새 학기 상태 `NEW_TERM`**: 온보딩을 마쳤는데 이번 학기 캠퍼스 · 층을 고르지 않은 계정 → 내 땅굴 + 닫을 수 없는 새 학기 안내(팀 명세 05 탐색 · 방문 "새 학기 안내", 아직 안 만듦). 서버 `nextStep` 은 `ONBOARDING | NEW_TERM | HOME` 세 값(지금 앱 `LoginResponseDto.next` 에는 `NEW_TERM` 없음)
- **접근 제한 에러**: `403 ONBOARDING_INCOMPLETE`(온보딩 전에 다른 API 호출) · `403 NEW_TERM_INCOMPLETE`(새 학기 안내를 받은 채 호출). 프론트는 NEW_TERM_INCOMPLETE 를 받으면 어느 화면에서든 새 학기 안내를 띄움. `api/client.ts` 에러 처리와 `RequireLogin` 에서 받아 이동
