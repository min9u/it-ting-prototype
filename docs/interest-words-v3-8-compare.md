# 관심사 v3.8 이름 대조: 핸드오프 `interest_words_v3_8.json` ↔ 앱 `data/interestTags.ts` (2026-11-21)

- 요청: 핸드오프의 대분류 12 · 소분류 90 · 단어 164개를 앱의 11-18 확정본과 비교해, 다른 것·빠진 것만 표로. 단어 쪼개기가 기획 규칙("/"로 묶인 관심사는 단어 중 하나 고르기, 한 단어는 고정)과 맞는지 확인
- 비교 대상: `design/digul_3d_handoff_interest_v3_8/docs/interest_words_v3_8.json` ↔ `app/src/data/interestTags.ts`(`TAG_TREE`). 스크립트로 전부 대조함(손으로 본 게 아님)
- 읽기만 했고 앱 코드는 바꾸지 않음

## 결론
- **이름은 다 같다.** 대분류 12개(이름 · 이모지 · 순서), 소분류 90개(이름 · 순서)가 한 글자도 안 다르다. 빠진 것도 남는 것도 없다
- **다른 것은 대분류 id 5개뿐**(이름이 아니라 영어 id). 앱 id 는 백엔드 enum 후보라 못 바꾸므로 **JSON 쪽을 앱 id 로 옮기는 표**를 데이터 교체 단계에서 한 곳에 둔다
- 단어 쪼개기는 규칙과 맞는다. 소분류 90개 → 단어 164개. 예외 2건(아래)만 "기타" 단어를 디자이너가 일부러 뺐다

### 소분류 이름
다른 것 없음 (90개 전부 같음, 순서도 같음).

## 단어 쪼개기 확인 ("/" 기준)
| 구분 | 개수 | 내용 |
|---|---|---|
| 소분류 | 90 | |
| "/"가 없는 소분류 (단어 1개, **고정**) | 33 | 예: 맛집탐방, 영화, 축구 |
| "/"로 묶인 소분류 (단어 2개 이상, **중 하나 고르기**) | 57 | 단어 수가 `/` 쪼갠 수와 같음 |
| 단어(모델) 합계 | 164 | = "/" 쪼갠 수 166 − 빠진 "기타" 2 |

예외 2건 (JSON 의 `words` 가 "/" 쪼갠 것보다 하나 적음. `docs/CHANGELOG_v3_8.md`: "그 밖의 것" 뜻의 `기타` 2개 제외):
| 소분류 이름(앱 그대로) | "/" 쪼갠 것 | 모델이 있는 단어 | 영향 |
|---|---|---|---|
| 액세서리/기타 (미술·수공예) | 액세서리, 기타 | **액세서리** 1개 | 단어가 1개뿐이라 "한 단어는 고정"이 된다 (원래 "/"가 있어도 고를 게 없음) |
| 곤충/파충류/기타 (반려동물·식물) | 곤충, 파충류, 기타 | **곤충, 파충류** 2개 | "기타"는 선택지에서 빠지고 둘 중 하나 고르기 |

- "/"로 묶인 소분류 57 + 위 `액세서리/기타` 1 = **58개가 이름에 "/"를 가진 소분류**. F4 문서([burrow-f4-figma-2026-11-21.md](burrow-f4-figma-2026-11-21.md))의 58개와 같음 → 표는 그대로 쓸 수 있다
- 단어 이름이 "기타"인 모델은 없다. 소분류 이름에 "기타"가 들어간 `기타/베이스/일렉`(악기 기타), `기타언어`는 문제 없음(기타 = guitar, 단어 3개 / 1개)
- 단어 `node` 164개가 전부 다르다(중복 없음). 모델 크기 구성: 작은 134 · 큰 27 · 벽 3. 큰 27 중 동물 용품 7(`dog_house` `cat_bed` `hamster_cage` `rabbit_hutch` `parrot_perch` `ant_farm_case` `lizard_tank`)은 동물 짝 자리라 `big_model_sizes.json`(23개)에는 없고, 나머지 큰 20 + 벽 3 = 23이 같음. 반려동물 단어 7개(`pet` 값 있음): 강아지 · 고양이 · 설치류 · 소동물 · 새 · 곤충 · 파충류
- 상태: 기존 102 · 새로 56 · 되살림 6

## 기획에 확인받을 것
1. **"기타"를 뺀 2건**은 화면 이름은 그대로("액세서리/기타", "곤충/파충류/기타")인데 단어 선택지에서 "기타"가 사라진다. 명세·F4 문서의 "/"로 묶인 관심사 표에 이 둘이 어떻게 보이는지(칩 글자는 소분류 이름 그대로, 고르는 단어는 위 표대로) 한 줄 확인 필요
2. "한 단어는 고정"인 33개와 "고르기"인 57개를 코드에서 구분하는 기준은 **JSON `words.length`** 하나로 정함(이름 "/" 검사 아님 → 위 예외 2건이 자동으로 맞음)
