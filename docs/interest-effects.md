# 관심사 이펙트: 땅굴 안 · 탐색 들판

- 날짜: 2026-11-17
- 요청 (그대로): "사람들의 관심사를 좀더 재밌고 한눈에 확인할 수있도록 만들고 싶어. 1. 땅굴 내에서 이팩트를 새로 만드는 작업 2. 탐색화면에서 다른 사람의 땅굴에서 보이는 이팩트를 넣는 작업. 두 작업을 여러 아이디어를 만들어서 반영해줘. 새로운 아티팩트에서 실험해."
- 기준 차별점: ① 처음 말 거는 부담 낮추기(방의 소품·사연이 대화 계기) ② 내향적인 사람도 편하게 ③ 니치한 취미끼리 잘 찾기(드문 관심사에 가중치)
- 브랜치: GitHub `interest-effects` (main `a72ad65` 기준, 아직 main 에 합치지 않음)
- **실험 아티팩트: https://claude.ai/artifact/9gE4UfgV4LntWwNJiWtkxu** ("디굴디굴 이펙트 실험", 비공개로 시작). 팀 링크·시험판과 별도. 탐색 이동 화질 작업(같은 시간 진행)은 아직 안 들어감

## 결론
- 아이디어를 땅굴 12개 · 들판 12개 냈고, **땅굴 5개 · 들판 8개를 구현**했다. 모두 화면의 **"✨ 이펙트" 패널**에서 하나씩 켜고 끄거나 "모두 켬 / 추천 묶음 / 모두 끔"으로 고른다 (처음엔 추천 묶음, localStorage 에 기억).
- 이펙트는 3D 장면 안이 아니라 **WebGL 캔버스 바로 위 2D 겹 캔버스**에 그린다. 3D 좌표를 매 프레임 카메라로 화면에 옮기므로 방 돌리기·확대·들판 점프를 그대로 따라가고, 저사양(가속 꺼짐)의 "배경 한 번 굽기 + 두더지 둘레만 다시 그리기"와 **완전히 따로** 돈다. 구운 배경을 다시 굽게 만들지 않고, 3D 루프가 쉬는 것(idle)도 막지 않는다 (이유는 아래 "그리는 방식").
- 탐색 들판은 카메라가 가까워서 **화면에 구멍이 1~3개뿐**이었다. 그래서 예시에 없던 **"옆 땅굴 이정표"**(화면 밖 옆 구멍의 관심사를 가장자리에 화살표·이름과 함께)를 만들었고, 이게 들판에서 가장 효과가 컸다. "가까이 가면 펼쳐짐"도 이정표 위에서 펼쳐져서 어느 쪽으로 갈지 고를 때 바로 쓰인다.
- 들판 카메라로는 "멀리서도 한눈에"가 안 돼서 **미니맵의 땅굴 점을 대표 관심사 색**으로 칠하는 것(F12)도 넣었다. 마을 전체에서 어떤 취미가 어디 모였는지는 이게 가장 잘 보여 준다.
- 추천 묶음: 땅굴 = 관심사 숨결 · 관심사 카드 · 나와 같은 관심사 · 가장 드문 관심사 (빛줄기는 분위기용이라 뺌). 들판 = 말풍선 · 펼쳐짐 · 이정표 · 겹치는 고리 · 드문 반짝 · 접속 중 활발 · 미니맵 색 (연기는 정보가 말풍선과 겹쳐 뺌).
- 성능: 아래 "성능" 표. 이펙트를 켜도 GPU·가속 꺼짐 모두 3D 장면 fps 는 거의 그대로다 (1~2% 안). 가속 꺼짐에서는 이펙트가 20fps 로 따로 돌며 가까운 것만 움직이고, 카메라가 움직이는 동안은 숨고, **8초 동안 가만히 있으면 멈춘 그림으로 쉰다** (가만히 둔 PC 의 CPU 가 이펙트 끈 것과 거의 같아짐). 아주 느린 PC(weak)·움직임 줄이기는 움직임 없이 아이콘만.

## 구현한 것

### 땅굴 (`app/src/three/interestFx/roomFx.ts`)
**관심사 숨결**: 카테고리 주 가구(카탈로그 `furniture[0]`: 피아노·포토보드·화분대·오락기·이젤·책장·망원경·주방·자전거 거치대·TV)는 1초에 1.7개, 세부 관심사 소품(선반)은 0.45개. 동물(반려동물)은 둘레를 도는 발자국.

| 카테고리 | 입자 |
|---|---|
| 음악 | 음표 (보라·연보라, 흔들리며 오름) |
| 사진 | 하얀 반짝 별 + 3~6초마다 큰 플래시 (찰칵) |
| 자연·식물 | 잎 (초록 4색, 돌며 날림) |
| 게임·놀이 | 픽셀 사각형 (5색, 5cm 계단으로 오르고 끝에 깜빡임) |
| 공예·만들기 | 물감 방울 (5색, 톡톡 튀어 오르다 떨어지며 터짐) |
| 책·글 | 종이 한 장 (줄 그어진 페이지가 펄럭이며 오름) |
| 우주·과학 | 별 반짝임 (흰·연보라·노랑, 가구 둘레에서 깜빡) |
| 차·커피·베이킹 | 김 (하얀 연기가 흔들리며 퍼짐) |
| 운동·아웃도어 | 모닥불 불티 (주황, 빠르게 오르며 깜빡) |
| 영화·애니 | 팝콘 (튀어 올라 포물선으로 떨어짐) |
| 반려동물 | 바닥 발자국 (동물 둘레를 걸으며 찍히고 사라짐) |

**관심사 카드**: 관심사 가구에 마우스를 올리면 장면의 이름표 대신 카드가 가구 위에 뜸 (카드 안에 "누르면 · 빈백에 앉기" 같은 원래 동작 줄). 세부 관심사 소품이면 이름·카테고리, "이 관심사를 고른 사람 N명"(목 인원수), 드문 정도 배지와 20위 안이면 "관심사 65개 중 n번째로 드물어요", "서울-2층 들판 이웃 중 N명도 좋아해요"(내 들판 목 데이터), 남의 땅굴이고 겹치면 "♥ 나도 좋아하는 관심사예요 · “OO” 이야기로 먼저 말 걸어 볼까요?". 카테고리 가구면 그 카테고리에서 주인이 고른 관심사 칩(겹치는 것 ♥).

**나와 같은 관심사**: 남의 땅굴에서만 (`VisitBurrow` 가 내 관심사를 넘김). 예린 땅굴은 캠핑·수채화·레트로게임이 겹쳐서 세 선반 소품이 빛남.

**가장 드문 관심사**: 방 주인 관심사 중 가장 적은 사람이 고른 것 하나 (700명 미만일 때). 내 땅굴(목 데이터)은 SF소설 690명 → "이 방에서 가장 드문 취미", 예린은 다도 190명 → 금색 "드문 취미".

**빛줄기**: 천장 구멍(두더지가 떨어지는 원점 위)에서 바닥으로 대표 관심사 색의 사다리꼴 빛 + 바닥 빛 웅덩이 + 떠다니는 먼지 16개(가속 꺼짐 7개).

배지(드문 취미·나도!)는 선반 소품끼리 붙어 있어 겹치면 위로 쌓는다. 입장 연출(천장 구멍·가구 낙하) 중에는 숨겼다가 끝나면 0.6초에 걸쳐 나타남.

### 탐색 들판 (`app/src/three/interestFx/fieldFx.ts`)
- 자리마다 정보 (`data/interestFx.ts holeFxOf`): 대표 관심사(맨 앞)의 카테고리, 펼칠 아이콘 3개(겹치는 것 → 가장 드문 것 → 고른 순서), 나머지 수, 겹치는 수, 드문 정도(들판은 250명 미만만), 접속 중, 닉네임
- 서 있는 구멍은 안내판이 있어서 말풍선을 숨김. 이동 중에는 도착할 구멍 기준으로 펼침·이정표를 다시 정함
- 이정표 자리는 정보 패널(오른쪽 372px)과 아래 조작 줄을 피함. 장면 가운데(focusX)는 카메라 view offset 에서 읽음
- 움직이는(통통·연기·고리 맥박) 구멍은 두더지에 가까운 순 GPU 12개 · 가속 꺼짐 5개 · 아주 느린 PC 0개. 나머지는 멈춘 그림

### 패널 (`app/src/components/FxPanel.tsx`, 상태 `app/src/lib/fxLab.ts`)
- 자리: 장면 오른쪽 아래, 정보 패널 왼쪽 (패널을 접으면 오른쪽 끝). 🧪 저사양 실험실(화면 맨 오른쪽 아래)·탐색 시안 칩(위 가운데)·리액션 줄(왼쪽 아래)과 안 겹침
- 버튼 "✨ 이펙트 4/5" → 카드: 모두 켬 / 추천 묶음 / 모두 끔, 이펙트마다 스위치 + 설명 + 맞는 차별점 + "추천"·"남의 땅굴에서만" 표시, 맨 아래 지금 그리는 방식(GPU / 가속 꺼짐 20fps / 아주 느린 PC·움직임 줄이기는 아이콘만)
- 바꾸면 장면을 다시 만들지 않고 바로 반영 (겹 캔버스만 다시 그림). 저장 키 `digul.fx.v1`, 막혀 있으면 이 탭에서만
- 측정용 주소 손잡이 (사용자용 아님): `?fx=0|all|rec`, `?fxmode=full|lite|still`

### 그리는 방식 (`app/src/three/interestFx/overlay.ts`)
WebGL 캔버스 바로 뒤에 2D 캔버스(`data-fx="interest"`, 클릭 통과)를 붙이고 자기 rAF 로 그린다. 3D 루프와 따로라:
- 저사양 땅굴·들판은 움직이지 않는 것을 렌더 타깃·2D 캔버스에 한 번 굽고 두더지 둘레 사각형만 다시 그린다(scissor). 이펙트를 움직이는 층(layer 1)에 넣으면 그 사각형이 방 전체로 커지고 루프가 쉬지 못해(busy) CPU 를 계속 쓴다. 겹 캔버스는 이 경로를 전혀 건드리지 않는다
- 3D 는 0.55배 해상도지만 겹 캔버스는 1배라 아이콘·글자가 선명하다
- 카메라가 그대로이고 움직이는 이펙트가 없으면 다시 그리지 않음 (아주 느린 PC·움직임 줄이기는 카메라가 바뀌거나 켜고 끌 때만)
- 가속 꺼짐(lite)은 3D 루프의 "가만히 있으면 멈춤"과 같은 생각으로 **쉼(calm)**: 장면 위 마우스·키·휠·카메라 변화·켜고 끄기가 8초 동안 없으면 새 입자·연기를 만들지 않고, 남은 것이 사라지면 맥박·통통이 멈춘 그림 하나를 그리고 더는 그리지 않음. 다시 움직이면 바로 깨어남. 또 **카메라가 움직이는 동안(방 돌리기 등)은 한 번 지우고 그리지 않으며, 들판 점프 1.3초 동안은 겹 캔버스를 `display:none` 으로 합성에서 뺌** → 3D 가 가장 무거운 순간에 겹 캔버스 그리기·합성을 쉬게 (아래 "성능"의 1~5차)
- 아이콘·입자는 캔버스로 그린 글리프(`icons.ts`: 카테고리 11종 + 음표·하트·별·종이·팝콘·보석)를 (이름·크기·색·배율)마다 한 번만 그려 두고 drawImage. 이모지·svg data URL 을 쓰지 않음 (공유 빌드 제약)
- 단점: 이펙트가 늘 3D 위라 두더지가 지나가도 가리지 않음 (입자가 작아 거의 안 보임)

| 단계 (overlay `fxMode`) | 언제 | fps | 배율 | 입자 상한 | 들판 움직이는 구멍 | 땅굴 소품 입자 |
|---|---|---|---|---|---|---|
| full | GPU | 30 (카메라가 움직이는 동안은 매 rAF) | 기기 배율 최대 1.5 | 160 | 12 | 있음 |
| lite | 가속 꺼짐 · strong(16스레드급) | 20, **8초 동안 가만히 있으면 쉼**, 카메라 이동 중 비움, 들판 점프 중 합성에서 뺌 | 1 | 48 | 5 | 없음 (주 가구·동물만) |
| still | 가속 꺼짐 · weak(2코어급), 움직임 줄이기 | 바뀔 때만 | 1 | 0 | 0 | 주 가구 위 작은 배지, 동물 곁 발자국 하나 |

## 성능
측정: 공유 빌드(`npm run build:share`, `vite preview`)를 헤드리스 크롬 1920×1080 으로 열고 `explore/gpu/cdp-scene.mjs` (반복 1번, `?fx=0` 끔 / `?fx=all` 모두 켬). 장면 fps = 3D 루프가 실제로 그린 횟수, CPU = 프로세스별 CPU 시간 (100% = 코어 하나). 가속 켬 = RTX 5060 Ti, 가속 끔 = 같은 PC 크롬 가속 끔(WARP, 16스레드). 다른 작업자가 같은 PC 에서 측정 중이라 한 번씩만 잼 → 몇 % 차이는 잡음일 수 있음.

### 3D 장면 fps (켜도 떨어지지 않아야 함)
| 화면 · 구간 | 가속 켬 끔 → 켬 | 가속 꺼짐 끔 → 켬 |
|---|---|---|
| 예린 땅굴 가만히 | 59.9 → 60 | 15.0 → 15.3 (쉬는 중 숨쉬기만 그림, 원래 동작) |
| 예린 땅굴 걷기 (D·A 8초) | 60 → 60 | 59.0 → 59.8 |
| 탐색 가만히 | 59.9 → 60 | 12.1 → 12.2 |
| 탐색 점프 4번 (장면 fps · 카메라 이동 fps) | 59.7 · 62.5 → 60 · 62.5 | **최종** 58.5·61.9 / 57.6·58.8 → 58.8·61.9 / 59.1·63.8 (2번씩) |
| 탐색 구멍 클릭 점프 | 60.1 → 60 | **최종** 58.1 / 58.5 → 58.1 / 57.7 (2번씩) |

→ 가속 켬에서는 차이가 없고, 가속 꺼짐에서도 잡음 수준 (땅굴·가만히는 2차, 탐색 점프·클릭은 5차 최종).
가속 꺼짐 탐색 점프는 여러 번 고쳤다 (모두 켬 기준, 끔은 57.6~58.5):
| 차수 | 바꾼 것 | 점프 장면 fps · 카메라 이동 fps |
|---|---|---|
| 1차 | 처음 (20fps 계속) | 52.5 · 48.1 |
| 2차 | 8초 가만히 있으면 쉼 | 57.6 · 59.4 (한 번, 운이 좋았던 듯) |
| 3차 | + 카메라 이동 중 `visibility:hidden` | 50.2 · 53.1 (스타일 바꾸기가 오히려 무거움) |
| 4차 | 숨기는 대신 한 번 지우기 (2번) | 53.0 · 52.5 / 57.8 · 59.4 |
| 5차 (최종) | + 점프하는 1.3초 동안 겹 캔버스를 `display:none`(합성에서 빠짐) + 움직임 멈춤 (2번) | **58.8 · 61.9 / 59.1 · 63.8** |
화면 가득한 투명 층 하나가 있는 것만으로 WARP 는 매 프레임 그 층을 섞느라 점프가 느려졌다 → 무거운 순간(점프)엔 층을 빼는 게 답이었다.

### 가만히 둘 때 CPU (`idlecpu`: 들어와서 16초 뒤 8초 동안 · 깨어 있을 때는 6초 뒤 4초 동안)
| 화면 | 가속 꺼짐 · 쉬는 중 (끔 / 추천 / 모두) | 가속 꺼짐 · 깨어 있음 (끔 → 모두) | 가속 켬 (끔 / 추천 / 모두) |
|---|---|---|---|
| 예린 땅굴 렌더러 / GPU 프로세스 | 22 / 105 · 19 / 86 · 17 / 82 | 23 / 110 → 22 / 76 | 22 / 27 · 23 / 29 (30fps) — 60fps 이던 때 17 / 23 → 21 / 30 · 모두 27 / 36 |
| 탐색 렌더러 / GPU 프로세스 | 15 / 58 · 16 / 61 · 13 / 54 | 27 / 69 → 31 / 81 | 18 / 24 · 21 / 32 (30fps) — 60fps 이던 때 15 / 21 → 29 / 51 · 모두 31 / 50 |
| 겹 캔버스 fps | 0 (쉼) | 20 | 30 (예전 60) |

→ 가속 꺼짐에서 쉬는 중이면 이펙트를 켜도 끈 것과 같다 (겹 캔버스 0fps, 차이는 3D 숨쉬기 타이밍 잡음). 깨어 있는 8초 동안은 탐색에서 렌더러 +4%·GPU 프로세스 +12% 정도.
→ 가속 켬은 겹 캔버스를 매 rAF(60fps)로 그리던 2차에서 탐색 렌더러 +14%·GPU 프로세스 +30% 였다. 입자는 30fps 로도 충분해서 카메라가 움직일 때만 매 프레임 그리게 바꿨고(3차), 그 뒤 추천 묶음은 +3% / +8% 안쪽.

### 이펙트 자체 비용
- 땅굴 이펙트 한 프레임 그리기 최대 7ms, 가구 자리 재기 최대 0.9ms (가속 켬, 모두 켬, `window.__fxCost`). 겹 캔버스 프레임 수는 `window.__fxFrames`
- 처음 들어올 때 가장 긴 작업: 이펙트를 켜면 땅굴에서 길게 나온 적이 있음 (가속 켬 85 → 287ms, 가속 꺼짐 114 → 213ms, 한 번씩 잰 값). 이펙트 쪽 일은 위처럼 짧아서 측정 잡음(다른 작업자 측정과 겹침)일 가능성이 큼 → 메인 세션이 합친 뒤 `REPS=3` 으로 다시 재 볼 것
- 이펙트가 그려지는 수의 상한: 입자 GPU 160 · 가속 꺼짐 48, 연기 GPU 140 · 가속 꺼짐 40, 움직이는 구멍 12 · 5 · 0. 화면 밖(±80px)은 그리지 않음

## 사용자가 확인할 화면과 순서
1. **내 땅굴** (`#/burrow`): 오른쪽 아래 "✨ 이펙트" → 추천 묶음이 켜져 있음. 피아노에서 음표, 포토보드에서 플래시, 이젤에서 물감 방울, 자전거 거치대에서 불티. 왼쪽 선반에 "이 방에서 가장 드문 취미" 배지. 가구에 마우스를 올려 카드 보기
2. 패널에서 "모두 켬" → 천장 구멍 빛줄기(대표 관심사 = 캠핑 → 주황). 하나씩 끄고 켜 보기
3. **예린 땅굴** (`#/burrow/yerin`): 캠핑·수채화·레트로게임 선반 소품이 빛나고 하트 + "나도!" 배지, 다도에 금색 "드문 취미", 고양이 둘레 발자국. 겹치는 소품에 마우스를 올리면 "“레트로게임” 이야기로 먼저 말 걸어 볼까요?"
4. **탐색** (`#/burrow/explore`, 시안 A): 위·오른쪽 가장자리의 이정표(이름 + 화살표 + 관심사 3개), 겹치는 구멍의 산호색 고리와 ♥N. 방향키로 옮겨 다니며 펼쳐짐·이정표가 바뀌는 것 보기. 접속 중인 이웃은 초록 점과 통통. 왼쪽 아래 미니맵의 땅굴 점이 대표 관심사 색 (크게 보기에서도)
5. 탐색에서 "모두 켬" → 연기. 다른 캠퍼스-층(예: 서울-3층)도 보기
6. (가속 꺼진 PC) 같은 순서로 20fps · 가까운 것만 움직이는지, 🧪 실험실 기기 단계를 weak 로 바꾸면 움직임 없이 아이콘만 남는지
