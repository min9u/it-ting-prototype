# 탐색: 방노트 사이드바 · 빵은 대전만 · GNB "게시판"

- 날짜: 2026-11-20 (시험 브랜치 `try/explore-v3-11`, push 안 함)
- 요청 3가지 (사용자 결정):
  1. 층 → 작물: 빵은 **대전 캠퍼스 층에만**. 대전이 아닌 층은 나머지 8종을 목록 순서대로 돌려 씀
  2. 탐색 오른쪽 사이드바를 Figma 처럼: 접혀 있다가 "방노트" 버튼으로 펼침, 땅굴 놀러가기 버튼은 사이드바 안으로
  3. GNB "커뮤니티" → "게시판" (팀 명세에서 확정)

## 1. 층 → 작물 (`app/src/data/field.ts` `cropOf`)

| 층 | 작물 |
|---|---|
| 대전 (몇 층이든, 목록에 없는 층도) | 빵 |
| 서울 2 · 3 · 12 | 호박 · 사과 · 딸기 |
| 광주 1 | 고구마 |
| 구미 2 · 3 | 당근 · 옥수수 |
| 부울경 1 | 토마토 |

- 돌려 쓰는 순서 = 호박 → 사과 → 딸기 → 고구마 → 당근 → 옥수수 → 토마토 → 해바라기. 순서는 캠퍼스-층 목록(고르기 창 순서)에서 **대전 층을 세지 않고 건너뛴** 위치
- **해바라기는 아직 안 나옴**: 대전이 아닌 층이 7개라서. 8번째 층이 생기면 해바라기
- 이전 임시 매핑(9종을 목록 전체 순서로)과 달라진 층: 광주 1(옥수수 → 고구마), 구미 2·3(토마토·해바라기 → 당근·옥수수), 부울경 1(빵 → 토마토), 대전 1·2(고구마·당근 → 빵). 서울 3개는 그대로
- 같은 캠퍼스 층끼리 작물이 다르다는 성질은 **대전에서만 깨짐**(층이 여러 개여도 전부 빵 = 사용자 결정). 사다리로 대전 층끼리 옮기면 작물로는 구분이 안 됨
- 실서비스는 서버의 캠퍼스-층 설정에 작물 값을 두자는 제안은 그대로 (이제 "대전 = 빵" 규칙도 같이 서버가 가져야 함)

## 2. 방노트 사이드바 (`app/src/screens/burrow/ExploreBurrow.tsx`)

Figma: `design/figma/explore_collapsed.png`("탐색 – 사이드바 접힌 버전", 오른쪽 위 "방노트 🐾" 버튼 + GNB "게시판"), 펼친 모양은 `design/figma/spec/f5/f5-explore.png` 3번.

- 들어오면 **접혀 있음**. 오른쪽 위에 "방노트" 버튼만 (내 땅굴의 접힌 버튼과 같은 모양·같은 글자, 예전 "땅굴 정보"를 바꿈). 새로 들어올 때마다 접힘(저장 안 함)
- "방노트"를 누르면 펼쳐짐: 머리글("○○님의 땅굴" + "접기 ›") · 프로필 · 자기소개 · 관심사 · **"땅굴 놀러가기 Enter"**(내 구멍이면 "내 땅굴 들어가기") · Q&A (2026-11-20 밤에 Figma 와 맞춤 → 아래 "Figma 와 맞춘 네 가지")
- **두더지 옆 "땅굴 놀러가기 Enter" 안내판 카드는 없앰.** 안내판 위치 코드(`onAnchor` 받는 곳)와 `.sign` 위치 CSS도 지움. 안쪽 카드 CSS(`signCard` 등)는 탐색 시안 A~D(`explore-designs/common.tsx`)가 써서 남김
- Enter 키로 들어가기는 그대로 (접힌 상태에서도, 방향키 · +/− 도 그대로). 이동 중이거나 어두워지는 중엔 버튼이 비활성
- 펼친 채 다른 구멍으로 옮기면 그 주인 정보로 바뀜(이동을 시작할 때 바로 바뀜, 예전과 같음)
- 키가 작은 화면: 머리글(접기)은 고정, 그 아래(프로필~Q&A, 버튼 포함)는 한 덩어리로 안쪽만 스크롤 (`Burrow.module.css` `.noteAside` · `.noteBody`)
- 키보드로 접고 펼치면 서로 맞은편 버튼으로 초점을 옮김(`e.detail === 0` 일 때만). **마우스로 누르면 안 옮김** → 마우스로 펼친 뒤 Enter 를 누르면 접기가 아니라 땅굴 들어가기로 감
- 데모 쿼리: 예전 `?panel=closed` 는 의미가 없어졌고, 펼친 채로 열려면 `?panel=open`
- 펼치면 3D 카메라 중심이 왼쪽으로 옮겨 가는 것(`focusX` 0.5 → 0.403), 미니맵·줌 버튼·이펙트 버튼이 사이드바 왼쪽으로 비켜 가는 것은 예전 그대로
