## 메인이 이은 것
- 채팅 모임 대화방 = 모임 저장소 기준 (새로 만든 모임·새로 확정된 모임도 대화방이 생김, 모임이 끝나면 끝난 대화방). 채팅의 "모임 나가기" = 모임 참여 취소 (같은 24시간 규칙)
- 알림 팝업 "모임 참여 요청" 수 = 모임 신청 관리의 처리 안 된 신청 (수락·거절하면 줄어듦), 누르면 내 모임 › 내가 연 모임 › 신청 관리
- 로그아웃·회원 탈퇴 → 비로그인 상태로 랜딩
- 프로필 팝업: 신고 아이콘 → 신고하기 / 차단하기. 차단한 사람의 1:1 대화·대화 요청은 채팅에서 숨김, 설정 › 차단 관리에서 해제
- 없는 모임(`/meetups/없는id`)·없는 땅굴은 00 공통 21 안내 화면
- 화면 목록(`/screens`) 모임 항목을 새 프레임 번호·데모 쿼리로

## 확인한 것
- 영역마다 `tsc -b`·빌드·헤드리스 스크린샷 (각 문서), 합친 뒤 `tsc -b`·빌드 통과, 12개 대표 화면 오류 없이 뜸

## 확인받을 것 (작업자들이 판단한 것 중 큰 것)
1. **랜딩을 4구간(땅 위 → 구멍 → 방 → 이웃)으로 되돌림**: 11-12 에 03 디자인 따라 2구간으로 줄였던 것을 02 명세대로 되돌림
2. **모임**: 02 스크린샷(모임 전용 카테고리, 만든 뒤 완료 팝업, 그만두기 = 저장 전 취소)과 11-13 결정 표(대표 관심사 + 태그, 상세로 이동, 임시 저장)가 다름 → 결정 표를 따름. 명세가 새로 바뀐 것이면 다시 맞춰야 함
3. **커뮤니티 글쓰기 이어 쓰기 팝업 없음**: 최신 명세 "임시 저장 없음"을 따름 (모임은 임시 저장 — 둘이 다름)
4. **알림 팝업에서 바로 수락·거절(#102·#103) 없음**: 최신 명세는 요청 줄을 누르면 신청 관리·채팅 요청으로 이동
5. **땅굴 무드 = 대표 관심사(맨 앞)의 분야** (예전: 가중치가 가장 큰 분야)
6. 내 정보에서 캠퍼스·층을 바꿔도 탐색 들판의 내 자리는 아직 안 옮김
