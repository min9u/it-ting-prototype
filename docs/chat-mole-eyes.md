# 채팅방 두더지 눈이 안 보이는 문제 (mole_chat.glb)

- 날짜: 2026-11-22
- 요청: 채팅방(`mole_chat.glb`)과 랜딩 방 두더지에 눈이 안 보임. 내 땅굴 두더지(`mole.glb`)는 보임. 원인 확인 → 앱 문제면 고치고, glb 에 눈이 없으면 3D용 메모
- 결론: **눈은 glb 에 있음.** `mole_chat.glb` 의 애니메이션 클립에 눈 노드의 이동·회전 트랙이 틀린 값으로 구워져 있어 눈이 머리 안으로 들어감. 앱에서 그 트랙을 빼서 보이게 함(`three/chatMoleClips.ts`). 랜딩 방 두더지는 `mole.glb` 라 이 문제가 아님(아래)

## 3D 쪽 메모 (디자이너·3D 담당에게)

### 두 파일 비교
| | `mole.glb` (v1_3) | `mole_chat.glb` |
|---|---|---|
| 눈 노드 | `mole_eye_L` · `mole_eye_R` (`upper_body` 자식, mesh 15·16) | 똑같음 (위치·회전·크기 기본값도 같음) |
| 눈 재질 | `M_mole_eye` (검정에 가까운 갈색, 거칠기 0.1) | 똑같음 |
| 기본 자세(눈 L) | 이동 (0.140, 0.306, **0.2926**), 크기 (0.03, 0.04, 0.022) | 같음 |
| 클립 안 눈 트랙 | 크기(깜빡임)만 | **이동 + 회전 + 크기** |

### 문제가 되는 값 (`mole_chat.glb`)
- 거의 모든 클립(`mole_sit_idle` · `mole_idle` · `mole_drink` · `mole_greet` · `mole_walk` …)에 눈 이동·회전 트랙이 **키 2개짜리 고정값**으로 들어 있음
  - 이동 (±0.140, 0.293, **−0.072**): 기본 자세 z 는 **+0.2926** 이라서 눈이 얼굴 앞이 아니라 몸 안쪽(−0.072)으로 들어감 → 몸에 가려 안 보임
  - 회전 (−0.809, ±0.097, ∓0.069, 0.575): 기본 자세는 거의 회전 없음(−0.166, 0.118, 0.020, 0.979). 약 −108° 돌아간 값
  - 원인 추정: 눈이 뼈(bone)가 아니라 `upper_body` 자식 메시인데, 클립을 구울 때 눈 노드의 월드 변환이 로컬 값으로 들어간 것으로 보임 (구울 때 눈을 애니메이션 대상에서 빼면 `mole.glb` 처럼 크기 트랙만 남음)
- `mole_sit_talk`(채팅방 전용으로 합친 클립): 눈 크기 트랙이 **첫 키가 (0, 0, 0)** 이고 Y 가 0.223 까지 튐(정상은 0.013~0.040). 재생되는 동안 눈이 사라지거나 길어짐

### 제안: `mole_v1_4` 로 통일
- `mole.glb`(v1_3, 동작 25개)에 **`mole_sit_talk` 만 합쳐서 `mole_v1_4`** 로 만들고, 채팅방도 이 파일을 쓰게 하면 파일이 하나로 줄고 눈 문제도 같이 없어짐 (지금은 `mole.glb` 0.67MB + `mole_chat.glb` 0.80MB 가 따로 있음)
- 합칠 때 확인: ① `mole_sit_talk` 에서 눈 트랙 제거(또는 `mole_sit_idle` 처럼 크기 트랙만) ② 다른 클립에 눈 이동·회전 트랙이 없는지 ③ `mole_sit_talk` 의 다른 노드 첫 키도 0 으로 시작하는지(이동 0..0.14, 크기 0..0.03 으로 이 클립 전체가 0 에서 시작하는 것으로 보임)
