# 3D 담당께: 침대 빠진 빈자리와 "작은 소품만 고르면 바닥이 휑함" (2026-11-21)

관심사 v3.8(`room_base_v3`, 슬롯 49)을 앱에 넣어 보고 느낀 점과 공용 자리 추가 제안입니다. 사진: 저장소 `_shots/v38/` (3-A-small.png, 3-B-big.png, 3-C-pet.png — 커밋 안 하는 폴더라 필요하시면 따로 드릴게요).

## 확인된 것
- 소분류 90개 중 첫 단어가 **작은 소품인 것이 74개**(82%), 큰 모델 9 · 벽 2 · 반려동물 5. 대분류별로는 게임 · 외국어·자기계발 · 책 · 사진·영상 · 미술·수공예 · 덕질·수집은 큰 모델이 **하나도 없음**(덕질은 벽 1)
- 작은 소품은 선반 12칸에만 놓이므로, 작은 것 위주로 고르면 **바닥에는 원탁 · 방석 · 우체통뿐**이고 침대가 있던 왼쪽이 통째로 비어 보임(`3-A-small.png`). 큰 모델 여러 개를 고르면(`3-B-big.png`) 뒤쪽 벽이 차서 균형이 맞음
- 이번 앱 구도에서 앞쪽 반려동물 줄을 UI(아래 버튼 줄 · 정보 패널)에 안 가리게 하려고 방을 11% 줄였더니, 비어 있는 바닥이 더 눈에 띔(슬롯 좌표는 안 건드림)

## 제안
1. **공용 바닥 자리 2~3개 추가** — 위 "왼쪽 벽 따라" 구역에 `shared_big` 급 1개(1.0×0.8×1.2 안팎), "왼쪽 안쪽"에 낮은 것 1개(0.6×0.6×0.5). 큰 모델이 없는 대분류가 많아서 **작은 소품 중 몇 개를 "바닥 소품"으로 키워** 놓을 수 있는 자리 규칙(작은 단어도 바닥 자리를 쓸 수 있게)도 같이 필요
2. **고정 장식 1~2개**(관심사와 상관없이 항상 있음, 우체통처럼 `fixed` 슬롯): 예를 들어 화분 · 바구니 · 책더미. 아무것도 안 골랐을 때나 선반 소품만 있을 때 방이 비어 보이지 않게
3. **선반 소품이 12칸을 넘지 않도록**(지금은 10개까지 고르므로 문제 없음) 유지하고, 작은 소품을 고르면 **원탁 위 · 방석 옆에 놓이는 작은 소품 자리**(`table_top`, 지금은 찻주전자 · 컵만 있음) 2~3칸 추가하는 방법도 있음 — 이쪽은 두더지 동선과 안 겹쳐서 안전
4. 새 자리가 생기면 `drop_by_height` 줄(낙하 / 팝)과 `big_model_sizes.json` 키를 같이 부탁드립니다. 앱은 `slots.json` 만 교체하면 자동으로 읽음(배치 규칙 `PLACEMENT_v3_8.md` 그대로)
