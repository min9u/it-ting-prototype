## 다른 화면과 이어진 것
- 상태는 `app/src/data/chat.ts` 하나 (서버 대신, 이 탭 안에서만 기억). 예전 `mock.ts`의 `CHAT_ROOMS`·`CHAT_REQUESTS`와 타입은 지움
- **방문자 뷰**: "대화 요청하기" → 보낸 요청에 들어감(인사 50자, F5 명세). 이미 요청했으면 말풍선이 "⏳ 답변 기다리는 중", 대화방이 있으면 "💬 대화하기" **→ 2026-11-21: 이미 요청했으면 말풍선은 "요청 보냄"(누를 수 없음)**
- **모임**: "모임 채팅"·"모임 대화 열기" 링크가 그 모임의 대화방(`/chat/g-<모임 id>`)으로. 참여 확정·내가 주최인 모임은 모두 대화방이 있음. "내가 연 모임 · 전체 보기"는 요청 탭이 아니라 내 모임으로
- 화면 목록(`/screens`) 채팅 항목을 새 프레임 번호로

## 판단한 것 (확인받을 것)
1. **찻방 = 2D 방 + 3D 두더지**. 찻방 그림이 Figma 에 아직 없어서 명세 밑그림을 그대로 그렸고, 두더지는 땅굴과 같은 3D 두더지(액세서리 포함). 디자이너 그림(또는 glb)이 오면 `TeaRoom.tsx` 의 `RoomArt` 만 바꾸면 됨
2. **모임 찻방은 5마리까지**, 나머지는 "+N명"
3. **첨부(+)는 "모임 공유하기"만**. 사진·파일 첨부는 명세에 내용이 없어서 안 만듦
4. **목 답장**: 1:1 에서 처음 보내면 상대가 "입력 중…" 뒤에 한 번 답함 (팀원 시연용. 실제 서비스엔 없음)
5. 보낸 요청 "요청 취소"는 확인 팝업 없이 바로 (명세에 확인 단계가 없음) + 토스트
