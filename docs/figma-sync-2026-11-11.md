### 반영 못 한 것과 이유
- **얼굴·목·손 아이템 목록**: Figma 스크린샷이 "머리" 탭만 보여 줘서 이름을 모름. 손은 "물감 팔레트" 하나만 넣음. 아이템 아이콘은 스크린샷에서 잘라 쓴 임시본 (`app/src/assets/mole-items/`)
- **미리 보기 두더지**: Figma는 3D 렌더지만 glb 두더지에 아이템 모델이 없어서 2D 아바타 위에 아이콘을 겹쳐 대신함 (`MoleWithItems`)
- **Figma 메모로만 있는 요청**: "‘모임 수정’ 누른 후 페이지 필요", "내가 만든 모임에 신청한 사람 목록(수락·거부) 페이지 없음", "모임 ‘00개씩 보기’", "방명록 정렬", "‘땅굴 놀러가기’ 버튼이 없음", "내 땅굴 → 탐색 전환 모션", "답글 달 때 어느 댓글인지 표시", "회원가입 후 바로 로그인" → 디자인이 없거나 기획 확인이 필요해서 손대지 않음
- 글 상세 B안(494:13242)은 프레임 안 구성이 바뀌었지만 A안 투표 중이라 그대로 둠
