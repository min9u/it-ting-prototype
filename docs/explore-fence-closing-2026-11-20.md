# 탐색 들판: far 에서 울타리가 끊겨 보임 → 켠 구역 둘레로 닫기

- 날짜: 2026-11-20 (시험 브랜치 `try/explore-v3-11`, push 안 함)
- 요청: "far 로 멀어지면 울타리가 잘려 보여. 카메라 far 값인지 안개인지 타깃 한계 때문인지 원인부터 찾아서 알려 줘" → 원인 확인 뒤 사용자가 **B(켠 구역 바깥 경계를 따라 울타리가 끊기지 않게 닫기)** 선택
- 결론: 원인은 카메라가 아니라 **"안 켠 구역은 울타리도 숨김" 규칙**. 켠 구역 둘레를 따라 울타리를 새로 세워 닫음 (인계 모델 `fence.glb` 로 가능)

## 원인

| 의심 | 결과 |
|---|---|
| 카메라 far 값 | 아님. far 평면 138m, 울타리가 보이려면 약 67m 면 충분 |
| 안개 | 아님. `holeField` 에는 안개가 없음 |
| 타깃 한계(바깥 잔디 안쪽 2m) | 아님. 같은 카메라로 울타리만 항상 그렸을 때 끊긴 끝이 사라짐 |
| **구역 필터** | **맞음.** 둘레 울타리 174조각을 "중심이 켜진 구역 안에 있는 것만" 그림 (`inOn`) → 켠 구역 수에 따라 18 / 36 / 71 / 105 / 139 / 174조각 |

3D 핸드오프 v3.11 `camera_zoom_spec_v1_2.md` 53행도 "안 켠 구역은 울타리도 숨김"이라 **의도된 동작**이지만, far(보이는 폭 ±33m)에서는 끊긴 끝이 화면 한가운데 보임. 구역을 하나만 켠 층은 남쪽 변 18조각만 보이고 동·서·북쪽은 땅이 끝나는 모양이 없음.

## 한 일

`app/src/three/fieldFence.ts` (three.js 없는 순수 계산) + `holeField.ts` 한 곳 연결.

1. 켠 구역마다 사방으로 **1.5m 넓힌 직사각형**을 둘레 울타리 선 안으로 자른 것의 합 E
2. E 의 테두리 중 둘레 울타리 위가 아닌 부분 = **새 울타리 길**. 이어진 구역 사이엔 안 생기고 ㄴ자 꺾임도 따라감
3. 둘레 조각은 E 안의 것만 쓰고, 경계에 걸친 조각은 `fence.glb` 의 x 스케일로 잘라 새 길과 만나게 함
4. 새 길은 2m 토막으로 깔되 길이에 맞춰 x 스케일 0.975~1.025 로 끝을 맞춤. 앞면은 둘레 울타리처럼 바깥을 봄
5. 구역 6개를 모두 켜면 새 길 0, 둘레 174조각이 **하나도 안 바뀜**(v3.11 그대로)

| 켠 구역 | 예전 | 지금 (둘레 + 새 길) |
|---|---|---|
| 1 | 18 | 21 + 56 = 77 |
| 2 | 36 | 41 + 70 = 111 |
| 3 | 71 | 75 + 69 = 144 |
| 4 | 105 | 107 + 35 = 142 |
| 5 | 139 | 141 + 34 = 175 |
| 6 | 174 | 174 + 0 |

조각은 12m 칸 인스턴싱이라 늘어난 수는 그리기 비용에 거의 영향 없음.

### 왜 경계 바로 위가 아니라 1.5m 바깥인가

작물 모델이 구역 경계 밖으로 튀어나옴. 모델 반경을 보수적으로 재면 **작물 1.21m · 꽃 0.78m(구역 2 꽃 하나는 경계 밖 0.59m 에 있음) · 풀 0.05m**, 구멍은 경계에서 2.9m 이상 안쪽. 경계 바로 위에 세우면 식물을 뚫고 지나가서 `FENCE_OFFSET = 1.5`(작물 1.21 + 울타리 반 두께 0.08 + 여유). 비활성 구역 쪽에는 그려지는 물건이 없음.

### 인계 모델로 되는가 (사용자가 "안 되면 이유를 알려 줘"라고 한 부분)

된다. `fence.glb` 는 x 방향 2m 직선 한 토막(메시 x ±1, y 0~0.6, z ±0.08)이라 직선 길은 그대로 이어 붙일 수 있음. 다만 알아 둘 것:
- **모서리 전용 조각이 없음.** 새 길이 꺾이는 곳(ㄴ자·동서북 모서리)은 두 직선이 직각으로 맞닿고 반 두께(0.08m)만큼 살짝 파임. 둘레의 둥근 모서리(10조각)는 같은 직선 조각을 비스듬히 돌려 놓아 곡선처럼 보이게 한 것이라, 새 길의 모서리는 그렇게 안 만들고 모두 직각으로 둠
- **핸드오프 규칙과 다름**: "안 켠 구역은 울타리 숨김" → 지금은 안 켠 쪽 1.5m 에 울타리가 서 있음. 디자이너 확인 필요

## 확인한 것

- 단위 테스트 15개 (`src/tests/field-fence.test.ts`): 구역 1~6 · 켜는 방법 63가지 모두 끝이 다른 조각 위에 있음(끊긴 곳 0, 같은 검사를 예전 방식에 돌리면 구역 1~5 에서 2~4곳이 나옴), 6개면 둘레가 원본과 같음, 앞면 방향, 켠 구역의 구멍·작물·꽃·풀과 안 겹침(물건 반경 + 0.08 보다 멂). 둘레 울타리는 원래 모서리 부근 조각끼리 0.4m 겹쳐 있어서 "끝점끼리 만남"이 아니라 "끝점이 다른 조각 위"로 검사
- 진짜 GPU(Apple M4 Pro) + 저장소를 매번 비운 화면, 예전(`?fence=0`) ↔ 새 방식: 서울-12층(구역 1) 시작 자리 5, 서울-3층(구역 3) 시작 자리 30·54·70. 서울-3층 자리 30 far 에서 예전엔 울타리가 한가운데서 뚝 끊기고, 새 방식은 모서리를 돌아 동쪽 변으로 내려감
- 가속 꺼진 경로(SwiftShader): 구운 배경 그림에도 새 울타리가 들어옴
- 테스트 295개, 타입·빌드 OK, 스모크 탐색 7개 (swiftshader · WebGL 없음) 통과
