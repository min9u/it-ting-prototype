## 시연 방법
- 계정: `wrong@ssafy.com`(실패) · `banned@ssafy.com`(정지 팝업) · `new@ssafy.com`(→ 온보딩 1) · 그 밖 형식이 맞는 이메일 + 아무 비밀번호(→ 내 땅굴). 인증 코드 `000000`은 틀림, 다른 6자리는 통과
- 쿼리: 랜딩 `#s1`~`#s4`(해시 라우터 `?s=1~4`), `/login?demo=error|suspended`, `/look?gate=1|reset=1|room=sample-a`, `/password-reset/new?token=demo`, `/password-reset/expired`, 아무 화면 `?device=mobile`, `?guest=1`(비로그인으로)
- 메일이 없어서 "메일 보냄" 화면 아래에 점선 테두리의 **"체험용 · 메일 속 링크 열기"** 버튼을 둠 (실서비스에는 없음)

## 판단한 것
1. **랜딩을 4구간으로 되돌림.** 03 디자인(11-12)은 방 → 이웃 2구간이지만 02 명세(F1 흐름 문장·타임라인)는 땅 위 → 구멍 속 → 방 → 이웃이라 명세를 따름. 푸시인은 왼쪽 굴로(가운데 굴은 두더지가 가려서, 오른쪽 굴은 앞에 팻말이 있어서), 굴을 화면 가운데로 끌어오며 확대. 되돌리려면 `Landing.tsx` 이전 커밋
2. 명세의 "조명이 켜지고 가구가 하나씩 떨어져 놓임"은 11-12 사용자 결정(다 차려진 방을 한 번에 페이드 인)을 유지
3. 랜딩 04 버튼 순서: 명세 그림은 "내 땅굴 만들기"가 왼쪽이지만 Figma 메모(완료 표시)대로 "먼저 둘러보기" 왼쪽 유지
4. 구경한 방 수는 **들어갈 때마다** 하나씩 셈("구경할 때마다 점이 채워진다"). 들판에 굴이 3개뿐이라 서로 다른 방만 세면 4번째 방이 생기지 않음
5. 로그인 성공은 명세대로 항상 내 땅굴(로그인 필요로 튕겨 왔어도 원래 주소로 돌아가지 않음). 예전 "로그인하면 보던 예린이의 방으로 돌아가요" 안내는 명세 흐름("둘러보기의 방은 견본이라 돌아가지 않는다")에 맞춰 뺌
6. 로그인 상태는 **처음 연 주소**로 정함: 시작 화면(F1·F2)으로 들어오면 비로그인, 그 밖의 주소로 바로 들어오면 로그인 상태(개발용 바로 가기·화면 목록이 막히지 않게). 로그인·가입 완료 시 로그인 상태로. 로그아웃은 설정 영역이라 손대지 않음
7. 명세에 문구가 없는 것: 비밀번호 쓸 수 없는 문자 "영문 · 숫자 · 특수기호(!@#$%)만 쓸 수 있어요", 코드 틀림 "인증 코드가 맞지 않아요", 시간 초과 "인증 시간이 지났어요. 코드를 다시 받아 주세요", 정지 팝업 본문(사유·기간 표), 재전송 간격 30초, 코드 유효 5분, 비밀번호 변경 완료 토스트 "비밀번호를 바꿨어요. 새 비밀번호로 로그인해 주세요", 재전송 토스트, PC 안내 부제
8. 비밀번호 확인 칸은 앞부분이 같으면(아직 치는 중) 기다리고, 갈라지거나 길이가 같아졌는데 다르면 바로 오류
9. 이메일 가입은 SSAFY 메일로 제한하지 않음(명세는 형식 검사만). 예전 "@ssafy.com만" 제한은 뺌
10. 약관 동의는 회원가입 2 → 3으로 옮김(명세). 전문 보기는 Figma 메모에서 질문으로만 남아 있어 넣지 않음
11. 캠퍼스·층·기수 목록은 임시값(서울 2·10·12·13층 등, 기수 12~16기)
12. 명세 그림 아래 어두운 칩 중 "가입 때와 같은 규칙(00 공통 9)"은 주석으로 보고 뺐고, "링크는 30분 동안, 한 번만…"은 번호가 붙은 항목이라 화면에 둠. "메일의 링크로 새 비밀번호를 만들 수 있어요"(번호 없음)는 뺌
13. 기기 판별은 창 폭이 아니라 UA·userAgentData·iPadOS 터치로(좁은 데스크톱 창은 그대로). 적용은 F1·F2 라우트만. 다른 영역도 `PcOnly`로 감싸면 됨
14. 견본 방 이름: 명세 예시 "내굴"(독서·게임·캠핑)을 첫 방으로, 나머지 2개는 지어 냄. 관심사 칩은 카탈로그의 세부 관심사 이름으로(캠핑·레트로게임·SF소설·베이킹·보드게임·뜨개질·고전영화)

## 남은 것
- 이미 가입한 이메일로 회원가입할 때의 처리(명세에 없음)
- 견본 방 우체통 위에 자물쇠 표시(3D 오브젝트라 화면 위치를 못 받음. 누르면 로그인으로는 감)
- 대기 루프(두더지 숨쉬기·풀 흔들림·전구), 모바일 세로 영상(명세상 이번 범위 밖)
- 랜딩 04 팻말 태그는 화면 비율에 따라 하늘에 걸릴 수 있음(이전부터 있던 문제)
- 로그아웃 시 `setAuthState('guest')` 호출은 설정 영역에서 붙여야 함
- 실제 SSAFY PC·브라우저에서 스크롤 푸시인 느낌 확인
