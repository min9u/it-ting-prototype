- **최신 02 스크린샷(2026-11-16)과 결정 표가 다른 곳은 결정 표를 따름**: 스크린샷에는 모임 전용 "카테고리"(스터디/프로젝트/…)와 "생성 완료 팝업으로 이동", "그만두기 = 저장 전 취소(18)"가 다시 적혀 있음. M15(대표 관심사), M1(상세 + 토스트, 팝업은 "보관 · 사용 안 함"), M3(임시 저장)으로 구현
- 관심사 필터 칩은 **관심사 분야 11개**로 함 (모임 대표 관심사가 세부 관심사·예전 주제 이름이 섞여 있어 분야로 묶음). 대표 관심사·태그는 **내 관심사 중에서** 고름 (M15에서 미정)

- 주최자 확정 0명 화면의 "확정 0 / 6명"은 M2(주최자 포함)에 맞춰 **확정 1 / 6명**으로 씀
