## 동작 (명세 그대로)
- 새 학기 들판이 열렸는데 이번 학기의 캠퍼스 · 층을 안 고른 계정이 접속하면 **내 땅굴 위**에 안내가 뜸 (`screens/burrow/NewTermNotice.tsx NewTermGate`, 로그인 뒤 틀 `AppLayout`에 한 번)
- **닫을 수 없음**: × · "나중에 하기" · Esc · 바깥 클릭 모두 없음(`Modal onClose` 를 비워 두고 `hideClose`). 고르기 전에는 다른 화면도 못 씀(내 땅굴이 아니면 `/burrow` 로 되돌림 + 팝업이 뒤를 막음)
- 지난 학기에 고른 캠퍼스가 처음에 선택돼 있고 그 층에 "지난 학기" 표시, 층을 골라야 [이 층으로 정하기]가 켜짐
- 누르면(`data/newTerm.ts chooseNewTermFloor`): 내 땅굴이 고른 캠퍼스 · 층 들판으로 이사(방명록 · 단골 · 방 모습은 그대로), 프로필의 캠퍼스 · 층 변경, 지난 학기 들판의 자리는 비어 입구가 안 남음 → 완료 토스트
- **내 정보 수정**에서 캠퍼스 · 층을 바꿔도 땅굴이 그 들판으로 이사(명세 04): `data/field.ts moveMyBurrow` 한 곳. `MY_FLOOR` 를 같은 객체 그대로 고쳐서 탐색 · 미니맵이 따라옴(전에는 프로필만 바뀌고 `MY_FLOOR` 는 서울-2 고정이었음)

## 시연 손잡이
- `/burrow?newterm=1` → 새 학기가 열린 것으로 함(주소에 붙어 있으면 새로고침해도 다시 뜸) · `?newterm=0` → 되돌림(지난 학기 자리로 복귀)
- 저장하지 않음(탭 메모리만): 저장하면 한 번 켠 뒤 모든 화면이 안내에 막혀 화면 목록 · 스모크가 깨짐. 화면 목록에 "내 땅굴 – 새 학기 안내" 추가

## 백엔드
- `GET /me` 의 `nextStep = NEW_TERM` 이면 안내를 띄움, "이 층으로 정하기" = `POST /me/burrow/move {campusFloorId}`(응답 `entrance`), 끝나면 닫힌 화면과 `GET /me` 를 다시 불러옴. 목 서버는 아직 이 API 를 안 거침(`newTerm.ts` 가 서버 노릇)
