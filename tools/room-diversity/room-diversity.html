    무엇을 바꿨나: 대분류 색 묶음 {{N_THEMES}}개

    대표 관심사(맨 앞)의 대분류가 땅굴 분위기를 정해요 (온보딩 문구 그대로). 묶음마다 벽 · 바닥 · 나무 뼈대 · 러그 색과 가구 팔레트 8자리가 있고, 사람마다(회원 id 씨앗) 다른 벽 · 바닥 빛깔(40%), 이불 · 방석 · 러그 무늬, 침대 머리판 · 버섯 갓 · 테이블보 같은 모양이 달라요. 같은 사람은 늘 같은 방이에요.

    색은 "화면에 보이는 색"으로 적었어요. 껍데기(벽 · 바닥 · 나무)는 조명을 구운 그림이라, 앱이 톤 매핑(AgX)을 거꾸로 풀어 그 색이 나오도록 구운 빛에 곱해요 → 음영 · 나뭇결은 그대로. 동물(고양이 · 강아지 …)은 칠하지 않아요. 앱에서 ✨ 이펙트 → 🎨 땅굴 색 다양하게를 끄면 디자이너 원래 색으로 돌아가요.

    방 {{N}}개

    칩 색은 관심사 대분류, 테두리만 있는 칩은 방에 놓이는 소품이 없는 관심사예요. 위 "보는 것"에서 나란히를 고르면 카드마다 전 · 후가 나란히 나와요.

    보기

    전에는 왜 비슷해 보였나 · 무엇이 남았나

    전: 늘 같았던 것

    • 화면에서 큰 것은 전부 고정: 벽 · 바닥 · 나무 뼈대 · 침대 · 러그 · 원탁 · 램프 · 가랜드 (벽지를 같게 놓으면 방 넓이의 {{B_FURN_NEVER}}가 어느 방에서나 같았음)
    • 관심사 가구는 작고 같은 띠에 모여 있음 (벽 아래쪽 띠 · 바닥 가장자리)
    • 같은 대분류면 같은 방, 빌려 쓰는 세트(스포츠 → 아웃도어, 외국어 → 책)는 다른 대분류끼리도 같은 방 (운동형 · 여행형 {{B_SPORT_OUT}})
    • 벽지 8가지 중 6가지가 비슷한 연한 무늬

    후: 바꾼 것 · 남은 것

    • 바꾼 것: 벽 · 바닥 · 나무 뼈대 · 러그 · 기본 가구 · 관심사 가구 색 (대분류 묶음), 이불 · 방석 · 러그 무늬와 기본 가구 모양 (사람마다)
    • 그대로: 가구 배치 · 가구 종류 (관심사 가구는 여전히 작고 같은 띠), 가랜드 · 액자 · 매달린 화분 (구운 그림 한 장이라 못 칠함), 두더지, 카메라 구도
    • 소품 없는 소분류 39개는 여전히 방에 아무것도 안 생김 (디자이너 요청)
    • 같은 대분류끼리는 벽 결이 같음 (사람마다 다른 빛깔 40%, 무늬 · 모양이 다름)
    1단계에서 고친 것: 벽지 문제 전에는 남의 땅굴 화면이 집주인이 저장한 벽지 · 가구를 받지 않고, 내 땅굴(맨 앞 관심사)과 다른 규칙(가장 무거운 대분류)으로 벽지를 다시 계산했어요 (예: "나"는 내 화면 01 기본, 남이 보면 08 줄무늬). 이제 내 땅굴 · 남의 땅굴 · 온보딩 미리 보기가 한 함수(data/roomLook.ts roomLookOf)로 방 모습을 정하고, 저장한 방(BurrowDto.room)이 방문자 뷰까지 그대로 와요. "나"를 두 화면으로 찍어 비교하니 다른 픽셀 0%였어요.

    저사양 PC (그래픽 가속 끔)

    남의 땅굴(예린, 입장 연출 있음)에 들어가서 가만히 6초 → 걷기 8초 → 가만히 6초. 반복 3번의 가운데 값. 색 묶음은 재질 색 값만 바꾸고(셰이더는 그대로), 무늬 · 벨벳 방석 · 모양 덧붙이만 그리기를 조금 늘려요.

    남은 것 · 부탁할 것

    • 디자이너: 관심사 가구 · 소품 채우기디자이너 요청빌려 쓰는 세트 3개(스포츠 · 외국어 · 덕질), 소품 없는 소분류 39개. 색으로 방 전체는 달라졌지만 "무슨 관심사인지"는 여전히 작은 가구로만 보여요.
    • 디자이너: 재질 나누기 · 러그 떼기 · 장식 칠하기디자이너 요청침대 크림 = 시트 + 베개처럼 한 재질을 같이 써서 따로 못 칠함. 러그는 껍데기에 구워져 테두리 · 가운데가 한 색이 됨. 가랜드 · 액자 · 매달린 화분은 구운 그림 한 장이라 테마 색을 못 받음.
    • 디자이너: 기본 가구 변형 모델 · 관심사 액자디자이너 요청침대 · 협탁 · 원탁 변형 2~3종, 벽 액자 3개에 넣을 관심사 그림(소품 없는 소분류용). 액자 그림을 받으면 코드 쪽은 그림만 끼우면 됨.
    • 백엔드: 땅굴 응답의 roomAPI 초안wallpaperId · furniture · themeId(꾸미기 색 탭). 나머지 꾸미기 값은 회원 id 씨앗으로 프론트가 계산해서, 씨앗 = 실제 회원 id 여야 함.
    • 확인받을 것정할 것꾸미기 "색" 탭을 명세에 넣을지, 색 묶음 12개 색감, 같은 대분류 안에서 벽 빛깔을 바꾸는 정도(지금 40%).

    어떻게 찍고 쟀나

    찍은 방법 · 계산 · 고른 사람

    찍기: 헤드리스 크롬, 그래픽 가속 켬({{RENDERER}}), 창 1440×900. 앱의 실험 경로 /lab/rooms(방문자 뷰와 같은 RoomView · 같은 땅굴 API 길)에서 "다 차려진 방"으로, 관심사 이펙트 꺼짐, 리액션 버튼 줄 숨김, 두더지 자세 고정 · 같은 난수 씨앗.

    전 · 후: 전 = 다양성 작업 전 앱(11-18 1차 비교 때 같은 PC로 찍은 그림, 앱 코드 같음). 후 = 이번 작업 뒤 앱(🎨 땅굴 색 다양하게 켬, 기본값). 빈 방(관심사 0개)은 대표 관심사가 없어서 둘 다 디자이너 원래 색.

    세 번 찍음: ① 보이는 그대로(카드 · 크게 보기) ② 두더지만 숨김(숫자 · 차이 지도 · 비교) ③ 두더지 숨김 + 벽지 그림 01 고정. 후 묶음은 ③에서도 색 묶음이 벽 · 바닥 색을 바꿈.

    계산: 방 둘레(장면 가로 130~1310px)만 잘라 반으로 줄여(590×418) 칸마다 비교. ΔE76 10 넘으면 "다름". 방마다 숫자 = 다른 칸 ÷ 방 칸. 방 바깥 흙색 배경은 뺌.
