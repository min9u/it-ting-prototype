# three.js 탐색하기(field) 반복 기록

기준: `ref-field.png` (Figma "땅굴 메인 – 탐색하기- 돌아다니는 화면 - 사이드바 접힌 버전"). 스크린샷은 `shots/`.

배치 방법: 원본 그림의 화면 좌표를 카메라 광선으로 땅에 쏴서(`P`, `PD`) 3D 위치를 얻고, 높이는 화면에서 꼭대기가 원본과 같은 y에 오도록 이분 탐색(`heightTo`)으로 맞춤. 그래서 원근이 조금 어긋난 AI 그림이어도 위치가 겹침.

| 회차 | 원본과 다른 점 | 고친 것 |
|---|---|---|
| r1 | 두더지 확대 시점이 얼굴만 잡힘, 둔덕이 너무 높아 구멍 안 보임, 덤불이 크고 빽빽, 언덕 높음, 채도 과함, 코가 넓적 | 확대는 전체 비율 유지, 하늘·땅 색, 언덕 낮춤, 덤불·꽃 크기 줄임 |
| r2 | 둔덕 구멍 그라데이션이 위아래 뒤집힘, 두더지 뒤 검은 사각형, 머리 쪽이 넓음 | 그라데이션 뒤집기, 두더지 단면을 아래가 넓은 젤리형으로 |
| r3 | 검은 사각형은 GTAO 후처리 탓 (후처리 끄면 사라짐), 구멍 안쪽이 여전히 주황 | GTAO 제거, 구멍 안쪽이 일찍 어두워지게 |
| r4 | 두더지가 조금 크고 아래로 내려옴, 머리 뾰족, 얼룩 진함, 눈 간격 넓음 | 위치·크기 재조정, 머리 둥글게, 얼룩 흐리게, 눈 간격 좁힘, 둔덕 볼록하게 |
| r5 | 구멍이 덜 어두움, 볼터치가 진하고 김 | 구멍 더 어둡게, 볼터치 연하고 동그랗게 |
| r6 | 최종 | |

남은 차이: 두더지 털의 보송한 질감과 빛 번짐, 표지판 나무결, 먼 곳의 흐려짐. 실시간 렌더링으로는 한계라 모델(glb)과 구운 조명이 필요.

## 조명 바꾸기 (PlayCanvas식)
PlayCanvas 버전이 더 좋아 보인 이유가 조명이라 같은 방식을 옮김. 탐색하기는 "PlayCanvas식 조명" 체크박스(또는 `#old`)로 이전 조명과 비교 가능.

| 회차 | 바꾼 것 | 결과 |
|---|---|---|
| l1 | 반구광 → 하늘·풀색 그라데이션 환경광(PMREM), VSM 그림자, GTAO | 부드러워졌지만 두더지 뒤 사각 얼룩 재발 → GTAO 자체 문제로 확인 |
| l2 | GTAO → N8AO (n8ao 1.10.1 + postprocessing 6.36.0) | 얼룩 사라짐 |
| l3·l4 | 잔디 밝은 연두, 해를 왼쪽으로 옮겨 그림자가 화면 쪽으로, PCF + 반경 블러 | PlayCanvas 버전과 거의 같은 느낌 |
| 최종 | 그림자 normalBias 0.06 (두더지 몸 사선 잡티 제거) | |

방 안: 환경광을 크림→살구→테라코타 그라데이션으로, 벽·기둥·바닥 색을 PlayCanvas 버전 값으로, 점광원과 색보정의 주황 틴트를 줄이고 톤매핑을 Neutral로. 이전 조명 스크린샷은 `shots/final-*-oldlight.png`.

## 두더지 펠트 질감 (원본 `shots/ref-mole.png`에 맞추기)
사용자 요청: 질감이 가장 큰 문제, 펠트 느낌으로. 회차별 확대 샷은 `shots/f1-mole.png` ~ `f9-mole.png` (로컬에만), 최종 `shots/final-mole.png`.

펠트를 내는 방법 세 가지:
- 섬유 노멀맵: 짧은 털 가닥 9,000개를 높이맵으로 그린 뒤 기울기로 노멀을 만듦 (`feltNormalTex`)
- sheen: `MeshPhysicalMaterial`의 천 재질 반사로 가장자리가 은은하게 밝음
- 잔털 껍질(셸) 12겹: 몸을 법선 방향으로 조금씩 부풀리고, 픽셀마다 무작위 알파로 바깥일수록 털을 드문드문 → 윤곽이 보송함

| 회차 | 원본과 다른 점 | 고친 것 |
|---|---|---|
| f1 | 몸이 어둡고 아래가 탁함, 가장자리 결이 안 보임, 코가 연하고 납작, 볼이 크고 붉음 | (첫 펠트 적용) |
| f2 | 비율·얼굴 위치만 남음 | 몸 색 밝게, sheen 강하게, 코·코끝 진하게, 볼 작고 연하게 |
| f3 | 세로로 김(1.36:1, 원본 1.25:1), 눈·코가 낮고 눈 간격 넓음, 볼이 낮음 | 폭 넓히고 눈·코·볼 위로, 눈 간격 좁힘 |
| f4 | 원본보다 6% 크고 아래로 내려옴, 눈 반짝임 안 보임 | 발 위치 올리고 하이라이트 밖으로 |
| f5 | 폭 4% 좁음, 정수리 뾰족, 발이 크고 하얌 | 폭·돔 넓히고 발 작게 (→ 몸통과 머리 사이에 턱이 생김) |
| f6 | 턱은 반지름 불일치 탓 | 옆면 꼭대기와 돔 시작 반지름을 맞춤 (→ 정수리에 밝은 세로줄) |
| f7 | 정수리 uv를 위에서 투영해 섞어 봄 | 경계에 띠가 생겨 되돌림 |
| f8 | 잔털 껍질이 극점에 몰린 탓으로 보고 정수리 근처 껍질을 줄임 | 줄이 조금 남음 |
| f9 | 진짜 원인은 극점에서 노멀맵 방향 계산이 불안정한 것 | 셰이더를 고쳐 정수리 부근만 노멀맵 세기를 0으로 → 줄 사라짐 |

남은 차이: 정수리 꼭대기의 아주 작은 점, 원본의 부드러운 빛 번짐(간접광). 방 안에도 같은 두더지를 넣음.

### 눈 사시 수정
- 문제: 눈을 몸 곡면을 따라 바깥으로 돌려 붙여서 두 눈이 서로 다른 방향을 보는 것처럼(사시) 보였음. 하이라이트도 곡면 기준이라 위치가 엇갈림
- 수정: 두 눈을 거의 정면으로(회전 0.2배), 몸에 조금 더 묻고, 하이라이트는 두 눈 모두 같은 오프셋(오른쪽 위)으로

### 머리 좁게 (원본형 단면)
- 사용자: "원본은 몸통에서 머리까지 좁아지는데 지금은 원통형"
- 원본·이전 확대 샷에서 줄마다 몸 폭을 재서 비교 (가장 넓은 곳 = 1): 눈 높이(0.75) 원본 0.78 / 이전 0.88, 이마(0.82) 원본 0.69 / 이전 0.81
- 새 단면: 높이 0.2에서 가장 넓고, 그 위는 초타원(n=2.6) x 선형 테이퍼(12%)로 꾸준히 좁아짐. 눈 각도 0.44→0.55, 볼 0.6→0.73 (머리가 좁아져서 원본 간격 유지)
- 결과: 높이별 폭이 원본과 3% 안쪽 (눈 높이 0.80, 이마 0.71). `MOLE_FELT.shape` = taper(기본) / cyl(이전, 해시 `cyl`), 탐색하기 페이지에 "머리 좁게(원본형)" 체크박스
- 스크린샷: `shots/final-mole.png`(원본형), `shots/final-mole-cyl.png`(이전)

## 가구 정리 + 두더지 움직임 (2026-11-10)
두더지는 이 three.js 버전으로 임시 고정. 원본 코드는 `lib/`로 옮김 (페이지에는 `node lib/splice.js <html>`, `node lib/splice-furniture.js <html>`로 끼워 넣음).

| 파일 | 내용 |
|---|---|
| `lib/mole-felt-cfg.js` | 펠트 재료(섬유 노멀맵, 잔털 알파맵)와 `MOLE_FELT` 설정 |
| `lib/mole.js` | `makeMole()` — 부위를 `mole.userData.parts`(rig, eyes, highs, paws, feet)로 노출 |
| `lib/mole-motion.js` | `createMoleMotion(mole, opts)` → `{ update(dt, t), walkTo(p), setWander(o) }` |
| `lib/furniture.js` | `FURNITURE` 카탈로그 + `furnishRoom(root, { interests })` |

### 가구 정리
- 가구 26개를 카탈로그로: 항목마다 `id`, `label`, `cat`(Figma 온보딩 11개 분야 + 기본), 이름표 위치 `tag`, `build(root)`
- 자리는 원본 렌더 배치 그대로. 고른 분야의 가구만 놓고 나머지 자리는 비움
- 원본에 없던 **반려동물** 가구(방석 + 밥그릇)를 앞 왼쪽 빈자리에 추가, 앞쪽 잡동사니(작은 가방)는 뺌
- 방 페이지: 관심 분야 칩으로 켜고 끄기, "가구 이름표"(랜딩 03처럼 분야 + 이름). 확인용 해시 `only=음악,책·글`

### 두더지 움직임
- 대기: 숨쉬기, 2.5~4.5초마다 깜빡임(가끔 두 번), 앞발 살랑 (Figma 모션 메모 "두더지 숨쉬기·깜빡임 3초 루프")
- 걷기: 목표 쪽으로 몸을 돌린 뒤 뒤뚱(좌우 기울기 + 통통), 발 번갈아 들기, 앞발 흔들기. 도착하면 살짝 눌렸다 펴짐
- 탐색하기: 땅을 누르면 그쪽으로 걸어감(둔덕 안은 못 들어감), 가만히 두면 근처를 돌아다님
- 방 안: 러그 위 빈자리만 돌아다님
- `prefers-reduced-motion`이면 깜빡임만, 걸음은 미끄러지듯
- 헤드리스는 rAF가 거의 안 돌아서 `#bare-sim<프레임수>`로 걷는 자세를 미리 계산해 확인
