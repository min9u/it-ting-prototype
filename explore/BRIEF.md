# 3D 엔진 비교 실험: 공통 과제

같은 두 장면을 엔진 세 개로 만들어 Figma 원본에 얼마나 가까워지는지 비교한다.

| 폴더 | 엔진 | 버전 (2주 이상 지난 버전으로 고정) |
|---|---|---|
| `explore/3d/` | three.js | 0.165.0 |
| `explore/babylon/` | Babylon.js | 9.31.3 (`babylonjs` UMD, jsDelivr) |
| `explore/playcanvas/` | PlayCanvas engine | 2.23.3 (`playcanvas` ESM, jsDelivr) |

## 만들 것 (폴더마다 두 개)
1. `room.html` 방 안. 기준 이미지: `explore/3d/ref.png` (= `design/figma/room-cutout.png`, 636×477, 배경 투명)
2. `field.html` 탐색하기(땅 위). 기준 이미지: `explore/3d/ref-field.png` (2880×1920 화면 캡처. 위 126px는 헤더라 잘라내고 아래 2880×1794 = 1440×897 비율이 장면. "방노트" 버튼과 "내 땅굴/탐색" 토글은 UI라 3D로 만들지 않음)

기준 이미지는 각 폴더로 복사해서 상대 경로로 쓴다 (아티팩트로 올릴 때 같이 올림).

## 페이지 규칙 (`explore/3d/room.html`을 참고 구현으로 볼 것)
- 아티팩트 형식: `<html>/<head>/<body>` 태그 없이 `<title>`, `<style>`부터 시작. 외부 스크립트는 jsDelivr/cdnjs/unpkg만, 버전 고정. 그 밖의 fetch 금지 (텍스처는 canvas로 직접 그림, 모델 파일 없이 코드 도형만)
- 비교 UI: "3D만 / 밀어서 비교 / Figma 원본" 세 모드 + 슬라이더. 3D 캔버스와 기준 이미지가 같은 박스에 같은 비율로 겹쳐야 함 (room 4:3, field 1440:897)
- 스크린샷용 해시: `#3d`, `#ref`, 그리고 `#bare`(UI 없이 장면만 창 전체에 꽉 차게. field는 1440×897 창으로 찍음), `#bare-mole`(두더지 부분만 크게. 원본 쪽도 같은 영역을 잘라 보여 주는 `#bare-ref-mole` 함께)
- 렌더가 끝나면 `window.__ready = true`. 헤드리스 Edge는 rAF가 거의 안 돌기 때문에 첫 프레임은 동기적으로 그릴 것
- 페이지 아래에 원본 대비 항목별 판정(가까움/부분/차이 큼)과 그 엔진의 장단점 메모

## 장면 명세

### 방 안 (room)
`explore/3d/room.html`과 `docs/3d-figma-reproduction.md` 참고. 반쪽 돔(뾰족하지 않은 둥근 포탄형), 갈비뼈 기둥 3개, 꼭대기 고리와 가운데 막대, 펜던트 조명, 삼각 깃발 줄, 꼬마전구, 걸이 화분, 나무 판벽 띠, 원형 마루 바닥, 노랑+초록 원형 러그, 가구(침대·배낭·빈백·책장·오락기·벽 TV·버섯 스탠드·티테이블·지구본·부엌 선반·피아노·스피커·러닝머신·이젤·여행가방·영사기·삼각대 카메라·벽 선반·코르크보드·매트 롤), 가운데 두더지. 색은 살구·연어색 벽, 갈색 테두리, 채도 낮고 따뜻하게.

### 탐색하기 (field) — 두더지가 핵심
- 하늘: 위쪽 맑은 하늘색(#9fd0f5 근처) → 지평선 쪽 옅게. 구름 없음
- 땅: 밝은 연두 잔디(#8fcf4a 근처), 멀리 갈수록 옅어지고 지평선은 완만한 언덕 곡선(화면 높이의 약 30% 지점)
- 흙 둔덕 3개: 주황 점토(#e3894a 근처) 도넛 모양, 안쪽 구멍은 아래로 갈수록 어두운 갈색→검정. 가운데 큰 것(두더지 바로 뒤), 왼쪽 뒤, 오른쪽 뒤
- 나무 표지판 3개: 둥근 모서리 판자(주황 갈색) + 기둥. 가운데 둔덕 왼쪽 뒤, 오른쪽 뒤(살짝 기울어짐), 오른쪽 앞(가장 큼)
- 꽃: 흰 데이지(노란 중심), 분홍·코랄 꽃(노란 중심), 초록 줄기·잎. 덤불: 연두색 공 여러 개를 뭉친 덩어리. 작은 돌멩이(갈색·크림), 주황 흙덩이. 멀리까지 흩뿌림 (인스턴싱 권장)
- 조명: 밝고 부드러운 낮 햇빛, 그림자는 옅고 부드럽게. 전체가 매끈한 점토 장난감 느낌
- **두더지** (화면 가운데 아래, 둔덕 앞 잔디 위에 정면으로 서 있음. 1440×897 기준 대략 가로 x 600~820, 세로 y 470~770):
  - 몸: 세로로 긴 탄환/총알형. 바닥은 평평하고 아래가 약간 넓으며, 옆면은 거의 수직, 위는 둥근 돔. 높이:폭 ≈ 1.3:1, 앞뒤로 약간 납작
  - 색·질감: 먼지 묻은 듯한 회갈색(#7a6257 근처)에 밝은 얼룩이 은은하게, 완전 무광, 털은 보이지 않고 매끈한 점토
  - 눈: 작고 까만 반짝이는 타원 두 개 (흰 하이라이트 점). 위에서 약 28% 높이, 두 눈 사이가 폭의 약 40%
  - 볼: 눈 바로 아래 바깥쪽에 흐릿한 분홍 볼터치 두 개
  - 코: 얼굴 가운데 크고 넓적한 연분홍(#f4a3a0) 타원 주둥이가 앞으로 튀어나옴. 가운데 아래에 진분홍 콧구멍 점 하나
  - 손: 몸 옆 가운데보다 약간 아래, 작은 분홍 앞발이 양옆으로 살짝 튀어나옴 (흰 발톱 2~3개)
  - 발: 바닥 앞쪽에 연분홍·흰색 납작한 타원 발 두 개
  - 입은 보이지 않음. 귀 없음

## 반복 방법 (필수)
1. 만들고 → `#bare`/`#bare-mole` 스크린샷 → 기준 이미지와 Read로 나란히 비교 → 다른 점을 목록으로 적고 → 고친다. **최소 3회 반복**, 두더지는 따로 확대 비교
2. 회차별 스크린샷은 `explore/<엔진>/shots/r1-field.png` 식으로 저장 (최종본 포함, 너무 크면 1440 폭 이하로)
3. 회차별로 무엇이 달랐고 무엇을 고쳤는지 `explore/<엔진>/NOTES.md`에 기록

## 확인 방법
```
node explore/serve.js 5191        # http://127.0.0.1:5191/babylon/field.html#bare
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --use-angle=swiftshader \
  --enable-unsafe-swiftshader --virtual-time-budget=20000 --window-size=1440,897 \
  --screenshot=<절대경로>.png "http://127.0.0.1:5191/babylon/field.html#bare"
```
- 서버는 백그라운드로 띄우고 끝나면 반드시 종료. 포트는 엔진마다 다르게 (three 5190, babylon 5191, playcanvas 5192)
- Bash에서 `node -e` 안에 백틱 금지 (스크립트 파일로). `python`은 이 PC에서 멈추니 쓰지 말 것
