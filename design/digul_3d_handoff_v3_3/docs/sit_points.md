> **v3.3 변경 (빈백 전용 앉기)**: ① 모든 sit point 노드에 extras **`sit_clip_set`** 추가 — 방석 2개 = `"cushion"`, 빈백 `sit_point_chair_01` = `"beanbag"` (카탈로그 `sit_point` 옆 `sit_clip_set` / `sit_clips`에도 같은 값). 이 값으로 재생할 clip 3개를 고름 ② 빈백은 새 clip 3개(`mole_sit_beanbag_v2`, `mole_sit_idle_beanbag`, `mole_stand_up_beanbag_v2`, **두더지 glb v1.2에 들어 있음**)를 씀. **sit point 위치·방향·높이 0.24m와 걸어오는 시작점 (−0.81, −0.72)은 그대로**

- 원본: `room_final_v5.blend` → 컬렉션 `sit_points` (Empty). `sit_point_cushion_01`, `sit_point_cushion_02`는 `models/room_base_v2.glb`의 방석 노드 자식으로 들어 있음 (이름 `sit_point_cushion_0x`, extras `sit_point: true`)
- 각 Empty의 위치 = 두더지가 앉았을 때 **엉덩이(루트 뼈, 발밑 중앙)가 놓이는 자리**, Empty의 -Y = 앉아서 바라보는 방향

## 앉아서 커피 마시기

- `mole_drink`는 **상체만**(upper_body, arm_L, arm_R, 눈, 컵) 움직이도록 정리함. root, lower_body, 발은 건드리지 않음
- 앉아서 마실 때: `mole_sit_idle`(또는 `_chair`)을 계속 재생하면서 그 위에 `mole_drink`를 덮어 재생
  - three.js에서는 두 클립이 상체 트랙을 함께 갖고 있으므로, 마시는 동안 sit_idle 클립에서 upper_body·arm·눈 트랙을 빼거나(subclip/트랙 필터) drink의 weight를 우선 적용
- 서서 마실 때도 같은 `mole_drink` 그대로 사용 가능
- 앉은 상태(방석·빈백 모두)에서 72프레임 전부 컵·몸·코·팔 겹침 0건 확인

## 노란 방석 `sit_point_cushion_02` (11/11)

- 노란 방석을 원탁 앞쪽(카메라 쪽)으로 옮김: (−0.70, 1.85) → **(−0.90, 0.35)**, **+90° 회전** (방 가운데를 바라보고 앉음, three.js `rotation.y = +90°`)
- sit point = 방석의 자식, 월드 **(−0.95, 0.35, 0.13)**. 걸어오는 시작점(앞 0.7m) = **(−0.25, 0.35)**
- 이전 막힌 점(앞 0.7m가 원탁 위)은 **해결됨**. `approach_blocked_by` 표시는 지움
- 확인: `mole_sit_cushion`·`mole_sit_idle`·`mole_stand_up_cushion` **전 프레임**에서 두더지 몸과 다른 가구(침대, 협탁, 원탁, 하늘색 방석, 빈백, 장식 등) 최소 거리 — 걸어와 앉기 2.7cm / 앉아 있기 4.3cm / 일어나기 4.0cm (모두 2cm 이상). 방석과 다른 가구는 24cm 이상
- 두더지 자리(0,0)와 앞쪽 통로(x ±0.7, 카메라 쪽)는 막지 않음. 하늘색 방석(−0.10, 1.50)과 겹치지 않음
- 걸어오는 시작점은 두더지가 서 있는 자리 바로 옆이라, 웹에서는 두더지를 (−0.25, 0.35)에서 −X 방향으로 걷게 하면 됨 (방석 쪽 +90° 회전)

## 빈백 `sit_point_chair_01` (5묶음 A, 11/11)

- **구조**: `bean_bag` 노드의 자식. 월드 (−1.50, −0.60, 0.24), 월드 회전 80°(three.js `rotation.y = 80°`). 자식 노드의 로컬 값은 위치 (0, 0.24, 0) / 회전 −31.8° (빈백이 슬롯에서 111.8° 돌아 있어서). **두더지는 이 노드의 월드 행렬 위치·회전에 그대로 두면 됨** (방석과 같은 규칙)
- **앞 0.7m에서 걸어와 앉기**: 걸어오는 시작점 = (−0.81, −0.72). `mole_sit_beanbag` 첫 프레임의 루트 뼈가 정확히 이 점이고, `mole_stand_up_beanbag` 마지막 프레임도 같은 점
- **왜 80°인가** (방향별 비교, 전 프레임 두더지 몸과 다른 가구 최소 거리):

| 월드 방향 | 시작점 | 최소 거리 | 결과 |
|---|---|---|---|
| 0° (카메라 쪽, 이전 값) | (−1.50, −1.30) | 침대 0.0cm | 닿음 → 안 씀 |
| 111.8° (빈백 앞, 방 가운데 쪽) | (−0.85, −0.34) | 노란 방석 1.1cm | 너무 가까움 → 안 씀 |
| 45° | (−1.01, −1.10) | 9.2cm | 통과 |
| **80° (채택)** | **(−0.81, −0.72)** | **9.6cm** (걸어와 앉기 11.6 / 앉아 있기 12.2 / 일어나기 9.6) | 통과 |

- **빈백 파고듦** (노란 방석과 같은 방식, 점 검사): 두더지 몸이 빈백 안으로 들어간 깊이 — 앉아 있을 때 몸 **최대 13.8cm**·발 최대 10.5cm, 걸어와 앉는 중 몸 13.7cm, 일어날 때 13.7cm (정점의 6~20%가 빈백 속). 노란 방석은 같은 검사에서 5.9cm. 빈백은 말랑해서 몸이 묻히는 것을 원래 설계(앉는 높이 0.24m, 빈백 겉 높이 0.44m)로 했고 렌더에서도 발바닥이 빈백 겉에 살짝 눌린 모양으로 보임. 바닥(z<0)을 뚫는 프레임은 없음 (가장 낮은 점 −0.7cm)
- 두더지 자리 (0,0)와 앞쪽 통로는 막지 않음. 시작점 (−0.81, −0.72)은 통로(x ±0.7) 바로 바깥

### 빈백 전용 동작 (v3.3, 11/11) — 눌림·발 검사

- 두더지 오브젝트는 위 sit point(월드 80°)에 그대로 두고 3개 clip을 재생. 방 안에서 전 프레임 점 검사한 결과 (`mole_sit_idle_beanbag` 61프레임 전부 + 앉기 끝 프레임):

| 항목 | 옛 동작 (`mole_sit_idle_chair`) | **새 동작 (`mole_sit_idle_beanbag`)** | 기준 |
|---|---|---|---|
| 몸이 빈백에 눌린 깊이 | 13.7cm | **4.6~4.9cm** (앉기 끝 4.8cm) | 3~5cm |
| 발이 빈백 속으로 묻힌 깊이 | 6.5~6.8cm | **최대 2.0cm** (왼발, 오른발 0.6cm) | 닿는 정도 |
| 발이 빈백 표면에서 뜬 거리 | 0 | **0.9cm 이하** (앉기 끝 0.2cm) | 닿음 |
| 발과 몸통 사이 거리 | 0 (겹침) | **0.7cm 이하** (앉기 끝 0.4cm) | 1cm 이내 |
| 걸어오는 첫 프레임 가장 낮은 점 | −0.7cm | **−0.7cm (같음, 발이 바닥에 닿음)** | 바닥에 닿음 |
| 일어난 뒤 마지막 프레임 | −0.7cm | **−0.7cm (같음)** | |
| 다른 가구와 최소 거리 | 8.5cm (앉기 중, 침대) | **16.4cm 이상** (앉기 16.4 / 앉아 있기 22.1 / 일어나기 18.3) | 2cm 이상 |

- 앉는 도중 몸이 빈백에 들어가는 최대 깊이: 앉기 8.0cm, 일어나기 7.0cm (옛 동작 13.7cm). 앉는 순간 잠깐이라 빈백이 눌리는 정도로 보임
- 앉기 끝 → 앉아 있기 첫 프레임, 앉아 있기 끝 → 일어나기 첫 프레임의 이음 자세 차이는 옛 동작과 같음 (최대 0.022). 앉아 있기 61프레임은 첫·끝 같아서 반복 이음 없음
- `mole_drink` 겹쳐 재생은 그대로 가능 (상체 트랙만 있음)
