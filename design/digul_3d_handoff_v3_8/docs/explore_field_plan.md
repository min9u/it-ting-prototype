## 2. 들판 크기와 구멍 좌표
- 렌더 카메라(거리 12m, 45°)의 한 화면: 아래 폭 9.6m ~ 위 폭 17.4m, 깊이 10.7m (약 145㎡, 평균 폭 13m).
- 제안: **36×36m 정사각형**(≈ 가로 2.8화면 × 세로 3.4화면), 울타리는 가장자리에서 0.6m 안쪽. 카메라 목표점은 x ±9.3, y 3.8~29.1 로 제한하면 땅 밖이 안 보임.
- 구멍 최소 간격 **6m(3칸)** (기존 4m → 상향). 한 화면에 구멍 약 4~6개. 집·사다리와는 4m 이상. 좌표는 모두 2m 격자(원점 = 들판 남쪽 가운데, x ±18, y 0~36).
- **A안 (5줄×4, 지그재그) — 채택**: 줄 y≈8/14/20/26/32, 줄마다 엇갈림 + 모든 구멍을 ±2m 흔듦. 번호→좌표(x,y)는 `renders/explore_field_plan/layout_stats.json` 값 기준: 1(-10,8), 2(-4,8), 3(8,8), 4(14,10), 5(-14,14), 6(-6,14), 7(2,14), 8(8,14), 9(-8,20), 10(0,20), 11(6,20), 12(12,20), 13(-14,26), 14(-8,26), 15(2,26), 16(10,26), 17(-10,32), 18(-2,32), 19(4,32), 20(14,32). 최소 간격 6.0m, 내 땅굴 예시 = 13번.
- **B안 (4~5줄, 고르게 흩뿌림)**: 줄 개념 없이 2m 격자 위에서 6m 이상 떨어지게 무작위 분산(좌표는 layout_stats.json). 최소 6.0m, 내 땅굴 예시 = 8번. 줄이 덜 보여 덜 징그럽지만 위치 예측이 어려워 점프 방향 UI 가 더 필요.
- 번호는 반 명단 순서(1~20)로 매기고 내 땅굴 위치는 사람마다 다름.

## 4. 집·사다리 위치
- (초안, 채택 안 함) 집 2개 = **서쪽 가장자리(이전 반) + 동쪽 가장자리(다음 반)**, 들판 깊이 중간(y=18). 사다리 = **남쪽 가장자리 가운데**(카메라 쪽, 입구처럼). 5개 반을 고리(1→2→3→4→5→1)로 보면 집 2개로 직접 이웃 2개 반, 나머지 2개는 두 번 건너면 도달.
- 대안(B안): 집 1개(남동쪽 모서리) + 반 선택 목록 UI 로 나머지 4개 반 전부 직접 이동. 길로 가는 느낌은 약하지만 이동 횟수 적음.
- 추천: 2개(이전/다음). 사다리는 서버(캠퍼스·층) 선택 메뉴로 연결.

## 5. 구멍 모델 분리
- 지금 `hole.glb` 는 Mesh 1개 + 재질 2개(`rim`, `hole_inner`). 인스턴싱하려면 **노드 2개로 분리**해 새 이름 `hole_v2.glb`(`hole_rim` 약 250, `hole_inner` 약 160 삼각형, 기존 파일 보존)로 내보내기 (모델 수정 아님, 같은 형상).
- 링 색: `hole_rim` 은 버텍스 컬러 흰색 + InstancedMesh `instanceColor` 로 구멍마다 다른 색. `hole_inner` 는 색 건드리지 않음(그라데이션 유지).
- 일반 구멍 링 팔레트 10색: 기존 4색(노랑 `#F6D07B`, 민트 `#BCD494`, 하늘 `#BCD8E4`, 복숭아 `#F0B389`) + 신규 6색(나무+크림 `#E0B891`, 벽+크림 `#F4CDA1`, 초록+노랑 `#C0C45E`, 초록+하늘 `#B6D4B4`, 주황+노랑 `#EE9C46`, 하늘+크림 `#D7DFD7`). 구멍마다 회전 0~360°, 크기 0.9~1.1 변형.
- 내 땅굴: 같은 모델 + 링 분홍 `#F2A3A1`(팔레트 밖, 꽃에 이미 쓴 값) + 두더지 `mole.glb` 를 구멍에 세워 빼꼼. 구분용 얇은 분홍 후광 링(`hole_mine_halo`, ≤120 삼각형)은 선택 신규 에셋.
- 폴리곤 예산: 구멍 408(일반 20개 = 8.2k, 인스턴싱), 후광 ≤120, 두더지 17.75k(1마리).
