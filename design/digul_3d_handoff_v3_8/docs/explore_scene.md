# 탐색 장면 (호박밭 층) — 개발팀용

목표 화면: `renders/explore_scene/pumpkin_preview.png` (1600×900)
원본: `blend/explore_scene_pumpkin.blend`, 빌드 스크립트: `scripts/build_explore_scene.py`

## 공통 규칙
- 1 unit = 1m. 격자 1칸 = **2m × 2m**. 칸 (col,row) 중심 = Blender (2·col, 2·row) = three.js `(2·col, 0, -2·row)`
- 모든 부품: **원점 = 바닥 중앙(z=0), 정면 = Blender -Y** (glTF/three.js 에서는 +Z). glb 는 Y-up 으로 내보냄
- 땅 윗면 = 높이 0. 길 윗면 = 0.05
- 회전은 Z축(three.js 에서는 Y축) 반시계 90° 단위. 좌우 반전 금지
- 재질은 전부 무광(roughness 0.8~0.95)
- 호박·잎·덩굴은 `vine_patch.glb`를 인스턴싱으로 흩뿌려 쓰고, 단독 호박(`pumpkin.glb`)은 필요할 때 추가로 놓기

### 길 타일 연결 (기본 방향, 아래=-Y, 오른쪽=+X)
| 이름 | 기본 연결 |
|---|---|
| `path_straight` | 아래·위 |
| `path_corner` | 아래·오른쪽 |
| `path_t` | 아래·왼쪽·오른쪽 (위는 막힘) |
| `path_cross` | 4방향 |
| `path_end` | 아래만 (끝은 둥글게) |
| `path_hole_pad` | 4방향, 중앙까지 뻗음(고리 없음). 구멍 테두리가 중앙을 덮음 |

이웃 칸과 이어진 방향 집합에 맞는 타일·회전을 고르면 됨. 구멍/빈자리/수직굴/오두막이 놓이는 칸 아래에도 같은 방식으로 **연결된 방향에 맞는 타일**을 깔면 됨(구멍 바닥이 0.075 로 길보다 높아서 길이 안쪽으로 비치지 않음). 경계 단면이 모든 타일에서 같아서 이음새가 맞음.

### 구멍 `rim` 색 바꾸기
`hole.glb` 의 `rim` 재질이 테두리, `hole_inner` 는 어두운 갈색 그라데이션(버텍스 컬러 COLOR_0, three.js GLTFLoader 가 자동 적용).
인스턴스마다 재질을 복제해서 색만 바꾼다 (`hole` 은 Mesh 1개에 재질 2개라 `o.material` 이 배열):
```js
const h = holeGltf.scene.clone(true);
h.traverse(o => {
  if (!o.isMesh) return;
  o.material = o.material.map(m => {
    if (m.name !== 'rim') return m;
    const c = m.clone(); c.color.set('#F8D26E'); return c;   // 관심사 색
  });
});
```
`rim` 의 COLOR_0 는 흰색(1,1,1)이라 `color` 가 그대로 반영됨. `hole_inner` 는 COLOR_0 그라데이션이라 건드리지 말 것.
렌더에 쓴 색(팔레트 색을 크림 `#F7E6C8` 과 섞은 파스텔): 노랑 `#F6D07B`, 민트 `#BCD494`, 하늘 `#BCD8E4`, 복숭아 `#F0B389`. (`scripts/build_explore_scene.py` 의 `RIMS`)

## 장면 배치 (렌더 기준, (col,row), 격자 칸 번호)
- 구멍: (0,4) 노랑 / (0,2) 복숭아 **(두더지 자리)** / (2,2) 민트 / (4,4) 하늘 — 구멍끼리 최소 4m(2칸) 이상
- 빈자리: (2,4) · 수직굴: (-2,2) · 오두막: (-2,4)
- 길: row 3 가로 줄(col -3~4)에서 세로로 갈라져 각 칸을 연결 (`EDGES` 목록은 스크립트 참고)
- 두더지: (0,2) 구멍 위에 `mole_master.blend` 의 `MOLE` 컬렉션을 Link 로 서 있음. 두더지는 `exports/mole.glb` 사용
- **잔디 덩어리**(`grass_patch.glb`): 화면에 6덩어리(전체 38.2㎡, 화면 안 30.9㎡ ≈ 보이는 땅의 27%). 회전은 0°/90°만 써서 길로 나뉜 칸에 맞춤, 스케일 0.8~1.3. 구멍·수직굴·오두막·빈자리 둘레에는 **흙 띠 0.4m 이상**(실측 최소 0.45m). **길은 잔디 위를 지나감**: 길 윗면 0.05 > 잔디 ≤0.038 이라 길이 위에 얹히고 잔디는 길 때문에 잘리지 않음. 겹치지 않게 서로 0.3m 이상 띄움
  - **아래쪽 두 칸 잔디 2덩어리**(`grass_cut_1`: 수직굴~두더지 구멍 사이 4.9㎡, `grass_cut_2`: 두더지 구멍 오른쪽~초록 구멍 5.5㎡): 큰 둥근 사각형(모서리 0.8m)에서 구멍·수직굴 둘레 **흙 띠 0.3m**만큼 둥글게 파낸 모양이라 glb 부품 없이 장면 전용 메쉬(격자 0.1m, 가장자리 부드럽게). 웹에서는 같은 모양을 `grass_patch.glb` 3종 + 원형 파냄 대신 타일링한 흙 구멍 테두리로 덮거나 이 메쉬를 따로 내보내 쓸 것. 총 8덩어리, 화면 안 잔디 41.2㎡ (아래쪽 절반 약 39%)
- **꽃·풀·버섯**(`flowers.glb` 8종): 잔디 위에만 43개, 8종이 화면 안에 모두 보임. 잔디 가장자리에서 0.2m 이상 안쪽, 호박 무리에서 0.3m, 꽃끼리 0.5m 이상, 길 가장자리 0.2m 이상 띄움
- **호박+덩굴**(`vine_patch.glb`, Collection `theme_pumpkin`): 호박 20개(무리 1~3개씩 9무리). **덩굴 무리 전체가 잔디 가장자리에서 0.2m 이상 안쪽**, 길과의 간격은 0.4m 규칙(실측 최소 1.0m, 0.25m 완화는 쓰지 않음)
- **울타리**(`fence.glb`): 뒤쪽 흙 슬랩 가장자리에서 0.6m 안쪽을 따라 한 줄(2m 칸을 곡선 접선 방향으로 회전해 이어 붙임)
- 땅: 주황 흙 `#F0B47A`(둥근 슬랩, 가로 21m × 세로 14.4m 둥근 사각형(슈퍼타원), 높이 0) + 바깥 잔디(재질 `grass`, 높이 -0.13)

## 층 테마 규칙 = 잔디 색 + 열매 모델
층마다 바뀌는 건 **두 가지뿐**이고 나머지(길·구멍·두더지·오두막·수직굴·울타리·꽃)는 공통이다.
1. **잔디 색**: 덩어리는 버텍스 컬러라 재질 색 대신 `Col` 을 바꾸거나 재질에 틴트를 곱한다. 바깥 잔디 바닥만 재질 **`grass`** 단색(`#8CC56A`).
2. **열매 모델**: 열매+덩굴을 담은 glb 한 세트를 통째로 교체한다. Blender 에서는 Collection **`theme_pumpkin`**(호박 `pumpkin_*` + 덩굴 무리 `vine_*` + 그 인스턴스)이 한 테마 묶음이다. 다음 층은 `theme_apple` 처럼 같은 구조(작은 덩어리 모양 3종 + 단독 열매)로 만든다.

| 층 | 잔디 색 (`grass`) | 열매 모델 |
|---|---|---|
| 호박밭 | **`#8CC56A`** (팔레트 포인트 초록) | `pumpkin.glb` + `vine_patch.glb` (`theme_pumpkin`) |
| 사과 과수원 | (다음 요청에서 정함) | (다음 요청에서 정함) |

```js
// 잔디 색 바꾸기: grass 재질은 공유되므로 한 번만 바꾸면 전부 반영
grassGltf.scene.traverse(o => { if (o.isMesh && o.material.name === 'grass') o.material.color.set('#8CC56A'); });
```

## 잔디 다듬기 (최신)
- 파낸 잔디 2덩어리(`grass_cut_*`)는 장면 전용 메쉬: 윤곽을 둥글게 다듬었고(모서리 포함) 같은 버텍스 컬러·풀 뭉치를 씀. 두께(0.03~0.04m)는 그대로.
- 안쪽 작은 풀 뭉치 `grass_tuft_small` 은 호박·꽃을 피해 장면에서 따로 배치(덩어리당 최대 3개, 자리가 좁아 실제 5개). 호박·꽃 위치는 변경 없음.
- 둥글린 윤곽 기준 꽃의 잔디 가장자리 거리 최소 0.16m(이전 규칙 0.2m), 호박은 0.20m 유지.

- **수직굴 사다리**: 길이 2.1m → 1.05m(절반), 가로대 2개. `ladder_shaft.glb` 다시 내보냄(크기·원점 동일, 구멍에서 짧게 삐죽 나온 모양).
- **grass_cut_1 확장**: 사다리 수직굴 쪽도 수직굴 둘레 흙 띠 0.3m만 남기고 같은 곡선으로 감싸도록 아래·왼쪽으로 넓힘(두더지 구멍 쪽과 좌우 대칭). 넓어진 부분에 꽃 2개·작은 풀 뭉치 3개 추가(호박 20개 그대로, 꽃 45개). 이 부분의 꽃은 윤곽에서 0.15m 이상.
