# v3.8 단어별 모델 연결표 (2026-11-18)

규칙
- 소분류를 `/`로 나눈 **단어마다 모델 1개**. 소분류를 고르면 그 단어 모델 중 **하나만** 방에 놓임
- "대분류 가구"라는 구분은 없앰. 모델 크기에 따라 자리만 다름: **큰**(바닥) / **벽**(벽걸이) / **작은**(선반·책상 위)
- "그 밖의 것"이라는 뜻의 `기타`(액세서리/기타, 곤충/파충류/기타)는 뺌 → 단어 **164개**
- 상태: **기존** = 지금 있는 모델 / **되살림** = 오늘 지웠던 옛 모델을 다시 씀 / **새로** = 새로 만들어야 함
