# 카메라 3단계 줌 스펙 v1.1

기준: 전 단계 **각도 45°(아래로), 세로 FOV 32.3°, 16:9**. 거리만 바뀜. 모델 새로 안 만듦. **v1 에서 바뀐 점: far 작물 ×1.25(×1.4 아님), far 단순화(변형 1 통일) 안 씀, far 구멍 중앙 정렬 막음 확정, 흙 노드 분리(soil_link_N_M)로 구역 경계 흙 토막 해결.** 이미지(v1.1 이전 렌더라 far 작물 ×1.4 이고 경계 흙 토막이 남아 있음. 구도·수치 참고용): `images/camera_far_zone1.png`, `images/camera_levels_compare.png`(같은 타깃 = 내 땅굴 13번 위치에서 near/mid/far, 각 단계 LOD 적용).

## 0. 각도 판단 (한 줄)
**45°·32.3° 고정이 낫다** — 구역 1개를 담는 거리는 45°에서 46m(여유 1.6m), 50°는 약 48m, 55°는 약 52m라 각도를 키우면 오히려 멀어져 작물·두더지가 더 작아지고, 40°로 낮추면 43.5m로 줄지만 나무·후광이 구멍을 더 가림. (먼 변이 넓고 가까운 변이 좁은 사다리꼴 때문에 정사각형 구역을 담으려면 가까운 변 폭 ≥ 36m 가 필요해서 40~42m 는 불가능, 45° 기준 최소 43m(여유 0), 여유 1.6m 두면 46m.)

## 2. 타깃 이동 한계
공식(모든 단계 공통, 활성 구역 합집합 U): **x ∈ [U.x0 + 먼변반폭, U.x1 − 먼변반폭], y ∈ [U.y0 + 타깃→가까운변, U.y1 − 타깃→먼변]**. 구간이 비면 그 축은 U 중앙으로 고정(far 단일 구역은 위 맞춤 타깃). 거리 D 가 중간값이면 계수로 보간: 가까운변 0.3167·D, 먼변 0.5767·D(=6.92/12), 먼변 반폭 0.7242·D.

| | near | mid | far |
|---|---|---|---|
| 6구역 전체 켬 x / y | ±45.3 / 3.8~65.1 | ±36.6 / 7.6~58.2 | ±20.7 / 14.6~45.5 |
| 구역 1만 켬 x / y | ±9.3 / 3.8~29.1 | ±0.6 / 7.6~22.2 | 고정 (0, 11.1) |
| (구멍을 화면 중앙에 둘 때) 슬랩 밖으로 보이는 폭: 좌우 / 북 / 남 | 4.7 / 2.9 / 0m | 13.4 / 9.8 / 1.6m | 29.3 / 22.5 / 8.6m |
| outer_grass(180×144m)에 남는 여유: 좌우 / 북 / 남 | 31.3 / 33.1 / 38.2m | 22.6 / 26.2 / 34.4m | 6.7 / 13.5 / 27.4m |

- 결정: **위 한계를 그대로 쓰면 어느 단계에서도 슬랩 밖이 보이지 않음**(near 한계는 v3.9 값과 같음). 구멍 중앙 정렬(가장자리 구멍 포함)은 near·mid 만 허용 — 슬랩 밖 잔디가 보이는 폭이 near 4.7m, mid 13.4m 로 outer_grass 안(여유 22m↑). far 는 29m 까지 보여 **막음(확정)**: 한계를 항상 적용하고 단일 구역은 맞춤 타깃 고정. outer_grass 를 더 키울 필요는 없음(far 에서도 모자라지 않음: 남는 여유 6.7m 이상).
- 켜지 않은 구역 = 잔디만 보이는 규칙: near·mid·far 모두 자연스러움. 구역 안쪽 흙(`soil_zoneN`)은 구역 가장자리에서 흙 가중치가 0 이라 끊기지 않고, 이웃으로 이어지는 흙 띠는 `soil_link_N_M` 노드로 분리돼 **N·M 두 구역이 모두 켜졌을 때만** 켜므로 far 경계 흙 토막이 없음. 켜지 않은 구역의 작물·길·울타리·흙은 숨김, 바닥은 잔디만.

## 3. LOD
| 요소 | near | mid | far |
|---|---|---|---|
| 꽃(`flowers.glb`) | 전부 | 50% (짝수 번째만) | 끔 |
| 풀 뭉치(`grass_tuft_small`) | 전부 | 끔 | 끔 |
| 울타리 | 켬(인스턴싱) | 켬 | 켬 |
| 작물 | 변형 그대로, 크기 1.0 | 변형 그대로, 1.0 | 변형 그대로, **크기 ×1.25** (변형 1 통일은 쓰지 않음) |
| 구멍 림·안쪽 | 1.0 | 1.0 | **×1.25** |
| 내 땅굴 후광 | 1.0 | ×1.0 | ×1.25 (구멍과 같이) |
| 두더지 | 1.0 | ×1.15 | ×1.5 |
| 길·흙·사다리 | 켬 | 켬 | 켬 |
- 구역 1(호박) 삼각형: near 13.7만 (꽃 7.0 + 작물 3.3 + 풀 0.5) → mid 9.8만 → far 6.3만. 사과로 채우면 각 단계 약 +1.2만.
- far 에서 작물을 색 덩어리로: **꽃·풀을 끄고 작물만 ×1.25 로 키움**(화면에서 호박 약 25px, 중앙 34px/m 기준). 인스턴스 색 틴트는 불필요(작물이 이미 단색 머티리얼). 호박 주황·딸기 빨강·사과 빨강점·고구마 보라·당근 주황 끝이 구분됨(이미지 참조).
- ×1.25 확대 시 슬롯 발자국 점검(길 간격 위반 0): 흙 번짐 가장자리에 닿는 슬롯 수(227개 중) — 호박 34, 사과 46, 딸기 35, 고구마 46, 당근 20. 닿는 곳은 흙 가장자리의 옅은 번짐이라 눈에 띄지 않음.

## 4. 두더지·내 땅굴
| | near | mid | far |
|---|---|---|---|
| 두더지 배율 | 1.0 | 1.15 | **1.5** |
| 구멍(림·안쪽·후광) 배율 | 1.0 | 1.0 | **1.25** |
| 두더지 키(화면 px, 45° 시점) | 약 90 | 약 52 | 약 36 |
- 두더지만 1.6배로 키우면 폭 0.82×1.6=1.31m 가 구멍 입구 1.02m 를 넘어서 림을 뚫고 보임 → **far 는 구멍도 ×1.25(입구 1.28m)로 같이 키우고 두더지 ×1.5(폭 1.23m)**. 구멍 ×1.25 는 흙 반경 1.3m 안에 들어감(구멍 반지름 1.19m).
- hop 클립은 두더지 오브젝트 배율에 같이 늘어나므로 그대로 사용(앵커는 구멍 중심, 높이 0.075×배율).
- 구멍 번호 UI 권장: near 전부 표시 / mid 전부 표시(작게) / far 내 번호와 마우스 올린 구멍만(한 화면 구멍 약 42개라 전부 표시하면 복잡).

## 5. 이동 연출 (hop + 카메라 패닝)
- `mole_hop_down` 0.417s / `mole_hop_up` 0.5s 는 **세 단계 모두 속도 그대로**(배율만 적용). far 에서 두더지 키가 약 36px 이라 사라지고 나타나는 동작은 작지만 읽힘.
- 카메라 패닝: 구멍 간 6~8m. 화면 이동량은 near 약 906px, mid 약 453px, far 약 236px. **near 0.4s, mid 0.4s, far 0.35s**, 이징 cubic-bezier(0.4, 0, 0.2, 1)(ease-in-out). 구역을 넘는 12m 이상 점프는 모든 단계 +0.1s.
- 순서(합계 약 1.3~1.4s)는 그대로: hop_down 0.42 → 숨김 → 패닝 → hop_up 0.5 → idle.

## 6. 줌 조작
| 항목 | 값 |
|---|---|
| 마우스 휠 | 누적 deltaY ±80 이상이면 한 단계 이동, 250ms 안 연속 입력은 무시 |
| 키·버튼 | `+` / `-` 키, 화면 버튼 3개(near·mid·far 점) |
| 전환 | 0.5s, `cubic-bezier(0.4, 0, 0.2, 1)`, 거리는 **로그 보간** D(t)=D0·(D1/D0)^e(t), 각도·FOV 고정 |
| 타깃 | 매 프레임 현재 D 의 한계(§2 공식)로 다시 clamp. far 단일 구역은 맞춤 타깃으로 0.5s 이동 |
| LOD 전환 | D < 17 near, 17~34 mid, > 34 far. 경계에서 ±10% 히스테리시스(올라갈 때 18.7/37.4, 내려갈 때 15.3/30.6). 켜고 끄는 요소는 전환 중간(0.25s)에 한 번에 바꿈 |
| 초기값 | near, 내 땅굴 중심 |

## 7. 확정 사항
1. far 작물 ×1.25. 2. far 단순화(변형 1 통일) 사용 안 함. 3. far 구멍 중앙 정렬 막음. 4. 흙 경계는 `soil_link_N_M` 규칙으로 처리(`explore_ground_150_v3.glb`).
