# 두더지 구멍 점프 클립 (두더지 잡기 방식)

파일: `exports/mole_v1_3.glb` (25개 = 기존 23개 + 아래 2개, `mole_v1_2.glb` 는 그대로 보존). 원본 `blend/mole_master.blend` (백업 `blend/_backup/mole_master_before_hop.blend`), 스크립트 `scripts/build_mole_hop.py`, 확인 시트 `renders/mole_hop/mole_hop_sheet.png`.
두 클립 모두 **방향 회전 없음(rotation 0), 정면(-Y, 카메라 쪽) 유지, 제자리**. 걷기·돌아서기·앞으로 착지 없음. 24fps.

## 클립
| 클립 | 프레임 | 길이 | 시작 루트 | 끝 루트 |
|---|---|---|---|---|
| `mole_hop_down` | 10 (11키) | 0.417s | (0, 0, 0), 스케일 1 = `mole_idle` 첫 프레임 | 위아래 -1.30m, 스케일 (폭 0.82, 높이 1.10, 깊이 0.82) → 머리 끝까지 구멍 바닥 아래 |
| `mole_hop_up` | 12 (13키) | 0.500s | 위아래 -1.30m, 스케일 (0.82, 1.10, 0.82) | (0, 0, 0), 스케일 1 = `mole_idle` 첫 프레임 (수치 검증: 모든 채널 차이 0.0) |

- `mole_hop_down` 키: 0s 서 있음 → 0.083s **웅크림**(높이 0.88, 폭 1.07) → 0.167s 내려가기 시작(가늘어짐: 폭 0.90, 높이 1.10, y -0.20) → 0.292s y -0.80 → 0.417s y -1.30.
- `mole_hop_up` 키: 0s 구멍 속 → 0.125s y -0.45 (늘어남: 높이 1.16) → **0.25s 오버슈트**(구멍 바닥 위 +0.10m, 높이 1.14) → 0.333s 착지 스쿼시(높이 0.90, 폭 1.08) → 0.417s 살짝 늘어남(1.03) → 0.5s `mole_idle` 자세.
- root 이외의 뼈·눈·셰이프 키는 클립 내내 `mole_idle` 첫 프레임 값으로 고정. 끝 자세가 `mole_idle` 과 정확히 같아서 `hop_up` 이 끝나면 바로 `mole_idle` 을 재생하면 이어짐.
- 앵커: 두더지 오브젝트를 **구멍 중심, 높이 = 구멍 바닥 0.075m** 에 둠 (`hole_v2` 바닥이 z=0.075). 지금 장면의 두더지 앵커 z=0 이면 0.075 로 올릴 것.

## 땅 아래 가리기 (마스크 사용법)
- `ground_props.glb` 의 `burrow_ground_mask` 는 스텐실이 아니라 옛 평평한 땅 위의 진갈색 불투명 원판(Ø1.6, z=0.04)이라 `hole_v2`(입구 Ø1.02, 바닥 z=0.075)에서는 **쓰지 않음**.
- 대신 불투명한 `hole_inner` 바닥과 땅 슬랩이 깊이 테스트로 가림. 두더지 재질에 투명·`depthTest` 끄기를 쓰지 말 것. 확인 시트에서 hop_down 11번째 프레임(0.417s)에 완전히 사라짐.
- 구멍 바닥을 뚫고 가라앉는 선이 거슬리면(선택): 두더지 재질에 z=0.075 클리핑 평면 `new THREE.Plane(new THREE.Vector3(0,1,0), -0.075)` 를 걸고 `renderer.localClippingEnabled = true`.
- 클립이 끝나면(`hop_down` 끝) 두더지를 **숨기고**(`visible=false`) 다음 구멍에서 다시 보이게 함.

## 전체 순서
| 구간 | 시간 |
|---|---|
| 1. `mole_hop_down` | 0.42s |
| 2. 두더지 숨김 (`visible=false`) | 0 |
| 3. 카메라 이동 (목표 구멍으로, 사이 간격 6~8m) | 약 0.4s |
| 4. 목표 구멍에서 두더지 보임 + `mole_hop_up` | 0.50s |
| 5. 곧바로 `mole_idle` (반복) | |
합계 약 1.3~1.4초 (0.42 + 0.4 + 0.5).
Enter 입장 모션(화면 어두워짐)은 별도.

## 참고: root 뼈 축 (직접 키를 만질 때)
`root` 뼈 로컬 Y = 월드 위(Z), Z = 앞뒤(깊이), X = 좌우. 그래서 위아래 이동은 location[1], 세로 스케일은 scale[1], 폭 scale[0], 깊이 scale[2]. (glb 에서는 translation y / scale 로 나옴.)
