## 2. 따라가기와 줌·hop 규칙
| 항목 | 규칙 |
|---|---|
| 타깃 | 두더지가 있는 구멍 중심 F. hop 중 F(t) = h0 + (h1−h0)·ease(t/0.4), ease = cubic-bezier(0.4,0,0.2,1) |
| 줌 | 0.5s, 같은 ease, D(t) = D0·(D1/D0)^e(t), 각도·FOV 고정. 타깃은 줌과 무관하게 F 유지 → 줌아웃해도 두더지 시점에서 멀어지기만 함 |
| 한계 보정 | 필요할 때만(자유 패닝, 단일 구역 far). 보정량 = clamp(raw) − raw 만 **임계감쇠 스프링** ω = 10 rad/s 로 평활(95% 수렴 0.47s). 타깃 자체에는 지연을 주지 않음 → 한 번에 쏠리지 않음 |
| 우선순위 | ① hop 패닝(0.4s 고정, 줌과 독립) ② 줌 D(t) ③ 한계 보정. hop 중 구멍 이동 입력은 잠금, 줌 입력은 허용. 줌 진행 중 재요청은 현재 D 에서 새 목표로 0.5s 재시작. hop 패닝은 줌 때문에 늘어나거나 줄지 않음 |
| 겹칠 때 | 독립 계산해 합성: 카메라 위치 = f(F(t), D(t)). 화면 이동 속도는 D(t) 에 따라 자연스럽게 달라짐 |
| 크기 연속 적용 | 두더지 (12→1.0, 24→1.15, 46→1.5), 구멍·후광·작물 (24→1.0, 46→1.25), log(D) 선형, D<12 는 1.0. 단계 경계에서 튀지 않음 |
| 켜고 끄는 요소 | 꽃 50% D≥17, 꽃 끔 D≥34, 풀 끔 D≥17, ±10% 히스테리시스, 0.25s 페이드 |

## 3. far 에서 구역 한 개만 켠 경우
| 규칙 | 활성 구역 비율 (화면 중 활성 구역 점유, 구역 1 구멍 25개 기준 최소 / 평균) |
|---|---|
| (이전 스펙) 구역 중심 고정 | 60% / 60% |
| 구멍 완전히 따라감 | 22% / 44% (구역 가장자리 구멍에서 화면 78%가 빈 잔디) |
| **채택: 맞춤 타깃 ± 9m** | **46% / 51%** |
| ±12m / ±6m | 38% / 49%, 53% / 55% |

- 채택 규칙(활성 구역 1개, far 만): 타깃 = ( Zx + clamp(Hx − Zx, ±9), Zy0 + 11.1 + clamp(Hy − (Zy0+18), ±9) ). 두더지가 가장자리면 구역 쪽으로 최대 약 5m 당겨지지만 줌 전환 중 스프링 보정으로 부드럽게 이동. 활성 구역 2개 이상이면 안전 한계만 적용(완전 따라가기).
- near 는 구멍 그대로 따라감(활성 비율 최소 55% / 평균 88%), mid 도 그대로(최소 31% / 평균 71%).
- 켜지 않은 구역은 바닥 잔디만 보이고 작물·길·울타리·흙이 숨겨짐. 단일 구역이어도 구역 가장자리 흙 토막은 없음(`soil_link_N_M` 규칙).
