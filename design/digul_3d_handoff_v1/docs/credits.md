## 2. 영상 배경(방)에 나오는 외부 에셋

방 영상(`videos/`의 `mole_room_drop_v3`, `mole_idle_v3`, `mole_walk_v3`, `mole_drink_v4`, `mole_sit_sequence_v3`, `all_animations` 앞부분, `furniture_drop_*`)의 방 가구 일부는 Poly Pizza 모델입니다.
방·가구는 아직 작업 중이라 이번에 모델 파일로 전달하지 않지만, 영상을 외부에 보여주거나 나중에 방을 전달할 때는 아래 표기를 따라야 합니다.
모든 Poly Pizza 모델은 CLAUDE.md 팔레트로 색을 바꾸고, Bevel 등으로 모서리를 둥글게 다듬었습니다.
CC-BY 모델은 배포할 때 작가 표기가 필요합니다. CC0 모델은 표기 의무가 없지만 기록을 위해 남겨둡니다.
