# 지상 이동 규칙 (발 미끄러짐 없이 걷기)

- 대상: `exports/mole.glb`의 `mole_walk`, `mole_turn`, `mole_look_around`, `mole_greet`, `mole_burrow_exit`, `mole_burrow_enter`
- 미리보기: `ground_walk_reference.mp4` (11/10 확정본: 새 배치·깊은 굴·다이브 수정·씰룩 중 발 파닥 반영, 501프레임 20.9초. 원본 장면 `ground_walk_reference.blend`, 두더지는 `mole_master.blend`에서 링크. 이전 영상 `ground_walk_reference_old.mp4`)
- 지상 소품: `exports/ground_props.glb` (아래 7번)
- 좌표: Blender는 Z-up. three.js(Y-up)로는 `(x, y, z)` → `(x, z, -y)`. 두더지 정면은 Blender -Y = three.js **+Z**
- 24fps 기준

## 1. 걷기 속도와 재생 속도

`mole_walk`는 제자리 걷기 (24프레임 = 1.0초 반복). 발이 땅에 닿아 있는 동안 발이 뒤로 가는 속도가 곧 "미끄러지지 않는 이동 속도".

| 항목 | 값 |
|---|---|
| 한 걸음 | 6프레임 (0.25초), 1초에 4걸음 (왼-오-왼-오) |
| 딛은 발이 뒤로 가는 거리 | 한 걸음에 0.081m |
| **기준 이동 속도 (재생 속도 1.0)** | **0.32 m/s** (정확히 0.324) |

**공식: 재생 속도(timeScale) = 이동 속도(m/s) ÷ 0.32**

- 예) 0.40 m/s로 움직이면 `action.timeScale = 1.25`, 0.24 m/s면 `0.75`
- 자연스러운 범위: 0.8 ~ 1.25배 (0.26 ~ 0.40 m/s). 이보다 빠르거나 느리면 다리 움직임이 어색해지므로, 속도 대신 거리를 조절하는 것을 권장
- 이동 속도는 **땅 표면을 따라 잰 속도**. 언덕에서는 아래 2번처럼 수평 속도가 줄어든다

## 2. 언덕에서 걷기

### 높이 (발이 땅에 붙게)
- 매 프레임 두더지 위치(x, z — three.js 기준 수평면)에서 지면 높이를 레이캐스트로 구해 **`mole.position.y = 지면 높이`** (원점 = 두 발 사이 바닥 중앙)
- 이 장면에서는 지면보다 1cm 아래(-0.01m)로 둠 (발바닥이 잔디에 살짝 묻히는 정도). 0 ~ -0.02m면 괜찮음

### 기울기 (오르막에서 몸을 앞으로)
- 진행 방향으로 앞뒤 0.12m 지점의 높이 차로 경사를 구함: `g = (h(앞 0.12m) - h(뒤 0.12m)) / 0.24`, 경사각 `θ = atan(g)`
- 몸을 경사각만큼 앞뒤로 기울여 두 발이 비탈면에 같이 닿게 함
  - three.js: `mole.rotation.order = 'YXZ'`, `mole.rotation.y = 진행 방향`, **`mole.rotation.x = -θ`** (오르막에서 코가 들림)
  - Blender: 오브젝트 회전 X = -θ (적용 순서 X → Z)
- 언덕이 끝나 평지로 바뀌는 곳(멈출 곳 0.3m 전부터)에서는 기울기를 0으로 부드럽게 줄임. 멈춘 뒤 인사·굴 들어가기 동작은 기울기 0을 전제로 만들어짐

### 속도
- 땅 표면을 따라 **0.32 m/s를 그대로 유지** (재생 속도 1.0)
- 그래서 수평으로는 `0.32 × cos θ` m/s만큼만 나아가고, 높이는 `0.32 × sin θ` m/s로 오르내림
- 수평 속도 `v_h`를 코드에서 정해 쓰는 경우: **재생 속도 = v_h × √(1 + g²) ÷ 0.32** (경사가 급할수록 다리를 더 빨리)
- 경사 20°(g = 0.36)까지 확인함. 이보다 가파르면 몸 기울기가 커져 어색해지므로 길을 돌아가게 하거나 언덕을 더 완만하게

## 3. 출발과 멈춤

- 걷기의 4·10·16·22프레임(0.125·0.375·0.625·0.875초)에서 **두 발이 나란히 모임** = `mole_idle`과 같은 발 위치
- **출발**: `mole_walk`를 4프레임(0.125초)부터 재생 → 서 있다가 바로 이어짐
- **멈춤**: 위 네 시점 중 하나에서 멈추고 다음 동작(인사·idle·굴 들어가기)으로 0.1초 크로스페이드
- 목적지에 정확히 멈추려면: 걸음 수(6프레임 단위)를 먼저 정하고 이동 속도를 ±3% 안에서 맞춤
  - 예) 미리보기에서는 표면 거리 3.06m(수평 3.0m, 언덕 포함)를 235프레임(9.79초) 동안, 기준 속도의 0.98배로 걸음

## 4. 방향 전환 `mole_turn` (0.5초)

- 제자리에서 발을 종종거리는 동작만 들어 있음 (뼈대는 회전하지 않음). **실제 회전은 코드에서 오브젝트를 돌림**
- 90° 기준: 0.5초 동안 `mole.rotation.y`를 `smoothstep(t / 0.5)` 곡선으로 돌림 (`smoothstep(u) = u²(3 - 2u)`)
- 왼쪽·오른쪽 모두 같은 동작 사용 (발 동작이 좌우 대칭)
- 회전량이 다를 때
  - 0 ~ 120°: 그대로 0.5초 동안 돌림
  - 120° 초과: `mole_turn`을 2번 이어서 재생하고 반씩 돌림 (예: 180° → 0.5초에 90°씩 두 번)
- 미리보기에서 쓴 회전: 두리번 후 오른쪽으로 90° (이웃 굴 쪽), 인사 후 굴을 바라보도록 왼쪽으로 90° (아래 5-1 규칙)

## 5. 굴 나오기·들어가기와 이어 붙이기

- `mole_burrow_exit`: `mole` 오브젝트를 **내 굴 중심**에 회전 0으로 두고 재생 → 굴 중심에서 (0, -1.75, +0.033)(Blender 기준, 굴 앞쪽)에 착지, -Y를 바라봄
  - 끝나면 `mole`을 착지 지점으로 옮기고(높이는 지면 높이) 다음 동작 재생. 뼈대 위치가 같아 끊김 없음
- `mole_burrow_enter`: `mole` 오브젝트를 **들어갈 굴 중심**에 두고, 굴을 향해 다가오는 방향으로 회전
  - 시작 자세는 굴 중심에서 로컬 (0, -1.75, +0.033)에 서서 굴 쪽(로컬 +Y)을 바라봄
  - 따라서 걷기 도착점 = `굴 중심 + 회전(0, -1.75)`, 도착 방향 = 굴을 바라보는 방향
  - 굴 중심 높이 = 도착점 지면 높이 - 0.01 - 0.033 (도착점과 같은 높이로 맞춰야 시작할 때 튀지 않음)
- 미리보기 배치 (Blender 좌표, 11/10 수정)
  - 내 굴: (0, 0.7, 0.071) → 착지 (0, -1.05)
  - 언덕: x 0.2 ~ 2.3m, 최고 0.20m (x 1.25m), 걷는 동안 몸 기울기 최대 19°
  - 이웃 굴: (3.0, 0.7), 회전 0° → 도착점 (3.0, -1.05) = 굴 바로 앞(카메라 쪽) 1.75m
  - 이웃 두더지: (4.65, -0.95), 도착점을 바라보도록 회전 (옆으로 1.65m 떨어져 마주 봄)
- **굴(burrow) 구조**: 흙더미 안쪽 타원형 입구(좌우 1.0m × 앞뒤 1.18m, 들어가는 방향 +Y 쪽이 더 넓음)에서 **깊이 1.2m 깔때기 굴**이 이어짐(아래로 갈수록 좁아지고 다이브 방향 +Y로 0.2m 기울어짐, 벽은 진한 갈색 → 거의 검정, 바닥은 둥글게 막힘). **지면은 굴 중심에서 반지름 0.8m 원으로 뚫음**(가장자리는 흙더미가 덮음) → 웹에서는 `ground_props.glb`의 `burrow`를 쓰고, 지면에 같은 크기 구멍을 내거나(CSG) `burrow_ground_mask` 원판으로 스텐실 처리(7번 참고). 두더지는 땅을 뚫지 않고 굴 안 어둠 속으로 사라짐

### 5-1. 들어가기 전 규칙: 엉덩이가 카메라를 향하게

- 굴에 들어갈 때는 **어느 방향에서 왔든 항상 카메라를 등지고(굴을 바라보고) 들어감**. 다이브 중 카메라에 배나 발바닥이 보이면 안 됨
- 순서: **굴 앞 도착 → `mole_turn`으로 카메라를 등지는 방향으로 돌기 → `mole_burrow_enter`**
- "굴 앞 도착점"은 항상 **굴 중심에서 카메라 쪽으로 1.75m**
  - 탐색 화면처럼 카메라가 한 방향(Blender -Y, three.js +Z 쪽)에서 내려다볼 때: 도착점 = 굴 중심 + (0, -1.75) (three.js: 굴 중심 + (0, 0, +1.75))
  - 카메라 방향이 다르면: 도착점 = 굴 중심 + 1.75 × (굴→카메라 방향을 수평으로 투영해 정규화한 벡터)
- 회전 방법
  1. 걷기로 도착점에 멈춤 (이때 바라보는 방향은 상관없음)
  2. 목표 방향 = 도착점에서 굴 중심을 보는 방향 (three.js, 정면 +Z: `targetYaw = atan2(굴.x - 도착.x, 굴.z - 도착.z)`)
  3. `Δ = targetYaw - 현재 yaw`를 -180° ~ 180°로 정리하고, 4번 규칙대로 `mole_turn`과 함께 `smoothstep`으로 돌림 (|Δ| > 120°면 두 번에 나눠)
  4. 다 돌면 `mole`을 **굴 중심**으로 옮기고 회전을 굴 기준 회전(= targetYaw, 탐색 화면에서는 0°)으로 맞춘 뒤 `mole_burrow_enter` 재생 (뼈대 시작 자세 = 도착점에 서서 굴을 보는 자세라 끊김 없음)
- `mole_burrow_enter` 다이브: 옆으로 비틀거나 구르지 않고 **앞으로만 숙여서**(최대 약 120°) 머리부터 들어감. 엉덩이는 카메라 쪽으로 들린 채 씰룩 3번 → 쏙. 뛰는 순간 발을 몸 안으로 접어 발바닥이 안 보임. 씰룩하는 동안에는 두 발이 엉덩이 위로 나와 좌우 번갈아 파닥거림(흙더미에 묻히지 않음)

## 7. 지상 소품 `exports/ground_props.glb`

- 원본: `ground_v1.blend`의 `props_assets`, `burrow_assets` 템플릿. 오브젝트마다 노드가 따로 있고 **각 노드 원점 = 바닥 중앙**(x·z 0), 위치·회전·크기는 코드에서 정해 `clone()`해서 씀
- 미리보기: `renders/ground_anim/ground_props_preview.png`

| 노드 | 내용 | 삼각형 |
|---|---|---|
| `burrow` | 굴 입구 묶음(빈 노드). 자식: `burrow_mound`(흙더미 + 깊이 1.2m 굴, 버텍스 컬러 `COLOR_0`), `burrow_clump_01~05`(흙덩이), `burrow_daisy_01~03`(데이지), `burrow_ground_mask`(지면 구멍 원판) | 약 8,600 |
| `signpost` | 나무 표지판 | 184 |
| `grass_tuft_01~03` | 풀 덤불 3종 | 576~720 |
| `flower_daisy`, `flower_small` | 데이지, 작은 분홍 꽃 | 704, 572 |
| `pebble_01~02` | 돌 2종 | 144, 244 |

- `burrow` 놓기: 굴 중심을 **지면 높이 − 0.033m**에 두고(5번과 같음), 다이브 방향(Blender 로컬 +Y = three.js 로컬 −Z)이 카메라 반대쪽을 향하게. 탐색 화면에서는 회전 0
- `burrow_mound` 재질 `M_burrow_vc`는 버텍스 컬러로 굴 안쪽이 어두워짐 → three.js `GLTFLoader`가 `vertexColors`를 자동으로 켬. 끄면 굴이 밝게 보이니 주의
- **지면 구멍** `burrow_ground_mask`(반지름 0.8m 원판, 굴 중심보다 0.04m 위): 화면에 그리지 말고 스텐실로만 씀
  - 마스크: `colorWrite=false`, `depthWrite=false`, `stencilWrite=true`, `stencilRef=1`, `stencilZPass=ReplaceStencilOp`, `renderOrder`를 지면보다 먼저
  - 지면 재질: `stencilWrite=true`, `stencilRef=1`, `stencilFunc=NotEqualStencilFunc` → 원 안쪽 지면만 안 그려짐. 두더지·굴 메시는 영향 없음
  - (주의) 마스크에 `depthWrite`를 켜면 굴 속 두더지까지 가려짐
  - 지면을 미리 잘라 둔 메시로 쓰면 마스크는 숨기기만 하면 됨
- 재질은 모두 무광(roughness 0.85), 텍스처 없음. 풀·꽃·돌은 같은 메시가 많으니 `InstancedMesh`로 깔면 가벼움
