# cam_burrow_enter: 굴 들어가기 카메라 연출 (개발자 참고용)

- 원본: `ground_v1.blend` → 컬렉션 `dev_camera` → 카메라 `burrow_enter_cam`, Action `cam_burrow_enter`
- 두더지 glb(`mole_burrow_enter` 등)에는 **포함하지 않음**. 카메라는 이 문서의 수치로 웹에서 직접 구현하는 것을 권장
- 24fps, 카메라 Action의 프레임 1 = `mole_burrow_enter` 프레임 1 (같은 시각에 함께 재생)
- 미리보기 (11/10 현재 모델·새 굴 입구): `renders/ground_anim/mole_burrow_enter_v5_cam.mp4` (카메라 고정 버전은 `mole_burrow_enter_v5.mp4`). 예전 v4 영상은 옛 모델이라 참고하지 말 것

## 좌표 기준

- 아래 위치는 **굴 기준(`mole_anchor`, 굴 중심 바닥) 상대 좌표**. 두더지 애니메이션도 같은 기준이라, 웹에서 굴 위치에 그대로 더하면 됨
- 이 씬의 `mole_anchor` 월드 위치: Blender (0, 0.7, 0.071)
- 이 카메라는 두더지가 굴 앞(카메라 쪽, anchor 기준 -Y 1.75m)에서 굴을 바라보고 들어가는 경우 기준. 다른 방향에서 와도 `ground_move_spec.md` 5-1 규칙대로 먼저 카메라를 등지게 돌린 뒤 재생하므로 그대로 쓸 수 있음
- Blender는 Z-up. three.js / glTF(Y-up)로 바꿀 때는 `(x, y, z)` → `(x, z, -y)`
- 구멍 입구 중심 = anchor + (0, 0, 0.075). 11/10부터 구멍 아래에 깊이 1.2m 어두운 굴이 이어져, 카메라가 구멍 속으로 들어가면 어둠 속을 내려다봄 (굴 구조는 `ground_move_spec.md` 5번)
- 렌즈 고정: 30mm, 센서 36mm, 16:9 → **세로 FOV 37.3°** (가로 61.9°). 줌은 FOV가 아니라 **카메라 이동(돌리)** 으로 처리

## 화면 페이드 (미리보기 영상에서만 적용)

- **시작: 프레임 52 (t = 2.125s)**, 끝: 프레임 64 (t = 2.625s) → **0.5초** 동안 검정으로
- Blender에서는 노출(Exposure)을 0 → -12로 낮춰 표현 (Action `preview_fade_cam`, 미리보기 전용)
